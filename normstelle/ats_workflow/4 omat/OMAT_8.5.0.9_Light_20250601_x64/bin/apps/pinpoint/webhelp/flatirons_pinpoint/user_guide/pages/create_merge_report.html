Create Merge Report

Not applicable for Pinpoint Standalone Light.

Users must have permissions for the Can merge new revisions privilege to create a merge report.

  1. Open the Publication Management dialog. Refer to Publication Management for Merge Operations.
  2. Click the Create Merge Report option in the Actions column on the right side of the dialog.
    A confirmation message appears:

  3. Click the button to create the report.
    A success message appears:

    After the report is created, you can view it by selecting it in the Publication Management dialog. Refer to View Merge Report.
