B787 Wiring Diagrams

Wiring diagrams in B787 WDM publications have some additional features in the Graphics pane.

When opening these diagrams, the right pane is split horizontally with the wiring diagram in the upper section and a set of information tabs in the lower section.



B787 Wiring Diagram view

The lower section contains tabs for part, wire and harness tables. Above the three tabs there is a free-text search filter. The filter covers all columns and performs a continuous search while you are typing.

This view type includes a hot-spot feature that utilizes the linking mechanisms in the structured data. For example, you can click on a Harness Number to see its position highlighted in the wiring diagram:



Text-to-graphic link

The tools available for the wiring diagram graphic in the upper area are identical to those described in Graphics Pane.
