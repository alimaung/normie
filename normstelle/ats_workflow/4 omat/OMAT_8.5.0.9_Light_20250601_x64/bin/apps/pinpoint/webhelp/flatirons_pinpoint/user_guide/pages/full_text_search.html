Full Text Search Pane

Full Text Search is a quick way to find one of these types of data:
  • When not selecting the Part or FIN options, this search returns results for a set of words that appear in a publication, any attachments with machine readable text data, and some ATA vector graphics. When using this option, CIR data is not included in the search. For example, if you type a part number for an S1000D publication in Full Text Search without selecting the Part option, only part numbers defined in IPD data modules are returned.
  • Parts publications (such as AIPC, EIPC, IPD, IPDP, and Panasonic_IPD) have a Part option. When activating the Part option, the search first tries to do a normal full text search. If no results are returned, the input is assumed to be a part number in the CIR. For example, this type of search includes results for optional parts or preferred parts.
  • The FIN option appears for certain publications (such as ATA publications). When selecting the FIN option, this search returns results for FINs.
  • For iSpec 2200 data, a Code field allows you to search by ATA code.
The Full Text Search pane is opened by clicking the header below the Table of Content. The search page can be opened either in the context of a single publication or a library. If opened on the library level, it will search across all publications in that library.
The Full Text Search options depend on the context. For detailed descriptions of the search options, refer to these sections:
