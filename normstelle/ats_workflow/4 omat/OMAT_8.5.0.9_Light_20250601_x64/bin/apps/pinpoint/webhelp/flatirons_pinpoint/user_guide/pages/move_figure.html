Move Figure/Sheet

Not applicable for Pinpoint Standalone Light.

Users with the Can author content permission can move figures and sheets in the Figure List. Moving figures or sheets is available from the Figure List dialog.

To open the Figure List dialog, do these steps:
  1. Enter authoring mode. Refer to Enter Authoring Mode.
  2. From the Content pane header, select the Figure List icon.
    The Figure List dialog appears. For example:


    Figure List Dialog

Move a Figure
  1. In the Figure List dialog, hover over the name of the figure that you want to move. These options appear:


  2. Click the Move Figure icon. The icon changes to a move indicator.

    You can drag the figure to a different location in the figure list.

Move a Sheet
  1. In the Figure List dialog, click the figure title to view the sheets in the figure.
  2. Hover over the name of the sheet that you want to move. These options appear:


  3. Click the Move Sheet icon. The icon changes to a move indicator.

    You can drag the sheet to a different location in the figure list.
