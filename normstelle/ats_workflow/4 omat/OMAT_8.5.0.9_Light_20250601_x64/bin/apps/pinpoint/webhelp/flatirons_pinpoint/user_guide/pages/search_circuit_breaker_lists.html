Search Circuit Breaker Lists

Circuit Breaker Search is a search type in Wiring Search. For more details, refer to Wiring Search Pane.

Note: Circuit Breaker Search is not available for Airbus publications.
  1. Open a Wiring publication in the Library pane.
  2. Open the Wiring Search.
  3. From the Search Types drop-down menu, select Circuit Breaker Search.
  4. Do one of these choices:
    1. Enter all or part of a component number in the EIN field.
    2. Enter a panel numbe In the PAN field.
  5. Click on the Search button, or the keyboard Enter button, to start the search. If you need to clear the filter and start over, click the Reset button.
    Your search results appear in the Search Results Equipment tab. If there are multiple entries in the result you will see a tip about selecting one of the entries to see more information. For details on navigating the results, refer to Navigate Search Results in the Equipment Tab.
