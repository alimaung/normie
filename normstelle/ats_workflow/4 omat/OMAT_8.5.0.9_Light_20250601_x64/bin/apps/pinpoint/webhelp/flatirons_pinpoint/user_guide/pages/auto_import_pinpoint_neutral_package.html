Auto Import Pinpoint Neutral Package

You can add a Pinpoint Neutral Package (ZIP file) to an import-data folder to automatically import the package into Pinpoint. By default, this auto import feature is available. You need to create a new folder where you can add the Pinpoint Neutral package. When you place a package in the folder, the import happens automatically.
Note: You cannot add encrypted neutral packages to this folder. Encrypted neutral packages must be uploaded using the Import Data Package feature in Pinpoint.
Note: The scheduler runs every minute to read any ZIP files added to the folder.

To auto import a Pinpoint Neutral package, do these steps:

  1. Create a new folder named pinpoint-autoimport, for example, C:\pinpoint\pinpoint-autoimport.
    Note: This is the default name for this folder. Your administrator can configure the name of the folder to fit your environment and will advise you if you should use a different folder name.
  2. Add a Pinpoint Neutral package (ZIP) to the pinpoint-autoimport folder.
    The package imports into Pinpoint automatically. You can view the progress of the import by selecting the Publication Import Overview icon on the Action Bar.

    If the import is successful, the package disappears from the folder. If the import fails, .failed is appended to the file name, for example, importfile1.zip.failed.

  3. Navigate to and view the imported library and publication.
