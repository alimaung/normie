Navigating PDF Documents

When selected in the Library the PDF will be displayed directly embedded in the Content pane. Pinpoint provides embedded PDFJS for Chrome and Firefox and no PDF Viewer plug-in is required to view documents. Internet Explorer requires Acrobat Reader.

Click the Find in Document icon in the PDF Viewer header and enter a keyword in the search field to quickly search within a document and produce a search results list. The internal search bar shows the number of results from the search.



PDF Search List

The keyword is highlighted in both the search results list and the first instance in the document. You can select results directly from the search results list and go directly to that page content.

You can also use these features in the internal search bar to navigate within the document:
  • - Find the previous occurrence of the search phrase.
  • - Find the next occurrence of the search phrase.
  • - Highlight all instances of the search phrase in the document.
  • - Search for instances of the search phrase exactly as entered in the search field.
