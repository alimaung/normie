Authoring

Permissions

Not applicable for Pinpoint Standalone Light.

Authoring has four primary personas: authors, reviewers, mergers, and auditors. Access to the various authoring features is controlled by privileges. Setting the permissions for a privilege is a prerequisite to being able to use these features.

Each organization can make their own changes to shared documents. The modified version is accessed and viewable only to users within that organization. The original (non-modified) version is accessed and viewable to users in other organizations.
Note: Users in the System organization do not have access to the authoring functionality.
Note: This feature is not available for HTML publications.
The authoring features are available for iSpec and S1000D manuals. The following manuals are editable if published using the iSpec publish builder:
  • EM
  • IPC
  • OMAT
  • SDS
  • SPM
  • TLM
  • TSD
The following conditions identify additional details about Pinpoint authoring in publications uploaded using the S1000D publish builder:
  • For procedure schema data modules:
    • If a DM contains sections with IDs, then those sections will be editable.
    • Editable sections are designated as OEM updates.
    • If a DM contains no sections with IDs, then the entire DM will be editable.
    • The Pill and Tab feature will be hidden during an editing session.
    • The system does not handle automatic renumbering of sections, this must be done by the author.
    • The step navigator functionality will be disabled in the authoring tab.
    • When authoring figures, any changes that have been made to a figure title will not be reflected in the figure list in the graphics panel.
      • To sync the figure title in both the content and figure panel, the user has to edit them separately in the figure list and the graphics panel.
  • For descriptive schema data modules:
    • If a DM contains sections with IDs, then those sections will be editable.
    • Editable sections are designated as OEM updates.
    • If a DM contains no sections with IDs, then the entire DM will be editable.
    • The Pill and Tab feature will be hidden during an editing session.
    • The system does not handle automatic renumbering of sections, this must be done by the author.
  • For parts schema data modules:
    • If a DM contains sections with IDs, then those sections will be editable.
    • Editable sections are designated as OEM updates.
    • If a DM contains no sections with IDs, then the entire DM will be editable.
    • The Pill and Tab feature will be hidden during an editing session.
    • It is the responsibility of author to keep any existing Links intact (unbroken), ex: for the links of PNR, Vendor, SB.
    • The system does not handle automatic renumbering of sections, this must be done by the author.

Permissions are set in Access Control for the Authoring functionality. Refer to the "Permissions for Pinpoint Viewer" topic in the Flatirons Access Control Module User Guide for permissions available for Pinpoint. You can open this guide by clicking the button in the Access Control application Header Bar.

These privileges apply to Authoring:
  • Can author content provides access to the authoring mode.

    You must have permission for the Can author content privilege to access the authoring mode in Pinpoint. Refer to Enter Authoring Mode.

    This permission also allows you to see document anchors in the Table of Content pane. When the document anchors are available, you can use the copy link feature to copy links to the anchor. Refer to Insert Link.

  • Can merge new revisions allows users to create a merge report and do side by side merges.
  • Can review authored changes allows users to accept or reject authored changes.
  • Can review change log provides access to the log of authored changes.

Color Coding

  • Draft Status

    You can quickly identify the status of the draft by the color on the left side of the Change Log dialog and the Draft History log.

    • In draft status: Orange
    • In review status: Blue
    • In approved status: Green
    This is an example of the Draft History log, which is accessible to all users with the Can author content permission:

  • Revision Highlights

    These colors indicate the type of changes to the authored content:

    • OEM changes: light blue
      Note: OEM highlighting is visible on the Merge Report only.
    • COC changes (approved): light pink
    • COC changes (unapproved/new): darker pink
    • Conflicted changes: gray
