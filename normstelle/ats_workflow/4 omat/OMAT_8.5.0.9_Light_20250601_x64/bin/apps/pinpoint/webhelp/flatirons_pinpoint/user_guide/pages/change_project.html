Change Project

If you already have one project opened and want to move to another, do the steps that follow:

  1. Click the project you want to open in the Library pane.
    A dialog appears asking if you want to open the library in another page.


    Pinpoint Dialog

  2. Click the OK button.
    A new browser tab for the selected project opens. The tab name corresponds to the selected Project in the Library.
    Note: Multiple Pinpoint tabs can be open simultaneously.
