Hotspots in S1000D and iSpec Data

SVG hotspots are supported for data built with the S1000D builder and the following style kits:
  • stylekit-s1000d-4.0-ata
  • stylekit-s1000d-4.0.1
  • stylekit-s1000d-4.1
These 3D graphics are supported for the following iSpec 2200 manual types:
  • GENX-1B EIPC
  • GENX-1B ITEM (TEMAN)
Note: The 3D graphic file types are .wrl only. The graphic hotspots supported are text-to-graphic and graphic-to-text.
The following hotspot types are supported:
  • Text-to-graphic (internalRef)
  • Graphic-to-text (internalRef)
  • Graphic-to-document (dmRef) (only S1000D)
  • Multi-destination hotspots (dmRef) (only S1000D)

When navigating using hotspot links, you can use the Previous button in the Action Bar to go back to the document/graphic you were viewing. The associated graphic is open with focus on the selected graphic and with the hotspot highlighted.

Text to graphic (internalRef)

A text-to-graphic reference is a link in the content that will direct the user to a certain location within a graphic in the same document. When you click on this link, the Graphic pane opens and zooms in on the linked object. The object in the graphic is also highlighted.

Graphic-to-text (internalRef)

An object in a graphic can link to an element within the same document. When clicking on such a link, the Content pane is scrolled to the linked object.

Graphic-to-document and multi-destination hotspots (dmRef)

An object/location in the graphic can link to one or several different documents.
  • If the object links to one data module only, you will be taken directly to that document.
  • If the object links to more than one document, you will get a list of references when you click on that object, as shown in the example below:

When clicking on a reference the document will be opened in Content pane.

If you want to return to the previous document, you can click on the Previous button in the Action Bar.
