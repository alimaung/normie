Wiring Search Pane

The Wiring Search pane is available when you open a supported wiring publication in the Library. It is minimized by default, you can maximize it with a click. Wiring Search allows you to trace electrical wires from one component to another and see any in-between connections. For examples of supported wiring publications, refer to Table 1.
Note: The wiring search types available depend on the Original Equipment Manufacturer (OEM) and ATA specification of the publication. For example, Airbus publications support Wire Search and Electrical Path Search.
Note: Electrical Path Search is enabled by default, however, it is dependent on the Enable Electrical Path configuration in Data Manager for the builder.

The Wiring Search pane also has the Search Types, which helps you categorize the search. The system remembers the option that the user selected the last time and auto-populates it whenever the user accesses the Wiring Search next time.
Note: This capability is supported until the browser cache is cleared.
Note: When the Wiring Search is opened for the very first time, the search type value defaults to the top option of the list.
The search types available in Wiring Search are described in the sections below.

Electrical Path Search

This search allows you to search for components and wires in electrical paths. You can then navigate along an electrical path by clicking on components, pins, and wires. The Electrical Path search is an optional search type for wiring publications (e.g., AWL, AWM, and WDM).
Note: The Electrical Path search option is visible in the Search Types drop-down menu by default. To hide this option, clear the Enable Electrical Path checkbox when publishing the publication in Data Manager.
For details on how to perform a search, refer to Search Electrical Paths.

Wire Search

This search allows you to search for bundle and wire numbers in wire lists. The option to search for a Spare Wire is specific to Boeing.
Note: You can perform a harness/bundle search in a wire search for C-Series data. This feature is available when you enter an exact harness/bundle number in the Bundle field.
For details on how to perform a search, refer to Search Wire Lists.

Equipment Search

This search allows you to search for components in equipment lists.
Note: Equipment Search is not available for Airbus data processed through Data Manager. If you are viewing this data type, refer to FIN/Zone/Panel Search instead.
For details on how to perform a search, refer to Search Equipment Lists.

Hookup Search

This search allows you to search for the EIN or FIN in hookup lists. Whether the search field is EIN or FIN depends on the publication context.
Note: Hookup Search is not available for Airbus data processed through Data Manager. If you are viewing this data type, refer to FIN/Zone/Panel Search instead.
Note: The Hookup tab may or may not be available depending on the OEM data format.
For details on how to perform a search, refer to Search Hookup Lists.

Bracket Search

This search allows you to search for EINs in bracket lists.
Note: Bracket Search is not available for Airbus publications.
For details on how to perform a search, refer to Search Bracket Lists.

Circuit Breaker Search

This search allows you to search for PANs and EINs in wire lists.
Note: Circuit Breaker Search is not available for Airbus publications.
For details on how to perform a search, refer to Search Circuit Breaker Lists.

Ground Search

This search allows you to search for EINs in ground lists.
Note: Ground Search is not available for Airbus publications.
For details on how to perform a search, refer to Search Ground Lists.

Splice Search

This search allows you to search for EINs in splice lists.
Note: Splice Search is not available for Airbus publications.
For details on how to perform a search, refer to Search Splice Lists.

Terminal Search

This search allows you to search for EINs in terminal lists.
Note: Terminal Search is not available for Airbus publications.
For details on how to perform a search, refer to Search Terminal Lists.
