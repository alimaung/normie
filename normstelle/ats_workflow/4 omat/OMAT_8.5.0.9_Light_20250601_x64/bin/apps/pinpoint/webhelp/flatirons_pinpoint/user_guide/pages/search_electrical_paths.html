Search Electrical Paths

An Electrical Path search requires a single aircraft effectivity to be selected. For details about how to select effectivity, refer to Filter Pane.
Electrical Path search is a category in Wiring Search. For more details, refer to Wiring Search Pane. The Electrical Path search is an optional search type for wiring publications (e.g., AWL, AWM, and WDM).
Note: The Electrical Path search option is visible in the Search Types drop-down menu by default. To hide this option, clear the Enable Electrical Path checkbox when publishing the publication in Data Manager.
  1. Open a Wiring publication in the Library pane.
  2. Open the Wiring Search.
  3. From the Search Types drop-down menu, select Electrical Path.
  4. Do one of these choices:
    1. Enter all or part of a component number in the identification number field.
      Depending on the OEM, this can be an EIN or a FIN.
    2. Enter all or part of a part number in the WIRE field.
  5. Click on the Search button, or the keyboard Enter button, to start the search. If you need to clear the filter and start over, click the Reset button.
    Your search results appear in the Search Results section. If there are multiple entries in the result you will see a tip about selecting one of the entries to see more information. For details on navigating the results, refer to Navigate Search Results in the Electrical Path Tab.
