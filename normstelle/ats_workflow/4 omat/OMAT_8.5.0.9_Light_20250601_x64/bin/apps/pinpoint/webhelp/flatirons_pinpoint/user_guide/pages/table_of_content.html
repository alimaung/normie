Table of Content Pane

The Table of Content pane displays the structure of the publication selected in the Library.



Table of Content

Note: When you open a symbolic link publication, the Table of Content shown is for the original (target) publication.
If you have permission for the Can see content anchors in ToC privilege, the Table of Content expands an additional level to show content anchors and graphics. The content anchors and graphics are not visible if you do not have this permission. The Show More icon indicates that there is additional content. For example:


Table of Content (Task - Subtasks Available)

Click the Show More icon to view the additional content. For example:


Table of Content (Task - Subtasks Expanded)

Click the anchor reference you want to open.

Click the Minus icon to hide the first level anchors.

When publishing from Knowledge Center a (KCA), airframe and engine manuals have a Revision Highlights section that is generated automatically during publishing. For example:


Table of Content (Revision Highlights)

Note: This section is an authored one for the Airbook builder.
After you select Revision Highlights in the Table of Content and open it, it shows the new, revised, and deleted elements for full and incremental revisions. Refer to Revision Highlights (KCA Builders Only).
The table that follows describes various components of the Table of Content pane.
Table 1. Table of Content Components
Component Description
minimize pane icon / maximize pane icon Click this icon to minimize/maximize the Table of Content pane.
Table of Content header If a document is selected, the header shows the name of the selected document.
Show More icon For publications published with the iSpec or KCA builders only.

This icon indicates there are additional anchor references, such as subtasks and graphics. Click the icon to display those references. You can click a reference to view it.
Minus icon For publications published with iSpec or KCA builders.

When the first level anchors are visible, click this icon to hide them.
Show Revision History

Not applicable for Pinpoint Standalone Light.

Click this icon to display the Change Log dialog.
Note: You must have permission for the Can review change log privilege for this dialog to be visible.
You can view the status of documents in this dialog. Refer to Change Log.
Manage Publication icon

Not applicable for Pinpoint Standalone Light.

If you are an organization administrator, click this icon to set the revision that is shown for the selected publication. Refer to Manage Organization Revisions.
Bulk Print icon Click this icon to print the entire publication or a selected section of the publication. Refer to Bulk Print.
Hide/Show Filtered Content icon This icon allows the user to choose to show or hide the filtered content. Refer to Show/Hide Filtered Content
Show Metadata icon Click this icon to see additional publication details or define a landing page for the publication, Refer to Publication Metadata.
hierarchy node Click this icon to reveal lower levels of the publication, such as sections, tasks, subtasks, and subjects.
document node Click this icon to view the document in the Content pane. A loading indicator appears before the document is displayed.
Subtask Icon For publications published with iSpec or KCA builders.

This icon indicates a first level anchor for a subtask. Click this icon to open the subtask.
Figure Icon For publications published with iSpec or KCA builders.

This icon indicates a first level anchor for a figure. Click this icon to open the figure.
Sheet Icon For publications published with iSpec or KCA builders.

This icon indicates a first level anchor for a sheet. Click this icon to open the sheet.
