Resolve Revision Conflicts

Not applicable for Pinpoint Standalone Light.

Users must have permissions for the Can merge new revisions privilege to view a merge report and resolve conflicts.

The Merge Report panels provide information about documents with changes in the revision and allows you to resolve any conflicts.
Note: Sections, figures, and sheets in conflict have a gray background. You must resolve all conflicts in the document to mark the document as resolved. All documents must be resolved to complete the merge.
Note: The source data must specify unique identifiers (i.e. IDs or keys) for sections, figures, and sheets in order to see proper alignment between sections, figures, and sheets across revisions. Data without identifiers will show sections, figures, and sheets as removed from the previous revision and added in a new revision without alignment.

    The left side of the main panel shows the new OEM revision. The right side shows the preview of the new OEM revision with the added COC changes.

  • The far-right side of the panel shows available actions for each section of the document.
  • The top-right part of the screen has these icons:
    • Perform additional authoring changes icon

      This option is available when all conflicts of the current documents are resolved. You can perform additional changes to the right-side content before completing the merge. This is useful when you want to resolve a conflict using OEM or COC but also copy content from the version not selected. For example, you may want to keep your COC version but copy OEM changes to the COC version.

      When you select this option, this confirmation message appears:

      Enter the reason for the additional changes in the Comment field, and click the button.
      Note: The content entered in the Comment field is visible to auditors in the Merge History dialog. Refer to Merge Audit.
    • Merge History icon

      This option is available after any merge action and allows an auditor to display all merge actions for the current document. Refer to Merge Audit.

    • Reset preview document icon

      This option is available after any merge action and restores the right-side document to its initial state. Any merge actions are removed, and the merge history cleared for the document.

      When you select this option, this confirmation message appears:

      Click the button to reset the document to its initial state.

    • icon/field

      This icon/field indicates the total number of conflicted sections, figures, or sheets in the current document.

  2. Review the conflicts in the Document tab and/or the Figure List tab.

      A comment dialog appears:

    • Click the button to select the COC change.

      A comment dialog appears:

    • Click the button to reject all changes.

      A comment dialog appears:

    These are some things to consider when choosing the Reject option:
    • When you reject a section containing COC changes only, this action results in rejecting the COC changes and using the OEM version of the section instead.
    • When you reject a section containing OEM changes only, this action results in rejecting the OEM changes and using the OEM's content from the previous revision as a new COC.
    • When you reject a section containing both OEM and COC changes, this action results in rejecting both the COC and OEM changes and using the OEM's content from the previous revision as a new COC.
  4. Optional. Enter a comment in the comment dialog for the action selected.
    In the comment dialog, you can provide justifications for selecting that merge option. The user performing the action, the action taken, the timestamp when the action was taken, and comments are persistent on the merge history and are available for review by an auditor in the future. Refer to Merge Audit for more information.
  5. Click the button.
    A success message appears. A icon replaces the conflict buttons on the right side of the report.
    Note: If you hover over the icon, it changes to a Rollback changes icon. Click the icon to revert the previously selected conflict resolution. The resolution options appear again. You can select an option to change the conflict resolution.

    Refer to Abort or Complete the Merge for information on aborting or completing the merge.
