Edit Section

Not applicable for Pinpoint Standalone Light.

The authoring mode allows you to edit the content for the selected document. After the draft is approved, the modified document is available only to users within your organization.

To edit a section, do these steps:

  1. Enter authoring mode. Refer to Enter Authoring Mode.
  2. In the left margin of the Content pane, click the Edit content within this section icon for the section you want to edit. The selected section is available.
    For example:


    Authoring Tab - Section Open to Edit

  3. After editing a section, you can use the options on the Authoring Toolbar to format the information, add reference or graphic links, and warnings/cautions/notes. Refer to Authoring Toolbar.
  4. When the section is complete, select one of these options from the Authoring Toolbar:
    • Click the Save button.
      Note: A success message appears:

      The section with your changes is highlighted.
    • Click the Cancel button to cancel.

      A confirmation message appears:

      Click the button to delete the changes.

    After saving or discarding your changes, you can discard your draft or send it for review. Refer to Discard a Draft and Send Changes for Review for details.
