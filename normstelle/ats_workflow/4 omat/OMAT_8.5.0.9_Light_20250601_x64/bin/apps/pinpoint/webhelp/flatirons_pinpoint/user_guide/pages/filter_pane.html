Filter Pane

The Filter pane is opened by clicking on the icon in the Action Bar. This panel allows you to select a filter (Applicability/Effectivity) that will hide (S1000D context) or gray out (ATA context) content not applicable for the model you are interested in. You can configure if you want to hide or gray out the content which is not applicable. Refer to the “Client UI Configuration Options (Preferences)” topic in the Flatirons Pinpoint Configuration Guide for the configuration settings.
Note: The Filter icon can be located in the More drop-down menu if your page width is less than or equal to 1280 pixels.
Note: The Filter pane works differently for graphics. If the graphic is not applicable for the selected model, a message shows that the graphic is not available.

When you select a filter specific to an applicability or effectivity containing one or multiple selections, there are these possible results:
  • If the content being viewed has more than one applicability/effectivity filter applied to the publication and you select a filter, the content not applicable for the selected filter is either displayed (grayed out) or suppressed (hidden).
    Note: In publications with multiple applicability/effectivity filters applied, the Toggle Filtered Content icon is active only when you select one or more filters. Click the icon to suppress or display the content that is not applicable for the selected filter.

  • If the content being viewed contains only one applicability or effectivity option and you select a filter, the non-filtered content is suppressed.
  • The search results only include results expected from the selected filter.
  • Once you select a filter, the TOC does not include content for a node that is not part of the filter.
When you select an effectivity filter for publications published with a KCa builder in Data Manager, there are also these results:
  • If the search result is a different publication within the same folder structure, the effectivity remains active for both the original and new opened publication.
  • If the search result is a different publication in a different folder structure, the effectivity is reset for the new folder/new opened publication.
  • If the effectivity is not set to ALL, the specific effectivity text displays in the TOC.
Note: If you have separate publications that have their own filter set, these are merged in the library and can cause an issue when filtering. To avoid this issue, only one filter set should be in a library since this is applied to the entire library.
The free text search filter in the top of the pane is practical if you have many items in your table. The filter covers all columns and performs a continuous search while you are typing.
Note: Filtering can also be configured to display only those aircraft in the filter panel which belong to the user's organization. This will be based on the NCAGE code as mapped in the pct_mapping.xml file. Refer to the “Configuration to Display Only Those Aircraft in Filter Panel Which Belong to a Particular Organization” topic in the Flatirons Pinpoint Configuration Guide to enable this feature.

The filter information shown and the allowed actions in the panel depends on the data you are filtering. For ATA and A350 data, multiple filters can be selected by clicking on them. There are also buttons for selecting/deselecting all filters below the table.

Filter pane, S1000D context

The Condition tab allows you to apply a content filter based on one or several conditions, so you can filter portions of the content that you don’t want to see. You can filter conditions from all the conditions available in the package and relevant to the currently opened document. You do this by the selection of the checkbox beside the statement "Only shows filters relevant to currently displayed content.".
Note: Enabled only for S1000D Builder, so packages published with S1000D builder. Not enabled by default for all users. Only filters the data modules in the contents section and does not apply to Full Text Search or for the Table of Content.


Condition Tab

When an appropriate selection has been made, the filter is set by clicking on the OK button.

You are then redirected back to the publication and the parts that do not apply to the model (or models) appear either grayed out on the screen (ATA context) or they are completely hidden (S1000D context). The selected filter is also displayed as a rolling text in the top Action Bar next to the Filter icon.

Note: The selected Conditions will not be displayed as a rolling text on the Action Bar as per design.
Note: System administrators can configure the visible columns and the order in the effectivity/applicability selection page. Also the format that displays the selected products in the effectivity/applicability selection page and the application header. Refer to the topic "Customize Effectivity Selection Columns" in the Flatirons Pinpoint Configuration Guide.

Your administrator can apply effectivity filters for Airframe and Engine publications when they are published with a KCA builder in Data Manager. Administrators, refer to the specific KCA builder in the Flatirons Data Manager User Guide.

When the publications with effectivity applied for Airframe or Engine categories are in the same library, this is the behavior:
  • If a publication has effectivity selected, only the effectivity list for that publication displays.
  • If a publication has no effectivity set, an empty effectivity list displays or a pop-up message appears indicating there is no effectivity for the publication.
  • If you navigate to another publication with the same category, the selected effectivity applies to the new publication.
  • If you navigate to another publication with the same category, but the new publication does not contain the product selected, a pop-up message prompts you to select a different effectivity.
  • If you navigate to another publication with a different effectivity category, a pop-up message prompts if you want to proceed with the selected publication.

The table lists all filters available for the selected publication.
