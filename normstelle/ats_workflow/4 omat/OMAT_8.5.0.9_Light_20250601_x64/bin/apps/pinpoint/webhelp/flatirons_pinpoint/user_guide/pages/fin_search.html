FIN/Zone/Panel Search

Note: The FIN/Zone/Panel Search page is only available for A350 and C-Series data.

Zone/Panel Search page



The Fin/Zone/Panel Search pane is available when you open an A350 S1000D publication in the Library pane. This search option has these categories:
  • FIN (to search for Functional Item Numbers)
  • Zones (to search for zone links within AMM, AIPC, and TSM. The search results also include zone metadata and lists of all FINS and panels within the zone.)
  • Panels (to search for panel links within AMM, AIPC, and TSM. The search results also include panel metadata.)
You can do both complete and partial searches, and you can search across a set of pre-defined Business Categories:
  • AIPC
  • AMM
  • ASM
  • AWM
  • TSM or AFI
    Note: The publication names are the names set in data manager for the publications.
  • CB List
  • Fin List
  • Panel List
  • Wire List
  • Zone List

When running a search in specific business category, it returns hits belonging to the chosen category only. There is also an ALL option in the drop-down list. If you choose this instead, it will present the categories that return hits in a new dialog:



Searching with "ALL" - select business category

The number of hits per category is shown in the right side of the panel. Business Categories that do not return hits are not shown.

When a category is selected, the hits are listed in the Search Results section below.

Tip: A FIN search can also be initiated from the search field in the header bar. The behaviour when using the header bar search field is the same as when selecting the "ALL" option.

It is not required to start all over again if you want to switch business category, you can simply choose a different category from the drop-down list in the Search Results header:



Switch Business Category

How search results behave when they are opened depends on the business category:
  • AIPC: Presents the document in a new AIPC tab in the Content pane.
  • AMM: Presents the document in a new AMM tab in the Content pane.
  • ASM: Presents drawings/schematics in the Graphic pane.
  • AWM: Presents wiring diagrams in the Graphic pane.
  • TSM or AFI: Presents the document in a new TSM or AFI tab in the Content pane.
  • CB List: Search results are presented in a C/B tab with a list of FINs and their titles. When a FIN is selected in the list, information about the FIN is presented in a Technical Data tab.
  • Fin List: Search results are presented in a FIN tab with a list of FINs and their titles. When a FIN is selected in the list, information about the FIN is presented in a Technical Data tab.
  • Panel List: Search results are presented in a Panel tab with a table of panel numbers with columns showing Type, Access To, Access To FIN, Zone and Applicability. When a panel row is selected, information about the panel is presented in a Technical Data tab. If you click the “Zone” number, a pop-up appears with information about the selected zone.
  • Wire List: Search results are presented in a FIN tab with a list of FINs and their titles. When a FIN is selected in the list, information about the wiring related to this FIN is presented in a Wiring tab. Notice that the FIN you selected will be marked in bold letters to make it easier to identify it in the Wiring tab. You can further select a row in the Wiring tab to view detailed information about the wire in a Technical Data tab.
  • Zone List: Search results are presented in a Zone tab with a table of zone numbers with columns showing Designation, Applicability and links to FIN LIST and PANEL LIST containing all FINs and panels within the zone. When a zone row is selected, information about the zone is presented in a Technical Data tab, and you can open related zoning illustrations.

For additional search instructions, refer to Perform a FIN, Zone, or Panel Search.
