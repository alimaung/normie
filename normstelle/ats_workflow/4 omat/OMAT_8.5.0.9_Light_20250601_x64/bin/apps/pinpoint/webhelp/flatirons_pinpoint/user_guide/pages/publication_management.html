Publication Management

Not applicable for Pinpoint Standalone Light.

For each publication you want to configure, open it first in the Library pane. Click the Manage Publication icon in the Table of Content bar to open the Publication Management dialog. The options available in the dialog depend on the type of user and permissions granted to the user role to which the user belongs.

This is an example of the dialog for a non-admin user:

All users (admin and non-admin) can specify which revision to use as their active revision. Refer to Set your Active Revision.
Note: The revisions available are set by the organization admininistrator.
There are other types of users with permissions that allow them to perform additional tasks in the Publication Management dialog.
  • Authoring user (Merges)

    Users with the Can merge new revisions privilege can also create merge reports, view merge reports, and resolve conflicts between revisions. Refer to Revision Merge.

  • Administrator user (Organization)

    Users with the Can manage organization publications privilege can also set default revisions for their organization. Refer to Manage Organization Revisions.

Set your Active Revision

You can specify which revision to use as your active revision. To set your active revision, do these steps:
  1. Select a revision.
  2. In the Actions column, select Set as my Active Revision.
