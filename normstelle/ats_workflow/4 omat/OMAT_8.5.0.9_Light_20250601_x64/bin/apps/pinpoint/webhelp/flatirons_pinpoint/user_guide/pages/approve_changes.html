Approve/Reject Changes

Not applicable for Pinpoint Standalone Light.

To review changes, do these steps:

  1. Open the Change Log for a document. Refer to Change Log.
  2. Click in the far right column for the document you want to review.
    The selected document opens in the Content pane. In this example, the dark pink section shows the new content to be reviewed while the light pink section is pre-existing approved content:


    Authoring Tab - Review Content

    Note: The number that displays on the Reject Changes and Accept Changes buttons indicates the number of changed sections, figures, or sheets.
  3. After reviewing the changes, select one of these options:
    • Click the button to reject the changes.

      The Reject Changes dialog appears, for example:

      Optional. Enter a reason for the rejection in the comment field.
      Note: This comment is persistent in the draft history and can be accessed by the author.

      Click the button. This action returns the document to authoring.

    • Click the button to accept the changes.

      The Accept Changes dialog appears, for example:

      Optional. Enter a review comment in the comment field.
      Note: This comment is persistent in the draft history and can be accessed by auditors in the future.

      Click the button. This action updates the live version of the document with the new content.
