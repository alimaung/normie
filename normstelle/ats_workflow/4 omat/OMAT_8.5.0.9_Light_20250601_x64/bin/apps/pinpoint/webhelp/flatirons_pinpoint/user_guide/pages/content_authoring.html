Content Authoring

Not applicable for Pinpoint Standalone Light.

Content authoring allows you to perform these tasks:
  • Add a section: Refer to Add Section.
  • Edit a section: Refer to Edit Section.
  • Delete a section: Refer to Delete Section.

The Authoring Toolbar lets you format the content and add reference links, graphic links, and warnings/cautions/notes. Refer to Authoring Toolbar for a description of the options on the toolbar.
