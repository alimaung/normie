Edit Figure/Sheet

Not applicable for Pinpoint Standalone Light.

Users with the Can author content permission can edit figures and sheets. Editing figures or sheets is available from the Figure List dialog.

To open the Figure List dialog, do these steps:
  1. Enter authoring mode. Refer to Enter Authoring Mode.
  2. From the Content pane header, select the Figure List icon.
    The Figure List dialog appears. For example:


    Figure List Dialog

Edit a Figure
  1. In the Figure List dialog, hover over the name of the figure that you want to edit. These options appear:


  2. Click the Edit Figure Edit Sheet icon.
    You can edit the Figure Prefix and Figure Title fields for a figure. For example:


    Figure List Dialog - Edit Figure

  3. After making your changes, click the button.
Edit a Sheet
  1. In the Figure List dialog, click the figure title to view the sheets in the figure.
  2. Hover over the name of the sheet that you want to edit. These options appear:


  3. Click the Edit Sheet icon.
    You can edit the sheet's title, replace the sheet's graphic, or do both. For example:


    Figure List Dialog - Edit Sheet

  4. After making your changes, click the button.
    Note: Editing an existing sheet and replacing it with a new image will generate the thumbnail and display it in the Pinpoint content pane.
