Authoring Toolbar

Not applicable for Pinpoint Standalone Light.

The Authoring Toolbar is available when you add or edit a section.


Authoring Toolbar

This table describes the components of the toolbar:

Table 1. Authoring Toolbar Components
Component Description
Save Click this button to save your changes.
Cancel Click this button to cancel your changes.
Delete Section Click this button to delete the section.
Undo Click this icon to undo your changes.
Redo Click this icon to redo your changes.


Style Options		 Select the style options to format your content:
  • Paragraph (Headings, Preformatted)
  • Bold
  • Italic
  • Background Color
  • Align (Left, Center, Right, Justify)
  • Bulleted list
  • Numbered list
  • Decrease Indent
  • Increase Indent
  • Table
Add a Link Click this icon to add a link. Refer to Insert Link.
Insert graphic link Click this icon to select an existing graphic to add. Refer to Insert Image.
Insert warning and caution Click the down arrow and select an option from the drop-down menu:

Refer to Insert Warning/Caution/Note.
