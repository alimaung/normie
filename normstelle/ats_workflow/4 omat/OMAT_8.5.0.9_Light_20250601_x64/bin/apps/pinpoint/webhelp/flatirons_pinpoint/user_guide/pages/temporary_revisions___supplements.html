Attachments

Each separate document in the Library can have attachments (such as temporary revisions or supplements) that can be opened in many different ways. Refer to View Attachment.
Note: This feature is not available for HTML publications.
Users with proper permissions can manage attachments using the icons in the Attachments pane (refer to Attachments Pane). All attachments are shared among all Pinpoint Viewer online users in the Attachments pane. There is a synchronization job enabled with the Sync Supplement contents? configuration option (refer to Configuration Pane) that can refresh any attachments in Pinpoint Standalone that were added/modified/deleted on the Pinpoint Viewer online side. However, anything that is done with attachments in Pinpoint Standalone is not synchronized back to Pinpoint Viewer online. Additionally, Pinpoint Mobile users can also see attachments as they appear in Pinpoint Viewer online whenever a user does a manual synchronization, but it is not possible to add attachments at all through Pinpoint Mobile.
Note: For details on giving users the ability to manage attachments, refer to Flatirons Access Control Module User Guide.

Users with proper permissions can also add attachments from Knowledge Center or upload attachments via Pinpoint Viewer. For details on adding attachments with Pinpoint Viewer, refer to Add Attachment.

Note: The attachments described in this section are different from file annotations. For details on file annotations, refer to Annotations.
