Search Maintenance Messages

Maintenance Messages Search is a category in FRMFIM Search. For more details, refer to FRMFIM Search Pane.

To search Maintenance Messages, do these steps:

  1. Open a FRMFIM publication in the Library pane.
  2. Open the FRMFIM Search.
  3. From the Search Type drop-down menu, select Maint Message Search.
  4. Do one of these choices:
    1. Enter all or part of the identifying text in the Text field.
    2. Enter all or part of a maintenance message code in the Code field.
  5. Click on the Search button, or the keyboard Enter button, to start the search.
    Your search results appear in the Search Results section. Click on the link in the Refs column to see the task for a the message in the Content pane.


    Maint Message Search Result

    From the Search Results area, click the Print Search Results icon to print the search results in PDF format.
