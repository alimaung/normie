Search Observed Faults

Observed Fault Search is a category in FRMFIM Search. For more details, refer to FRMFIM Search Pane.

  1. Open a FRMFIM publication in the Library pane.
  2. Open the FRMFIM Search.
  3. From the Search Type drop-down menu, select Observed Fault Search.
  4. Do one of these choices:
    1. Enter all or part of the identifying text in the Text field.
    2. Enter all or part of a fault code in the Code field.
      FRMFIM fault codes are identified by an index number with the format NNN NNN NN, with N representing a numerical digit. Examples:
      • 223 480 42
      • 223 48
      • 22
  5. Click on the Search button, or the keyboard Enter button, to start the search.
    Your search results appear in the Search Results section.

    If you click on a hyperlink in the Refs column, the associated task is directly opened.

    If there are multiple tasks associated with the Code or Text results, click in the Refs column to view those. Click any of the task hyperlinks in the Refs column to open the task.

    Click in the Refs column to hide the tasks.



    Observed Fault Search Result

    From the Search Results area, click the Print Search Results icon to print the search results in PDF format.
