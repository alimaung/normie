Document Metadata

The Document Metadata window is opened by clicking on the "i" in the Content pane.
Note: This icon is only available if the data module has S1000D builder-generated metadata.


Document Metadata

The table lists document metadata, for example:
  • Data Module Code (DMC)
  • Language
  • Version
  • Issue Date
  • Security Classification
  • Responsible Partner Company
  • Originator
  • Quality Assurance
  • Applicability
Note: If a field does not have metadata, it will not appear in the table.
