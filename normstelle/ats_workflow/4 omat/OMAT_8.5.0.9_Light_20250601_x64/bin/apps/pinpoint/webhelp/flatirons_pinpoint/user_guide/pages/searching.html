Searching

This section describes how to use the different search options in Pinpoint.
Note: The in the top Action Bar is context sensitive, meaning that it will open the search pane relevant for the publication you are currently viewing. For example, if you are viewing a page in a TSM publication, it will open TSM Search. Also, if you are following a link, say from a TSM publication to an AMM, and then click the button, it will open Full Text Search pane.
Note: The Search icon can be located in the More drop-down menu if your page width is less than or equal to 1280 pixels.

  • Search EICAS/EIS Messages
