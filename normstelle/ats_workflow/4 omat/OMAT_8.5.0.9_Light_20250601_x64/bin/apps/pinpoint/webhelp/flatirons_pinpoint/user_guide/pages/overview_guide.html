User Guide Overview

This user guide provides the basic information necessary for using Pinpoint. It assumes that you are already familiar with basic computer functions and software terminology.

For the Flatirons Suite documentation, the term S1000D publications/manuals is most often used to refer to standard S1000D publications instead of OEM-specific S1000D publications. The functionality offered for some types of S1000D publications (such as C-Series, A350, and XWB) may be customized from the default standard S1000D publication behavior.

Note:

This documentation covers the general functionality of the product only and does not cover the wide range of customizations that can vary through configuration.

Note: Acronyms are used throughout this user guide. If you encounter an acronym you do not know, refer to Acronyms.
