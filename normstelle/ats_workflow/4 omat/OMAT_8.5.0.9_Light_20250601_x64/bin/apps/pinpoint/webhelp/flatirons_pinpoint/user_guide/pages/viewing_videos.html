Viewing MP4 Videos

Pinpoint supports MP4 video format. The MP4 videos can contain chapters.
Note: Chapters can be added through graphic hotspots. No VTT files are added with the video.
When selecting an MP4 with this type of structure, an icon is available in the toolbar below the video display. If you hover over the icon, the chapters appear. You can navigate to different sections of the video by selecting a topic.

The toolbar below the video display allows you to navigate through the video.

This table provides the components available on the toolbar.

Component Description
Play Select this option to play the video.
Pause Select this option to pause the video.
Replay Select this option to replay the video.
Mute/Unmute Select this option to toggle between mute/unmute.
The progress bar shows the progress of the video. The time displays the time remaining in the video display.
Previous Select this option to return to the previous topic.
Hover over this icon to display the chapters available in the video.
Next Select this option to skip to the next topic.
Fullscreen/Non-Fullscreen Select this option to toggle between fullscreen and non-fullscreen view.

These steps describe how to open, view, and navigate through an MP4 video:

  1. Open Pinpoint and navigate to a document that contains an MP4 video.
  2. Click the link to the video.
    The video appears in the Graphic pane.
  3. Click the Play button to start the video.
  4. Hover over the icon to display the chapters.


    Note: The video player remains static and is not hidden.
  5. Click a topic to navigate to that part of the video.
  6. Select the Previous and Next buttons to move between topics in the video.
