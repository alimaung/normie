Viewing SIMIC/VRML 3D Graphics

Pinpoint supports rendering of SIMIC/VRML 3D graphics in the Graphics pane.

Note: In A350, there is a complementary SIMIC data package that is add-on data to the existing A350 SRM. It supports the display of aircraft structure image as background of SRM Part 3D image.
Note: CORTONA 3D Viewer plugin for web browser must be installed on the Pinpoint client station for viewing SIMIC/VRML graphics. Notice that this is not required if you are using Internet Explorer and Chrome.
The steps below describe how to open and use the keyboard and mouse to rotate, move and zoom the SIMIC/VRML graphic.
Note: The functionality available for 3D graphics depends on the data construction and configurations.
  1. Open Pinpoint and navigate to a document that contains a SIMIC/VRML graphic.
  2. Click on the multimedia link to open it in the Graphic pane.


    3D Graphic in the Graphic pane

  3. The following keyboard and mouse combinations can be used to rotate, move and zoom the graphic:
    • Rotate: Click/hold left mouse button and move the mouse in any direction.
    • Move: Alt + left mouse button and move the mouse in any direction.
    • Zoom in/out: If the mouse has a wheel, simply use the wheel to zoom in and out. If the mouse does not have a wheel, press Ctrl + left mouse button and move the mouse up to zoom out and down to zoom in.
  4. If the graphic includes hotspot links, and the application has been configured to handle these, you will have additional navigational features in the Content and Graphic pane:
    • Mouse over the graphic and get part information in pop-up windows:

    • Click on a hotspot in the 3D graphic to highlight the corresponding item in the part list in the Content pane:

    • Click on an item in the Content pane to highlight the object in the 3D graphic.
    • Click once more on the same item to zoom in on the object.
      Tip: In some cases you will need to rotate the 3D object in order to see highlighted parts.
      Note: The hotspot functionality requires additional conversion software and configuration. For more information, refer to the Flatirons Pinpoint Configuration Guide.
