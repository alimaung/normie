TSM Search

The TSM Search pane is available when you open a Troubleshooting publication in the Library.
Note: When you launch a TSM Search, the default Search Type is CFDS FAULT. You can configure this to default to WARNINGS.


TSM Search

Note: For A350 and A380 data, there will also be a search field for Fault Code Criteria.
TSMs enable the systematic identification, isolation, and correction of aircraft warnings and malfunctions reported inflight and on the ground. Each of the standard chapters contains the information that follows:
  • Fault Symptoms (corresponding to each Fault Isolation Procedure)
  • Fault Isolation Procedures (with links to Highlights and Fault Symptoms)
  • Task Supporting Data
The Fault Symptom pages are divided into these three main columns:
  • WARNINGS/MALFUNCTIONS
  • CFDS FAULT MESSAGES
  • FAULT ISOLATION PROCEDURE
Note: For A350 and A380 TSM publications only, CMS FAULT (Central Maintenance System) is the search type instead of CFDS FAULT. The functionality is the same.

TSM Search allows you to search for Warnings and CFDS Fault Messages. They are available under Search Type field. The most recent option selected by the user is auto-populated the next time user accesses the TSM search.

The categories available are described in the sections below.

WARNINGS

WARNINGS search allows you to search for warning messages in TSMs and find links to related tasks.

The table that follows describes search options in the WARNINGS category:

Search Field Description
Category
  • ECAM: Limits the search to ECAM warnings and ECAM status (inoperative systems and maintenance status).
  • SD: Limits the search to ECAM warnings and ECAM status with system page (inoperative systems and maintenance status). Selecting this radio button reveals a SYSTEM PAGE field.
  • LOCAL: Limits the search to local warnings (panel lights and standby indicators).
  • EFIS: Limits the search to flags and advisories (on ECAM and EFIS system pages).
  • OBSV: Limits the search to crew and maintenance observations.
  • ALL: Enables searching all of the options.
FAULT CODE The full or partial fault code you want to search for.
KEYWORDS The keywords you want to search for.
Exact Match This check box can be selected if you want to exactly match the text you entered into the KEYWORDS field.
ATA CODE The ATA code refers to sections of the publication. The ATA code is represented in this format: AA-BB-CC-DDD.
System Page System Page keyword to search for.

For specific steps, refer to Search Warning Messages.

CFDS FAULT

CFDS FAULT (Central Fault Display System) search allows you to search for fault messages in TSM publications and find links to related tasks.

The table that follows describes search options in the CFDS FAULT category:
Note: For A350 and A380 TSM publications only, CMS FAULT (Central Maintenance System) is the search type instead of CFDS FAULT. The functionality is the same.
Search Field Description
KEYWORDS The keyword you want to search for.
FAULT CODE The full or partial fault code you want to search for.
Exact Match This check box can be selected if you want to exactly match the text you entered into the KEYWORDS field.
ATA CODE The ATA code refers to sections of the publication. The ATA code is represented in this format: AA-BB-CC-DDD.
