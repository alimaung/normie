Parts Inquiry

The parts inquiry feature allows you to perform a part inquiry and pass parameters for the part to a third-party application for your organization.

Note: Administrators, this feature must be enabled. Refer to the topic Enabling Parts Inquiry in the Flatirons Pinpoint Configuration Guide.
To perform a parts inquiry, do these steps:
  1. From the Library pane, select a folder.

    Publications that belong to the selected folder appear under the folder name.

  2. Select a publication.

    The publication displays in the Content pane.

  3. Select the button below the part you want to check.
    Note: This button does not appear for an manufacture part number (MPN) when the UPA column is blank, contains the letters REF or RF, or any other non-numeric value.

    The third-party application configured for your organization appears.

  4. Verify the information in the application. For example, you may want to verify these items:
    • Part Number
    • MFG cage code
    • Part Description
    • Other items as determined by your organization
