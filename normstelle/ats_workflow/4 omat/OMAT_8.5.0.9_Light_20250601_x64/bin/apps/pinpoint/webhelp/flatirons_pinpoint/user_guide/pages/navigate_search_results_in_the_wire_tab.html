Navigate Search Results in the Wire Tab

  1. Perform a Wire search as described in Search Wire Lists.
    The search results are displayed in the Wire tab below the search fields.

    From the Search Results area, click the Print Search Results icon to print the search results in PDF format.



    Wire Search Result

    Note: If the data for A350 contains a Next Higher Assembly (NHA) for a wire number, the search results show NHA next to the wire number, for example:

  2. Click on the search result to access more information about the entry.
    The row is highlighted and expanded so that you can see detailed information about the entry.


    Wire Search Result Expanded



    Wire Search Result Expanded (Airbus Example)



    Wire Search Result Expanded (Boeing Example)

    Note: The information categories available on the search results page vary depending on the type of search.
    Note: With an entry highlighted in the Wiring search result, you can open the Electrical Path tab and trigger a electrical path search for the wire. If a result for another entry is already present in the Electrical Path tab, you will be asked if you want to start a new electrical path with the selected entry. Refer to Navigate Search Results in the Electrical Path Tab for instructions to electrical path search navigation.
  3. Use the search results in the Wire tab as desired.
