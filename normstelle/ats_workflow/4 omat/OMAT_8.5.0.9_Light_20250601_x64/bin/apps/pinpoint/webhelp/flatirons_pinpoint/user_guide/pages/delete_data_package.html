Delete Imported Data Package

Not applicable for Pinpoint Standalone Light.

You can delete publications imported directly into Pinpoint, Pinpoint Standalone, and Pinpoint Server Light. The publication must be in a released state. This functionality applies to these types of publications:
  • Publications rendered from Pinpoint Neutral Packages
  • Single PDF files
Note: The delete feature does not apply to publications imported through Data Manager. If you select a publication imported in Data Manager, this message displays: "This publication was imported from Data Manager. Please remove it from Data Manager."
Note: You must have Read permission for the Can import and delete data packages privilege. You must also have Read access for the publication you want to delete. Refer to the Flatirons Access Control Manager User Guide for permission information.

To delete a data package, do these steps:

  1. Select a publication imported directly into Pinpoint from the Library pane.
  2. Click the Publication Operations icon in the Action Bar.
    The publication operations delete option appears, for example.

  3. Click Delete <publication>.
    A delete confirmation message appears, for example:

  4. Click OK to delete the publication.
    The publication is deleted from the library.
