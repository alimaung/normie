Viewing X3D Graphics in X3D Landing Page

Note: To view X3D Graphics in an X3D Landing Page, you must first configure the landing page. Refer to the Flatirons Pinpoint Configuration Guide for more information.

The steps below describe how to open and use the keyboard and mouse to rotate, move and zoom the X3D graphic in the Landing Page. You can also use the options at the top of the Landing Page to manipulate the graphic. Additionally, you can right-click the graphic to perform a full text search, focus on a specific element (hiding the other elements), or hide an element.

  1. Open Pinpoint and open a library or publication that has a landing page that contains an X3D graphic.


    X3D Graphic in the Landing Page

  2. These keyboard and mouse combinations can be used to rotate, move and zoom the graphic:
    • Rotate: Click/hold left mouse button and move the mouse in any direction.
    • Move: Alt + left mouse button and move the mouse in any direction.
    • Zoom in/out: If the mouse has a wheel, simply use the wheel to zoom in and out. If the mouse does not have a wheel, press Ctrl + left mouse button and move the mouse up to zoom out and down to zoom in.
  3. These options located at the top of the Landing Page can be used to manipulate the graphic:
    Table 1. Landing Page Graphic Options
    Option Description
    Reset Resets the image to its original size.
    Default Returns the image to its initial view when first loaded.
    Left Shows the left side of the image.
    Top Shows the top of the image.
    Bottom Shows the bottom of the image.
    Right Shows the right side of the image.
    Hidden Items Click this icon to display the Hidden Elements tab. To close the tab, click the icon again.
    Go Back Returns the image to the previous view.
    Explode Explodes the elements in the image.
    Zoom Zooms in on the image.
    Opacity Increases or decreases the opacity for the non-selected parts in the X3D image.
  4. Right-click an area of the graphic to display the context menu.


    X3D Graphic - Context Menu

  5. Select one of these options from the context menu:
    • Search: Searches configured text in the X3DConfig.json file.
    • Focus: Displays the image focused on and hides the other elements.
    • Hide: Hides the element.
    When you select the Focus or Hide option, any hidden elements are listed in the Hidden Elements pane.


    Hidden Elements Pane

    Click the Hidden Items icon to display/hide the pane.
  6. To redisplay any hidden elements, left-click the part ID in the Hidden Elements pane.
    The hidden element reappears in the graphic displayed in the Graphic pane.
