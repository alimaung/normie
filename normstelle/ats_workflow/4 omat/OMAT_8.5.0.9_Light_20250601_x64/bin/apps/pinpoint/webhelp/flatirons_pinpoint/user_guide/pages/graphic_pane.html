Graphics Pane

The Graphics pane shows illustrations selected in the Content pane. Illustrations in the text are represented by links, and when clicking on these, the user interface automatically changes to a Content/Graphics split view.



Graphics pane

From the Graphics pane, click the Figure List icon to view the Figures list. The list contains all of the figures in the currently selected document. The list view is the default view. For example:


Figures List - List View

If the selected document is a wiring publication (WDM, AWM, SSM, ASM), the Figures list includes the Page Number. For example:


Figures List - Wiring Publication

ASM and SSM publications can also have a Scheme. For example:


Figures List - ASM Wiring Publication

From the Figures list, click the option to switch to a gallery view of the figures. For example:


Figures List - Gallery View

Click the option to return to a list of the figures.
