Navigate Search Results in the Equipment Tab

The Equipment tab search results reveals information about components.

  1. Perform an Equipment search as described in Search Equipment Lists.
    The search results appear in the Equipment tab.


    Equipment Search Result

    From the Search Results area, click the Print Search Results icon to print the search results in PDF format.

  2. Click on a row in the search result to access more information about the entry.
    The row is highlighted and expanded so that you can see detailed information about the entry.


    Equipment Search Result Expanded

    Note: The information categories available on the search results page vary depending on the type of search.
    Note: With an entry highlighted in the Equipment search result, you can open the Electrical Path tab and trigger a electrical path search for the equipment. If a result for another entry is already present in the Electrical Path tab, you will be asked if you want to start a new electrical path with the selected entry. Refer to Navigate Search Results in the Electrical Path Tab for instructions to electrical path search navigation.
  3. Use the search results in the Equipment tab as desired.

    Refer to the table below for some possible types of displayed information:

    Table 1. Search Results Equipment Tab
    Identifier Description Action
    EIN/FIN Functional identification number or equipment identification number. Shows connecting data for the selected component in the Hookup search results tab. For details about how to navigate it, refer to Navigate Search Results in the Hookup Tab.
    FUNCTIONAL DESIGNATION Name of the component. Click to expand the row and reveal more information. Listed underneath are various properties of that wire. The type of information available depends on the publication.
      Location Numerical designation of where the component is located. N/A
      Quantity Number used. N/A
      Diagram/Illustration Ref. Wiring diagram link. Opens the selected wiring diagram in the Graphic pane. In SVG diagrams FIN/EIN may also be highlighted to make it easier to locate.
      PN/SN Part number or serial number. Opens ESPM and/or IPC publication. If a reference cannot be found for the clicked PN or SN, then a dialog appears to inform you of this fact.
      Drawing Drawing number. N/A
      Vendor Numerical designation of the company who sold the component. N/A
      Airline PN Shows an Alternate Part Number (ALPRTNBR) N/A
      Equivalent PN Shows an Equivalent Part Number (EQUIVPNR) N/A
    FILTER Effectivity/Applicability filter number N/A
