Perform a Full Text Search

Full Text Search is a quick way to find sets of words or phrases in publications, including any supported attachments with machine readable text data. For some publications, it also offers the ability to find FINs and part numbers. Refer to Full Text Search Pane. When performing a Full Text Search, you can search a selected library/publication or search all libraries. You can also search in metadata fields for manuals that have metadata.
Note: If the publication has metadata, a configuration controls whether the metadata filtering fields are shown or hidden. If the fields are hidden, you can select the + (plus) next to the Metadata filtering area to display those fields.
Text data in vector graphics is also searchable for some ATA publications.
Note: Only ATA manuals support vector graphic search. These manuals must contain a vector graphic index, which is generated by Knowledge Center a. If you are searching within certain supported ATA publications in which Pinpoint can search graphic text, the search returns hits in vector graphics. Clicking on graphic references in the search results will open the Graphic Pane directly.

If the Part option was activated for the search, Pinpoint navigates to the first part. Every time a new part is selected, there is a part pop-up with the defined part number highlighted.

Starting a Full Text Search

You can start a Full Text Search search either from the in the header bar or from the Full Text Search pane directly. If you start the search from the header bar, enter the text you want to search on. After you enter or select text and press Enter, you will be directed to the Full Text Search pane, where you can view the search results and optionally add more search parameters.

If the Predictive Search with Autocomplete feature is enabled, a drop-down list appears with keyword suggestions based on the search history, common misspellings, synonyms, and abbreviations. Select a keyword and press Enter.
Note: If the beginning of your input matches the most relevant suggestion, that suggestion is filled in automatically.
You will be directed to the Full Text Search pane, where you can view the search results and optionally add more search parameters.
  • You can use keyboard shortcuts to search more effectively. When the most relevant suggestion is filled in automatically, click the right arrow to config that selection. Use the tab key and up/down arrows to navigate between suggestions in the list.

You can also select Advanced from the Search bar drop-down menu to go directly to the Full Text Search pane.

The placeholder text in the Search bar corresponds to the type of search you are currently doing. For example, if you are searching a library, the text "Search the Library" is shown in the Search bar.

If your administrator has enabled the Can access current revisions only privilege, publications that are not current do not appear in the search results. You must update to the latest revision before these publications are available. Refer to Library Pane for more information.

Do these steps:

  1. Select one of these options:
    1. Do not select a library or publication to search all libraries.
    2. Select a library to search all publications in that library.
    3. Select a publication you want to search in from the library.
    Note: If you selected a library or publication to search, you can click outside the tree structure to deselect it. After you clear the selection, the search is across all libraries. The Library field in the Full Text Search pane changes to ALL.
  2. Begin your search by selecting one of these options:
    • Open Full Text Search.
    • Enter the text you want to search for in the Search bar in the Action Bar, and press Enter.

    If you started your search from the Search bar, the search results are available in the Full Text Search pane. You can optionally add more search parameters.

    Note: If you open the Full Text Search pane without selecting a library for the search, the search defaults to ALL libraries.

  3. When starting a search from the Full Text Search pane, type a keyword or phrase in the Text field.
    Previously entered keywords in the Text field are remembered and appear when you start typing.

    The “*” wildcard can be used to replace 0 or more characters. For example, to search for test, tests or tester, you can use the search:

    test*
  4. Optional: Limit the search by filling in the additional available fields. For a description of these fields, refer to Full Text Search Pane.
  5. Click the Search button (or press the Enter key) to start the search.
    A loading icon appears while the search results load for the selected library. The fields in the Full Text Search pane are grayed out while the results load. The icon disappears when the loading is complete, and the Library field shows the current library.

    When you switch libraries, a loading icon displays while the new library loads. The icon disappears when the loading is complete, and the Library field shows the new library.

  6. Click the appropriate document in Search Results to open the document in the Content pane.

A loading indicator appears before the returned results are displayed in the Search Results pane (located just below the Full Text Search pane). The total number of documents returned are stated in the parenthesis to the right of the Search Results header. For example: "(639 results found)".

This list includes publications that match the search criteria. The documents with most hits are placed in the top of the result list. When you perform a search on all libraries, the search results include all libraries and publications, including Tech Ops publications.
Note: When searching a document that has metadata, the search results may include hits in the metadata that do not exist in the document. Since the search text is in the metadata only, the document will not show the search text when viewing it in the Content pane.
The number of hits per document is displayed in the rightmost Score column. The information available in the other columns varies depending on the type of document. For example, documents that came from an ATA data module can have a Code listed, but attachments do not have a Code.
The Type column in search results contain icons which indicate the type of resource (PDF, Data Module or Graphic). When selecting a graphic search result the search terms will auto-populate the Content Pane Search and highlight the hits in Yellow. The search term will also auto-populate the Graphic Pane Search and display the matched terms in the graphic in Red.
Note: Graphic Search supports only SVG images and search results are relevant to the latest version of the manual.
Note: SVG images uploaded to a DM in authoring mode are also included in the search result.


Full Text Search Results

From the Search Results area, click the and the Print Search Results Page icon, and the Print All Search Results icon show to print the search results in PDF format.

The Print Search Results Page icon allows you to print the search results from the page that is showing.

The Print All Search Results icon allows you to print all the search results pages.

If there are more than 10 documents returned, the list will be paginated. You can navigate between the pages using the number buttons located above and below the result list. Alternatively, you can type the page number directly in the Page field. You can also select how many results to display per page: 10 (default), 20 or 50.



Pane Number Buttons

Note: When you search across all libraries, the search results are not paginated. By default, the results display the top 100 results from the combined results of each configured data source. You can customize the result count that displays. Refer to "Configuring the Result Count for Searching All Libraries" in the Flatirons Pinpoint Configuration Guide.

When clicking on a returned document, the Content pane displays the part of the document containing the first occurrence of the search word. Search words are highlighted, and you navigate between the search hits by clicking on the Next/Previous (down/up arrow) buttons in the Content pane toolbar.

Searching in a Symbolic Link Publication

When you perform a Full Text Search on a single symbolic link publication, the process is the same as a search on other publications. You click a search result, and the publication opens in the Content pane.

There are some differences when performing a search on multiple symbolic link publications:
  • Search with multiple symbolic link publications (same library)
    Select the library and perform a Full Text Search. The search results appear in a single record. When you select the record, the Select Publication dialog appears. You must select the publication to open. For example:

    Enter text in the Search field in the Action Bar to search for in the symbolic link publications. The search results appear in a single record. When you select the record, the Select Publication dialog appears. You must select the publication to open. For example:
