Search Attachments

The Attachments search dialog allows searching several different categories of attachments, such as supplements and temporary revisions. You can reset this form by clicking the Reset button.
Note: As an alternative, you can also search textual content of attachments using Full Text Search. Refer to Full Text Search Options.
If your administrator has enabled the Can access current revisions only privilege, publications that are not current do not appear in the search results. You must update to the latest revision before these publications are available. Refer to Library Pane for more information.
Note: When you perform an attachments search on a symbolic link publication, the information displayed is for the original (target) publication.

To search attachments, do these steps:

  1. Select the Library you want to search in from the Library pane.
    The search page can be opened either in the context of a single publication, symbolic link publication, or a library. If opened on the library level, it will search across all publications in that library.
    Note: By default, all publications in the library are selected in the Publications drop-down list.
  2. Click the header below the Table of Content pane.
    The Annotations / Supplemental Contents search dialog search pane expands.
  3. Click the Attachments tab.
    The Attachments search dialog appears.


    Attachments Search Dialog

    Note: If there are attachments, a supplemental icon may appear to the right of the Annotations / Supplemental Contents header title. Refer to View Attachment.
  4. Optional: In the Search field, type keywords that the textual content of the attachment must contain.
  5. Optional: To view the fields described in the next steps, click the Advanced Search hyperlink.
  6. Optional: From the SELECT PUBLICATIONS drop-down menu, activate checkboxes of whichever publications you want to search and deactivate checkboxes of whichever publications you want to omit.
    By default, the currently selected publication in the Library pane are activated.
    Note: You must select a minimum of one publication.
  7. Optional: From the CATEGORIES drop-down menu, activate checkboxes for the specific categories you want to return in search results.
  8. Optional: From the ALERT TYPE drop-down menu, activate checkboxes for the importance types you want to return.
  9. Optional: With the NOTIFY FROM DATE and NOTIFY TO DATE fields, select an inclusive range of desired notification dates. For each date field, click the select date icon to select a date from a calendar widget.
    The search results will only include attachments that have a notify date that equals or occurs after the NOTIFY FROM DATE, as well as equals or occurs before the NOTIFY TO DATE. To only show attachments with a specific date, select the same date for both fields.
    Note: If you keep the NOTIFY FROM DATE field empty, there is no restriction on the lower limit of the date range. Similarly, if you keep the NOTIFY TO DATE field empty, there is no restriction on the upper limit of the date range.
  10. Optional: To only show attachments with unresolved revision conflicts, activate the Only Show Conflicts checkbox.
  11. Click the Search button.
    The Search Results pane appears below the Attachments search form.


    Attachments Search Results

  12. Click an attachment item to display the document associated with it in the Content pane.
    If you perform a search with multiple symbolic links in the same library, the original (target) publication and the multiple symbolic link publications display in a single record. When you select the record, the Select Publication dialog appears. You must select the publication to open. For example:


    Select Publication Dialog - Attachments

The corresponding publication and document are also selected and display in the Library and Table of Content panes respectively.

If you have all permissions enabled for Can Upload Supplement, you may see "Attachment is in conflict" icons. An attachment with this icon was made in a previous revision and it is possible that it contradicts the updated information in the latest revision. Refer to Migrate Attachments.

You can use the Attachments pane to manage attachments. Refer to Attachments Pane.
