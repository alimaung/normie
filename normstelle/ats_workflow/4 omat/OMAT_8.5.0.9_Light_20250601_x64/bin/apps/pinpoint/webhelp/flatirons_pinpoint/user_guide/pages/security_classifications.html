Security Classifications

Security classifications is a banner that shows in the same location as the supplements and temporary revisions banners. The language displayed in the security banner is defined by a mapping of data module language codes to a specific language in the style kit. The style kit is selected when setting up a publish activity. Therefore the security banner language displayed in the banner is not dependent on a language selected by the end user of Pinpoint. Selecting French does not impact the language shown in the security banner. Refer to the example below:


Security Classifications Banner

The color of the classification banner is configurable by an administrator, refer to the "Configure the Security Classifications" in the Flatirons Pinpoint Configuration Guide.
Note: The security classification is limited to S1000D 4x only.
The classifications banner can be configured for different languages and different security levels, refer to the "S1000D Publish Builders" in the Flatirons Data Manager User Guide.
