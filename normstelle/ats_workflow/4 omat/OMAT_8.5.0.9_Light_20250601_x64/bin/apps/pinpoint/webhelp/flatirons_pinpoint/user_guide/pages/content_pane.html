Content Pane

The Content pane displays the document selected in the Table of Content.

Note: PDF documents do not appear in the Table of Content. When selected in the Library the PDF will be displayed directly embedded in the Content pane. Pinpoint provides embedded PDFJS for Chrome and Firefox and no PDF Viewer plug-in is required to view documents. Internet Explorer requires Acrobat Reader. Refer to Navigating PDF Documents.
Note: Users might not be able to successfully load large PDF manuals in a 32 bit Windows machine with the use of browsers like Chrome, Edge, etc.. Internet Explorer shipped along with the Windows OS would be able to load large PDF documents without a problem but with a performance overhead.

Links to Split Large Fragments

The larger fragments are split into parts so that they load quickly in the Pinpoint viewer. You can access the split parts using the hyperlinks provided. This applies to large tables, page blocks of AMM and fault chapters of TSM as well.

To view the split large fragments, follow these steps:
  1. Split content are available as nodes under Table of Content.
  2. Click on a node to view it in content pane.
  3. Click on the link "Continue to .. -Part X" at the bottom, to view the next part from within the content pane.


  4. Click on the link "Continuation from.. -Part X" at the top, to view the previous part from within the content pane.

To view the split large tables, follow these steps:
  1. When large tables are split, the table content is replaced by an hyperlink named “Click here to see table body”.

  2. Click the link to view the table with contents split in its own fragment.
  3. Click the link “Continue to…Table Part X” to view the next part of the table.
  4. Click the link “Continue from…Table Part 1” to view the previous part of the table.

  5. Click the link "Source Fragment" on top of the table content to return to original content.

To view split page block in AMM Manuals, follow these steps:
  1. Click open a fragment of AMM from Table of Content.
  2. Click the link available within the content pane to view the split content.​

  3. Click the link “Continue from… Part X” at the top of content pane to view the previous part.

To view split fault chapter in TSM Manuals, follow these steps:
  1. Click any split chapter in a TSM to view the list of links of the split content in content pane,
  2. Click any link from the list to view the content.

  3. Click on the link "Continue to .. -Part X" at the bottom, to view the next part from within the content pane.

  4. Click on the link "Continuation from.. -Part X" at the top, to view the previous part from within the content pane.

Multimedia Links

How multimedia links in the content are handled depends on the format:

  • Clicking on a multimedia link that points to .ppt, .xls, .doc, .mkv, .3gp will open a new tab and let the user download the file.
  • Clicking on a multimedia link that points to a PDF will open the PDF in a new Content tab.
Tip: Press F8 to display the PDF toolbar.
  • Clicking on a multimedia link that points to a supported 3D format, like VRML, it will open the 3D in the Graphic pane. If you are using Internet Explorer or Chrome the VRML graphic can be viewed without any third party plugin. If other browsers are used you will need to install CORTONA 3D Viewer plugin on the client computer. For more details, refer to Viewing SIMIC/VRML 3D Graphics.
  • In the graphic list in the graphic pane, only images and 3D objects will be shown, as these are the only ones that are displayed in the graphic pane.

Container Data Modules

S1000D documents may reference container data modules which again can contain multiple references to data modules with different applicability. How container data modules are handled in Pinpoint depends on the data. In an A350 publication, if there is only one applicable document in the container, you will be routed directly to this. If there are several applicable documents, Pinpoint will open the container instead. In non-A350 data types, the container will always be displayed.

Process Data Modules

The Process Data Module contains interactive processing structures to provide the capability to sequence other data modules or steps within it. The sequencing is based on dynamic or static state information and is handled by a software component called Logic Engine.

The Logic Engine currently supports these controls in the dialog box:
  • Text input box
  • Push button
  • Submit
  • Cancel
  • Radio button
Note: The Process Data Module does not send inputs to or receive inputs from other external applications.

For example:

  • Click the Next button in the data module to navigate to the next node.

  • Enter your details in the text input boxes.
  • Select the menu choice (in this example, Yes or No).
    Note: The menu choice is usually presented as a radio button.
  • Click the Submit button.
    Note: Click the Cancel button to clear the entry and return to the previous page.

The information you enter in the dialog determines the content that appears after you click the Submit button.

  • The sequence continues to execute until you select the right answer. You can then continue to the next node, if available.

  • If you select a wrong answer, the number of wrong answers is incremented. The sequence repeats until you select the right answer.

  • The last node in the sequence will only have the Previous button.

dmRef Link in Process Data Modules

When you click a dmRef link in a Process Data Module, it opens in a new tab.
