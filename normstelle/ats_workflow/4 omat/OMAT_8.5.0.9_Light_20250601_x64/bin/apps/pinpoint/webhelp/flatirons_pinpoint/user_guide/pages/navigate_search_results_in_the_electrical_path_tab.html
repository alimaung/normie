Navigate Search Results in the Electrical Path Tab

  1. Perform an electrical path search as described in Search Electrical Paths.
    The search results are displayed in the Electrical Path tab below the search fields.
  2. If the Click on one Pin ..... to continue the Electrical Path dialog appears, click the OK button.
    This dialog indicates that the electrical path being shown has a component with multiple pins that the signal can travel from.

    The search results appear in the Electrical Path tab.



    Electrical Path Tab

    From the Search Results area, click the Print Search Results icon to print the search results in PDF format.

  3. Use the search results in the Electrical Path tab as desired.

    Refer to the table below for some possible types of displayed information:

    Table 1. Search Results Electrical Path Tab
    Identifier Description Action
    Electrical Path    
      ...... Indicates that the electrical path may continue beyond what is currently shown. If the electrical path continues beyond what is shown, clicking on ...... reveals the next connection in the electrical path. Otherwise, ...... simply disappears to signify that the electrical path ends at the component shown.
      Boxed FIN/EIN Represents a component. Sometimes the symbol is displayed to the left of the FIN/EIN. Shows information for the selected component in the Equipment tab.
      hyperlinked pin designator... Represents a component pin that the signal can travel from. Reveals the next link in the electrical path when the signal travels from that particular pin.
      Regular text pin designator below component For the currently displayed electrical path, represents the pin of the component above it that the signal travels from. N/A
      Regular text pin designator above component For the currently displayed electrical path, represents the pin of the component below it that the signal travels to. N/A
    Pin    
      Pin designator Pin designator. N/A
      ...... Indicates that the component has pins. Reveals/hides additional pins for a component that are not part of the electrical path being shown.
    Equipment Wire    
      For boxed FIN/EIN Functional identification number or equipment identification number. Shows information for the selected component in the Equipment tab.
      For pin designator Wire number. Sometimes the wire color is shown to the right of the wire number as a highlighted first letter of a color name. (For example: indicates the wire is red and indicates the wire is blue.) Shows information for the selected wire on the Wires tab.
    Technical Data    
      For boxed FIN/EIN Name of the component. N/A
      For hyperlinked pin designator... Wiring diagram. Opens the selected wiring diagram. In SVG diagrams your selection may also be highlighted to make it easier to locate.
      For regular text pin designator Type of wire, measurement of how large the wire is, and the length of the wire. Opens the selected wiring diagram. In addition, your selection may also be highlighted in the diagram to make it easier to locate.
