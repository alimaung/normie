Rollback a Publication Revision

Not applicable for Pinpoint Standalone Light.

The rollback functionality is only available for publications that are published as draft versions to Pinpoint. A user with the appropriate privileges can reject the draft by clicking the rollback button in the header bar. This means that the draft revision is removed from Pinpoint and Data Manager. Alternatively, the user can release the revision to the user groups that are able to read the publication, as described in the previous section.

Note: The user responsible for the review must be a member of a user group that has Read permission to the Can release or rollback draft revisions resource in Access Control.

To release a publication revision, do these steps:

  1. Log in to Pinpoint and navigate to the library that has the draft version you want to rollback.
  2. Select the draft revision.
  3. From the Publication Operations menu, select the option.
    Tip: If you do not see this menu option, you may not have the appropriate permissions.
    The publication revision draft is removed from Pinpoint and Data Manager. The publication revision resource is also removed from the privilege tree in Access Control.
