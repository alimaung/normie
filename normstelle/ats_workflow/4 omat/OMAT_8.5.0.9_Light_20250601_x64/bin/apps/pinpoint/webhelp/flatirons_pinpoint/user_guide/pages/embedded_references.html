Embedded References

Note: Your administrator must assign Read permission for the Can view embedded reference privilege to allow you to view embedded references in publications. To disable the ability to view embedded references, remove the permission.
Note: Administrators: You must disable the mouse-over preview of references if you are using the embedded references feature. Refer to the "Enable Mouse-over Preview of DM /CSN References" topic in the Flatirons Pinpoint Configuration Guide.

Embedded references allow you to open a reference in a container frame within the original content you are viewing in the Content pane. This feature can be enabled/disabled for all builders or selected builders. Refer to the topic "Enabling/Disabling Embedded References for Builders and Specific Publications" in the Flatirons Pinpoint Configuration Guide.

Supported Functionality

When working with embedded references, you should be aware of the functionality supported by the feature:
  • Only these types of links will work:
    • library to library
    • builder to builder
    • HTML to HTML
  • You must click the Show Reference icon to expand the reference.
    Note: Clicking on the reference link directly has the same current behavior and directs you to that reference.
  • You cannot create, edit, or delete Annotations or Supplements in an embedded reference.
  • The graphics list does not include graphics within an embedded reference.
  • If you enable embedded references, the hover over reference feature is disabled.
  • There is no limit to the number of references that you can open. However, performance will degrade as the number of opened embedded references is increased.
  • In ATA, data page block links will work as they currently do. There is no additional functionality for page blocks within embedded references.
  • For content that contains its own references link inside, those self references are not supported for viewing or printing.
  • Cross references between publication or data module types are supported for iSpec2200 and S1000D only. This functionality is available within the specific builder. Builder to builder cross references are not supported.
    • Supported publication types for iSpec2200: EM, OMAT, SDS, SPM, TLM, TSD
    • Supported data module types for S1000D (spec 3.x, 4.x, 2.3): descript, proced, frontmatter, crew, sb, schedul
    • Not supported: IPD, fault DMs

Supported Builders/Publication Types

The display of embedded references is supported in these builders and publication or data module types:
  • A350: AMM, SRM, NTM, TSM
  • C-Series: AMM, ANDTP, ASRP
  • iSpec2200: EM, OMAT, SDS, SPM, TLM, TSD
  • KCA: AMM, EM, ESM, SPM, SM, CIR
  • Pratt & Whitney: CIRM, EMAN, EMM, FIM
  • S1000D: Compatibility for spec 3.x, 4.x, 2.3 - descript, proced, frontmatter, crew, sb, schedul
  • XWB: CIRM, CREP, EMAN, SETM
Note: Procedure publications do not support embedded references.
Note: Reference to external links is not supported for KCA.
