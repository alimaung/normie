Hyperlinks in SVG Graphics

In SVG graphics, for example wiring diagrams, there can be links that allows you to trigger a new equipment search or to open another diagram. SVGs can also have hotspot that links to the parts list in the Content section. You can identify links by hovering the mouse pointer over the text in the diagram. If the cursor symbol changes from a cursor pan symbol to a cursor pointer you are dealing with a link.

Depending on the type object you will trigger different actions when double-clicking the links.

  1. View a SVG graphic, for example a wiring diagram.
  2. In the SVG graphic, double-click a hyperlink.
    • If the link is an EIN/FIN, the Wiring Search pane opens with the EIN/FIN code inserted in the appropriate search field.
      Note: If a previous equipment search has been performed, you will need to confirm that you want to start a new search in a pop-up dialog.
    • If the link is a another diagram, you will be asked to select the target publication.
    • If the link is a position number with a link to a parts list, the application will automatically scroll to and highlight the appropriate number in the Content section. This feature is available in ATA AIPC and A350 AIPC.
