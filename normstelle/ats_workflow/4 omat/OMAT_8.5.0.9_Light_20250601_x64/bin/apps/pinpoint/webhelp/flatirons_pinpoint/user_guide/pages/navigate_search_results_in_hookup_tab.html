Navigate Search Results in the Hookup Tab

The Hookup tab search results reveals the wires hooked up to a selected component.

Perform an Hookup search as described in Search Hookup Lists.
The search results are displayed in the Hookup tab below the search fields. Refer to the following table for some possible types of displayed information:
Note: The information categories available on the search results page vary depending on the type of search.
Table 1. Search Results Hookup Tab
Identifier Description Action
PIN Pin number N/A
BUNDLE Bundle number Click on the link to open the bundle in the Wire tab.
WIRE Wire number Click on the link to open the wire in Wire tab.
DIAGRAM Wiring diagram Click on the link to open the wiring diagram in the Graphic pane. In SVG diagrams your selection may also be highlighted to make it easier to locate.
TT Terminal Type Code.
Note: This is optional information for Boeing Data and it is not applicable to Airbus Data. In a Boeing WDM Wire List / Technical Data, if the component (EIN) is a Terminal Block, this TT would be present if an applicable value data is provided by Boeing.
 N/A
Gauge. Route

Gauge: Measurement of how large the wire is.

Route: The route for the wire.

 N/A
Filter Applicability/effectivity information N/A
