Manage Restricted Links

Not applicable for Pinpoint Standalone/Pinpoint Standalone Light.

After creating restricted links, an admin user with permissions for the Can create or remove restricted links privilege can manage the links. This privilege allows the admin user to perform these functions:
  • Perform a full text search
  • Copy restricted links
  • Open restricted links in a new tab
  • Delete restricted links
You must set Delete permissions for the Can create or remove restricted links privilege to allow end users to remove restricted links. Refer to Flatirons Access Control Manager User Guide for permission details.

To manage restricted links, do these steps:

  1. Select the Restricted Link Management icon in the Action Bar.

  2. Select one of these options:
    • Enter a keyword in the Search field, and click Search to perform a full text search.

    • Click the Copy to clipboard icon to copy the restricted link.

      You can send the copied restricted links to users who have the privilege to view the links.

    • Click the Open in a new tab icon to open the restricted link in a new tab.

      You can open the selected links in a new tab.

    • Select one or more restricted links, and click Remove to delete the restricted link(s).

      A success message displays, and the selected link(s) are deleted.
