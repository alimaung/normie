Permissions for the Viewer

Permissions for features in Pinpoint are set in Access Control. The Access Control administrator grants permissions to the different user roles that can access functions in Pinpoint. The administrator grants permissions to user groups, which allows members of a group access to the data. This data access includes libraries, their publications, and revisions.

For more details on how to grant permissions to user roles and user groups, refer to the "Manage Function Privileges and Data Access Permissions" topic in the Flatirons Access Control Module User Guide. Refer to the "Permissions for Pinpoint Viewer" topic in the Flatirons Access Control Module User Guide for permissions available for Pinpoint. You can open this guide by clicking the button in the Access Control application Header Bar.
