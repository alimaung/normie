Copy Pinpoint GOTO Link

For Pinpoint documents, copying the link from the Internet browser’s address bar will not work properly for viewing the same content later. Instead, you should use the built-in Link to Content feature.

The URL that is copied with this feature can include the current applicability/effectivity filter, search terms, and more. For details on the GOTO URL format and specification, refer to Flatirons Pinpoint Configuration Guide, "GOTO URL Format and Specification".
Note: This feature is not available for HTML publications.

If an administrator has enabled the "Can access current revisions only" privilege for your user role, publications that are not current cannot be accessed using the GOTO feature. You must select the latest revision before these publications are available. Refer to Library Pane.

To copy a Pinpoint GOTO link, do these steps:

  1. Navigate to the document in Pinpoint that contains the link you want to copy.
  2. Open the URL dialog:
    Option Description
    Mouse method In the Content pane header bar, click the Link to Content icon.
    Keyboard shortcut method Press Ctrl+Alt+C.
    The URL dialog shows the GOTO link to this document. By default, the link contains IDs as the parameters with the Use IDs toggle button selected in cyan.
  3. Select one of these toggle buttons:
    Toggle Button Description
    Use Ids This is the default option in which the ID will be generated when the publication is created. This option continues to work even if the publication or any of its parents are renamed. However, if you use multiple Pinpoint environments, it will not work across them because they will have different generated IDs.


    URL Dialog - Use IDs Selected
    Use Path This option uses the publication path as the parameter. This option works regardless of the Pinpoint environment as long as the publication is located in the same path. However, the path will no longer be valid if you rename the publication or any of its parents.


    URL Dialog - Use Path Selected
    Copy Link This option allows the user to paste the link into another location. The format of the link defaults to the same as the Show Revision format which includes revision and title.

    The toggle button you selected is highlighted in cyan.

  4. Set the Show Revision checkbox:
    Option Description
    Leave the Show Revision checkbox empty Use this option to link to the latest document publication. If the document you are viewing is revised, the link you copied will show the latest revision instead of the exact content you saw when you first copied the link.
    Activate the Show Revision checkbox Use this option to link to the specific publication revision that you are currently viewing. When the link is clicked by users with permission to see older revisions, the content you see now will be the exact content that will be shown when the link is clicked, even if the publication is later updated.
  5. Copy the URL:
    Option Description
    Button method In most cases, you can automatically copy the shown URL to the clipboard by simply clicking the Copy button.
    Highlight method For some Internet browser configurations, Pinpoint may not have proper permissions to update the clipboard automatically. If you notice that the URL is not copied properly when you click the Copy button, you can instead copy the link from the URL dialog box in the same way you copy normal text. For example, highlight the link in the dialog and press Ctrl+C.

The URL is copied to the clipboard.

You can paste the URL wherever needed. For example:
  • You can send the URL in an email.
  • When authoring a job card in Insight, you can copy paste the GOTO Link into the Pinpoint reference field on the job card. Refer to the Flatirons Insight User Guide.
Note: When you copy a URL for a symbolic link publication, the original (target) publication opens when you paste the URL into a browser.

If somebody that is not already logged into Pinpoint clicks on a GOTO link, that person will be directed to the Pinpoint login page (refer to Log In). After logging in, the user will be redirected to the correct document location that was setup by the GOTO link feature.
