Shopping Basket - Parts Ordering

The parts ordering shopping basket feature allows you to select and order parts through a third-party application.

Note: Administrators, this feature must be enabled. Refer to the topic Enabling the Part Order Shopping Basket in the Flatirons Pinpoint Configuration Guide.
To order parts, do these steps:
  1. From the Library pane, select a folder.

    Publications that belong to the selected folder appear under the folder name.

  2. Select a publication.

    The publication displays in the Content pane.

  3. Select the Shopping Basket icon below the part you want to order.

    The third-party application configured for your organization appears.

  4. Verify the information in the application. For example, you may want to verify these items:
    • Part Number
    • MFG cage code
    • Part Description
    • Other items as determined by your organization
  5. Submit your order.
Note: You must complete these steps for each part you want to order.
