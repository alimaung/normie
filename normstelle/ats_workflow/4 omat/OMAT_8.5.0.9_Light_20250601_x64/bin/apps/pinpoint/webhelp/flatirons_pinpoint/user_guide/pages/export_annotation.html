Export and Import Annotations

Annotations can be exported and imported in Pinpoint. While this functionality is applicable for Pinpoint Viewer and Pinpoint Standalone Light, it is mostly used for Pinpoint Standalone. It applies to the following scenario:

  1. The end-user receives a Pinpoint Standalone with data (version 1).
  2. The end-user creates annotations in this version.
  3. The end-user receives a new Pinpoint Standalone with updated data (version 2).
  4. The end-user wants to transfer annotations from version 1 to version 2.

To transfer annotations from one standalone version to another, do the steps that follow:

  1. Start and log in to the first version of Pinpoint Standalone.
  2. In the Action Bar, click the More button.

    More Drop-down menu

  3. Select Export Annotations.

    Pinpoint will now create a file with the name "annotations.json". How this is downloaded depends on the browser. In Internet Explorer you will be asked if you want to save or open the file.

  4. Save the file in the appropriate location.
  5. Start and log in to the latest received version of Pinpoint.
  6. From the More drop-down menu, select Import Annotations.
  7. In the file browser, find and select the "annotations.json" file created from the first version.
    A confirmation dialog appears:

  8. Verify that all annotations have been imported correctly into the new standalone version.
