Search Wire Lists

Wire is a search type in Wiring Search. For more details, refer to Wiring Search Pane.

You can perform a harness/bundle search for C-Series data through a wire search. This feature is available when you enter an exact harness/bundle number in the Bundle field.

  1. Open a Wiring publication in the Library pane.
  2. Open the Wiring Search.
  3. From the Search Types drop-down menu, select Wire.
  4. Do one of these choices:
    1. Enter a full or partial component number in the BUNDLE field.
      Note: You must enter an exact harness/bundle number for a C-Series harness/bundle search.
    2. Enter a full or partial part number in the WIRE field.
  5. (Boeing only) If applicable, click the Spare Wire button to limit the search to Spare Wires.
  6. Click on the Search button, or the keyboard Enter button, to start the search. If you need to clear the filter and start over, click the Reset button.
    Your search results appear in the Search Results Wire tab. If there are multiple entries in the result you will see a tip about selecting one of the entries to see more information. For details on navigating the results, refer to Navigate Search Results in the Wire Tab.
    For C-Series harness/bundle searches:
    • If there are multiple harness/bundle records, each field of the record displays the merged field values.
    • In the results, the first part shown is the harness/bundle records. The second part is the wire records where the harness/bundle number has been used. Only the harness/bundle record displays if there are no wire records.
