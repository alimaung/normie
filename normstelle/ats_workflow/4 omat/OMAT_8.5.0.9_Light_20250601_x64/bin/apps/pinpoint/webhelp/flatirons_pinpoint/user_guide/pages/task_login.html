Log In

For security reasons, when initially starting the application, the person using the browser is required to log in. Also, after periods of inactivity, the user is required to log in to the browser.
Note: If the application is configured to allow guest access, you can access the public, guest-accessible Pinpoint content without being required to log in.
Note: For new username and password assistance, contact your supervisor or administrator.

Do these steps:

  1. Open your Internet browser to the URL provided by your supervisor or administrator.
    The login page appears.
    Note: The first graphic below shows the standard login page. It will look different if the application has been integrated with SAML. The second graphic shows the login page when guest access is enabled.


    Login Page

    Login Page with Guest Access (Not Applicable for Pinpoint Standalone Light)

  2. Do one of these choices:
    1. Enter your Username and Password, and click the LOG IN button.
      Note: If you want to check the spelling of the password, select the Show Password check box.
    2. Not applicable for Pinpoint Standalone Light. Click the CONTINUE AS GUEST button.
      If the environment also allows authenticated users, you can select from the More drop-down menu to log out of the public environment and display the Access Control login page.
  3. Optional. Select a language (English or French) from the CHOOSE LANGUAGE drop-down menu.
    Note: You can also select the language in the Action Bar in Pinpoint.
  4. If an End User License Agreement (EULA) dialog pops up, read the content and click I Agree to continue. If you do not agree, you will not be able to access the application.
    Note: If the Must see EULA at every login permission is configured to be shown, users with Read permission will see the EULA at every log in. If this option is not configured, the EULA displays only for the first log in.
    These are scenarios for EULA display:
    • Pinpoint Server: EULA appears when a user first logs in, when changing to a different library, or when refreshing the page.
    • Pinpoint Standalone: EULA appears when a user first logs in, when changing to a different library, or when refreshing the page.
      • If another user accesses the same library, EULA only appears if the previous user logged out.
      • If another user accesses a different library, EULA appears even if the previous user did not log out.
    • Pinpoint Standalone Light: EULA appears when a user logs in and also when changing to a different library.
    • Pinpoint Standalone Light (Create for DVD): EULA appears when a user logs in and also when changing to a different library.

The application opens, showing the landing page in the Content pane. In the default configuration, the landing page is the Flatirons Logo, as shown in the graphic below, but this is configurable. Refer to Configuration Pane for information about changing the landing page.
