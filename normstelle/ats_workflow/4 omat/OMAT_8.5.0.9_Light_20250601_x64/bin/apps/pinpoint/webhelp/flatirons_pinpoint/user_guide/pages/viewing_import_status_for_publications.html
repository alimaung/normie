Viewing Import Status for Publications

Not applicable for Pinpoint Standalone Light.

Note: This procedure assumes that you have been granted read or write privileges for viewing import publication statuses in ACM. If you do not have privileges, the Import Overview icon does not appear.
Users with appropriate permissions can view and click the Import Overview icon to display a list of all publications (imported data in descending order). Revisions that you delete in Data Manager display in the list with the status for the deletion.
Note: You can select an option from the Filter Publications drop-down menu to limit the number of publications viewed.
Each record displays this information:
  • Library
  • Publication (includes System Release number)
  • Revision
  • Import Date
  • Progress
  • Status
  • Actions
Note: The status for imported Pinpoint Neutral packages is also displayed. The upload status for these packages is available only for that page. If you refresh the page or log out, the current upload status is no longer available. The status for Pinpoint Neutral packages that have been uploaded successfully is displayed at any time.

If you set the Download the Latest Revisions option in the Configuration pane to Manually, the Import Overview icon shows the number of publications available to download. These publications appear in the Import Overview dialog as Ready to Download. You can control the download process of the publications by pausing, resuming, and stopping the download.

The location and behavior of the Import Overview icon during import depends on the page width and whether an import is occurring:
  • If the page width is less than or equal to 1280 pixels, the Import Overview icon appears in the More drop-down menu. Both the More icon and the Import Overview icon blink while the import is in progress. Once the import is complete, the icons stop blinking.
  • If the page width is greater than 1280 pixels, only the Import Overview icon blinks while the import is in progress. Once the import is complete, the icon stops blinking.

To view the import publication statuses, do these steps:

  1. Click the Import Overview icon in the Action Bar.
    The Import Overview dialog appears.

    Note: The list of publication revisions is auto-refreshed in 1-minute intervals.

    If there are more than 10 documents returned, the list will be paginated. You can navigate between the pages using the number buttons located above and below the result list. Alternatively, you can type the page number directly in the Page field. You can also select how many results to display per page: 10 (default), 20 or 50.

  2. Click the Filter Publications down arrow to select the type of publications you want to view.

    By default, all publications are shown. These filtering options are available:
    • Show Completed

      Select this option to display only the latest revisions of each publication.

    • Show in Progress

      Select this option to display only publication revisions with actions (other than view logs).

    • Show Failed

      Select this option to display only publication revisions that have failed.

    • Show Ready to Download

      Select this option to display only publication revisions that are ready to download.

    • Click Select All to select all of the filtering options. Click Clear All to deselect all filters.
  3. View the list of imported publications.
    Publications currently being imported show the completed percentage in the Progress field. If an import fails, dashes (--) display in this field.

    The status of the import displays in the Status field.

  4. Optional. Click the Log icon for a publication.
    The Import Logs for the selected publication appears.
  5. Click the Restart Import icon to restart a failed import.
  6. Click the Rollback icon to rollback a publication from Data Manager.

    If you rollback a publication revision, that will restart the publication import process. You can view the process logs by clicking the Log icon for the publication.

    Note: Flatirons Solutions suggests that you not rollback publications that are importing without issues. This might lead to data corruption.
  7. Click the Start/Resume Download icon to start a download or resume a paused download.
    When you select the Start download option, the publication is added to the download queue, for example:

  8. Click the Pause Download icon to pause a download.
    When you select this option to pause the download, no further action can be taken on the download until the pause process is complete. After that process completes, you can select the Resume Download icon to resume the download.
  9. Click the Stop Download icon to stop a download.
  10. Select the Others tab to view the status for synced annotations.
    Note: This tab displays only if the logged in user has Read/Write permissions for the Can edit remote server details privilege in ACM. The information displayed in this tab is read-only.
