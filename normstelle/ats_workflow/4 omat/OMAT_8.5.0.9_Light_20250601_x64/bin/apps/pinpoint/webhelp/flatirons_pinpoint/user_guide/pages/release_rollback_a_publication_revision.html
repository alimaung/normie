Release a Publication Revision

Not applicable for Pinpoint Standalone Light.

The release functionality is only available for publications that are published as draft versions to Pinpoint. A user with the appropriate privileges can review the draft and then release it to the user groups that have access to the publication revision.

Note: The user responsible for the review must be a member of a user group that has Read permission to the Can release or rollback draft revisions resource in Access Control.

Release a Publication Revision feature is designed as a scheduler, which enables the user to control the date and time when a publication can be viewed as a released version. The user can choose to schedule the publication release either immediately or at a desired date and time in future.

To schedule a release for publication revision, do these steps:

  1. Log in to Pinpoint and navigate to the library that has the draft version you want to release.
  2. Select the draft revision.
  3. From the Publication Operations menu, select the option.
    Tip: If you do not see this menu option, you may not have the appropriate permissions.
    If it is the first revision of a publication, a Release a Publication dialog appears.

    If it is the second (or a later) revision you will not see this dialog. The application will then copy the privilege settings from the previous revision and the release will be immediate.
    Note: A user can only release to user groups within their organization.
  4. Optional. Enter a comment for the release.
    When you add a comment, you can view it by selecting the icon in the Pinpoint Viewer (Publication Metadata) and Data Manager (Release Comments).
  5. Select the schedule release type.
    • Select the option Immediately to release the publication on spot.
    • Select the option Schedule release date to plan the release in future. You can choose the desired date and time from the date picker icon.
    Note: Default selection is set to Immediately for the first time the UI is selected.
  6. Select those user groups that shall be able to view the released version and click Save.
    A dialog appears asking the user to confirm the publication revision, user groups selected and the time of release.
    Note: Users must have both Read and Write permissions for the publication in Data Manager to be able to release the publication in Pinpoint.

  7. Click OK again.
    The publication revision now becomes available for the selected user groups. The publication status in the bottom header should include the word "RELEASED" and the date of the release. Notice also that the release and rollback buttons disappear from the header bar. In Data Manager, a checkmark is inserted in the Released column within the publications Revisions table.
