Viewing X3D Graphics

Pinpoint supports rendering of X3D graphics in the Graphics pane. You can also view and perform more advanced manipulations on X3D through an X3D Landing page. Refer to Viewing X3D Graphics in X3D Landing Page for more information.
Note: Before you can view X3D graphics in an X3D Landing page, you must first configure the landing page. Refer to the Flatirons Pinpoint Configuration Guide for more information.

The steps below describe how to open and use the keyboard and mouse to rotate, move and zoom the X3D graphic. You can also use the options at the top of the Graphic Pane to manipulate the graphic. Additionally, you can right-click the graphic to perform a full text search, focus on a specific element (hiding the other elements), or hide an element.

  1. Open Pinpoint and navigate to a document that contains an X3D graphic.
  2. Click on the multimedia link to open it in the Graphic pane.


    X3D Graphic in the Graphic Pane

  3. These keyboard and mouse combinations can be used to rotate, move and zoom the graphic:
    • Rotate: Click/hold left mouse button and move the mouse in any direction.
    • Move: Alt + left mouse button and move the mouse in any direction.
    • Zoom in/out: If the mouse has a wheel, simply use the wheel to zoom in and out. If the mouse does not have a wheel, press Ctrl + left mouse button and move the mouse up to zoom out and down to zoom in.
  4. These options located at the top of the Graphic Pane can be used to manipulate the graphic:
    Table 1. Graphic Pane Options
    Option Description
    Explodes the elements in the image.
    Hidden Items Click this icon to display the Hidden Elements tab. To close the tab, click the icon again.
    Previous/Next Graphic Use these buttons to switch to the next or previous graphic.
    Minimize Graphic Click this icon to minimize the Graphics pane and give room for the Content pane.
    Maximize Graphic Click on this icon to go from 50/50 Content/Graphics to only display the Graphics.
  5. Right-click an area of the graphic to display the context menu.


    X3D Graphic - Context Menu

  6. Select one of these options from the context menu:
    • Search: Searches configured text in the X3DConfig.json file.
    • Focus: Displays the image focused on and hides the other elements.
    • Hide: Hides the element.
    When you select the Focus or Hide option, any hidden elements are listed in the Hidden Elements pane.


    Hidden Elements Pane

    Click the Hidden Items icon to display/hide the pane.
  7. To redisplay any hidden elements, left-click the part ID in the Hidden Elements pane.
    The hidden element reappears in the graphic displayed in the Graphic pane.
