Modifier la section

Non applicable pour Pinpoint Standalone Light.

Le mode de création vous permet de modifier le contenu du document sélectionné. Une fois le brouillon approuvé, le document modifié n'est disponible que pour les utilisateurs de votre organisation.

Pour modifier une section, procédez comme suit:
  1. Entrez en mode création. Faire référence à Entrer en mode de création.
  2. Dans la marge gauche du volet Contenu, cliquez sur l'icône Modifier le contenu de cette section pour la section que vous souhaitez modifier. La section sélectionnée est disponible.
    Par example:


    Onglet Création - Section ouverte pour modification

  3. Après avoir modifié une section, vous pouvez utiliser les options de la barre d'outils de création pour formater les informations, ajouter des références ou des liens graphiques et des avertissements / mises en garde / notes. Faire référence à Barre d'outils de création.
  4. Lorsque la section est terminée, sélectionnez l'une de ces options dans la barre d'outils de création:
    • Cliquez sur le bouton Enregistrer.

      Un message de réussite apparaît:

      La section contenant vos modifications est mise en surbrillance.

    • Cliquez sur le bouton Annuler pour annuler.

      Un message de confirmation apparaît:

      Cliquez sur le bouton pour supprimer les modifications..

    Après avoir enregistré ou annulé vos modifications, vous pouvez supprimer votre brouillon ou l'envoyer pour examen. Reportez-vous à Supprimer un brouillon et Envoyer les modifications pour examen pour plus de détails.
