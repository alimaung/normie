Changer de projet

Si vous avez déjà ouvert un dossier et vous souhaitez passer à un autre, suivez les étapes ci-dessous:

  1. Cliquez le dossier que vous souhaitez ouvrir dans la fenêtre Librairie.
    Une boîte de dialogue affiche demandant, vous voulez ouvrir la Librairie dans une nouvelle page?

    Pinpoint Dialog

  2. Cliquez sur le bouton OK.
    Un nouvel onglet du navigateur pour le dossier sélectionné s'ouvre. Le nom de l'onglet correspond au projet sélectionné dans la fenêtre Librairie.
    Remarque : Plusieurs onglets du Pinpoint peuvent être ouverts simultanément.
