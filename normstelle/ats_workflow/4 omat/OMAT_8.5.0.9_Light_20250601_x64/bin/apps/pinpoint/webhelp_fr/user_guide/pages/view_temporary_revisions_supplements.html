Afficher Attachement

Si un document contient des attachements (comme des suppléments ou des révisions temporaires), plusieurs indicateurs apparaissent qui permettent affichage des attachements:
  • Si le document contient des pièces jointes avec un type d'alerte Important, la fenêtre contextuelle Attachements importantes apparaît avec une liste de ces pièces jointes.
  • Les bannières de notification des attachements disponibles (cliquez pour afficher) apparaissent en haut du document dans le contenu volet pour toutes les attachements dont le type d'alerte est Important ou Normal.
  • Lorsque vous faites défiler le document dans le volet de Contenu, toutes les attachements apportées à des emplacements spécifiques sont affichées sur le côté gauche du document. Si le document est rendu au format HTML, les emplacements possibles des attachements sont des points d'ancrage spécifiques pouvant contenir des icônes de catégorie de attachement (tels que des suppléments et / ou temporaires révisions). Si le document est un PDF, les emplacements possibles des attachements sont des pages entières avec une bannière de notification message lorsque des attachements existent sur une page.
    Remarque : Puisqu'il peut exister trop de catégories de attachements pour toutes être affichées simultanément dans une emplacement de l'ancre, seuls ceux avec la priorité d'icône la plus élevée sont affichés, mais une liste de toutes les attachements à un emplacement peut être consulté en cliquant sur le groupe d'icônes. Reportez-vous au Flatirons Pinpoint Configuration Guide, Section "Configuration des types de catégories de attachements".
  • L'onglet Attachements sur le côté droit de la page est jaune lorsqu'il y a des attachements à l'actuel document. Le nombre de pattachements est indiqué entre parenthèses sur l'étiquette de l'onglet Attachements.
  • L'icône Nombre de contenus supplémentaires apparaît à droite des annotations / supplémentaires Titre de l'en-tête du contenu. Pour afficher les attachements, procédez comme suit:

  1. Ouvrez un document qui possède une icône de catégorie de attachement.
    Si un document contient des attachements, celui avec la priorité d'icône de catégorie de numéro la plus élevée s'affiche à gauche de Entrée de table des matières (tels que les les suppléments ou les révisions temporaires s'il n'y a pas de attachements d'un type de priorité plus élevée.
    Si le document contient des attachements marquées comme importantes, la fenêtre contextuelle Attachements importantes apparaît avec une liste de ces attachements. Les attachements qui ne sont pas marquées comme importantes sont disponibles en utilisant l'un des autres choix décrit à l'étape suivante.
  2. Faites l'un de ces choix:
    • Si la attachement que vous souhaitez afficher est répertoriée dans la fenêtre contextuelle Pièces jointes importantes, passez à l'étape suivante.

    • Cliquez sur une bannière de notification Attachements disponibles (Cliquez pour afficher) en haut du document dans le Volet Contenu.

      Remarque : Les notifications avec une priorité Aucune ne sont pas affichées dans ces alertes. Bannières de notification distinctes sont affichés pour chaque catégorie de attachements avec un type d'alerte Normal ou Important.

      La fenêtre contextuelle Attachements répertorie les attachements et affiche leur titre, leur date, et leur date de mise à jour.

    • Si vous recherchez une pièce jointe qui a été créée à un emplacement spécifique dans le document, faites défiler le Contenu volet jusqu'à ce que vous voyez une icône de catégorie de attachement (tels que supplément / révision temporaire) ou pièce jointe bannière de notification à gauche de cet emplacement.
    • Cliquez Attachements sur le côté droit de la page ou cliquez sur Télécharger la révision temporaire / Icône de supplément (si disponible).

      Ces deux options ouvrent le volet Attachements avec une liste des attachements dans le document. Faire référence à Volet Volet des Attachements.

    • Cliquez sur l'icône Nombre de contenus supplémentaires dans l'en-tête Annotations / Contenu supplémentaire.

      Toutes les attachements de la publication sont répertoriées dans les résultats de la recherche.

  3. Cliquez sur la attachement ou le groupe de attachements que vous souhaitez afficher.

    Si vous cliquez sur un titre de attachement, une bannière de notification ou une icône qui n'a qu'une seule attachement, il sera immédiatement s'affiche comme un nouvel onglet dans la page Contenu (dans ce cas, ignorez l'étape suivante). Si vous avez cliqué sur une attachement bannière ou icône de notification avec un groupe de attachements, elles seront répertoriées dans la fenêtre contextuelle attachements.



    Fenêtre contextuelle des attachements

  4. Si la fenêtre contextuelle Attachements apparaît, cliquez sur laattachement spécifique que vous souhaitez afficher.

La attachement apparaît sous la forme d'un nouvel onglet dans la page Contenu. En le visualisant, vous pouvez revenir au contenu parent en en cliquant sur l'onglet applicable sous l'en-tête de Contenu ou l'icône de Contenu parent (si disponible) dans le Contenu entête.
