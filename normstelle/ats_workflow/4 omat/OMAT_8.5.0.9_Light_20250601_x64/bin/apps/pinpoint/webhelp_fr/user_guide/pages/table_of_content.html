La fenêtre de Table des matières

La fenêtre de Table des matières affiche la structure du mode sélectionné dans la fenêtre de Librairie.



Table des matières

Remarque : Lorsque vous ouvrez une publication en lien symbolique, la Table des matières affichée correspond à la publication d'origine (cible).
Si vous disposez de l'autorisation pour le privilège Peut voir les ancres de contenu dans la ToC, la Table des matières 'étend d'un niveau supplémentaire pour afficher les ancres de contenu et les graphiques. Les ancres de contenu et les graphiques ne sont pas visibles si vous ne disposez pas de cette autorisation. L'icône Afficher plus indique qu'il y a du contenu supplémentaire. Par example:


Table des matières (Tâche - Sous-tâches disponibles)

Cliquez sur l'icône Afficher plus pour afficher le contenu supplémentaire. Par example:


Table des matières (Tâche - Sous-tâches développées)

Cliquez sur la référence d'ancrage que vous souhaitez ouvrir.

Cliquez sur l'icône Moins pour masquer les ancres de premier niveau.

Lors de la publication à partir du Knowledge Center a (KCA), les manuels de la cellule et du moteur ont une section Faits saillants des révisions qui est générée automatiquement lors de la publication. Par example:


Table desmMatières (Points saillants de la révision)

Remarque : Cette section est une section rédigée pour le constructeur d'Airbook.
Une fois que vous avez sélectionné les mises en surbrillance des révisions dans la Table des matières et que vous l'avez ouverte, elle affiche les éléments nouveaux, révisés et supprimés. Faire référence à Faits saillants de la révision (KCA Builders uniquement)
Le tableau qui suit décrit les éléments différents de fenêtre Table des matières.
Tableau 1. Les éléments de Table des matières
Component Description
icône de volet de réduction / icône de volet de réduction Cliquez sur cette icône pour réduire/agrandir le volet Table de matières.
Table de matières la barre Si un projet est sélectionné, le nom du projet est affiché dans l'en-tête de fenêtre.

Icône Afficher l'historique des révisions

Non applicable pour Pinpoint Standalone Light.

Cliquez sur cette icône pour afficher la boîte de dialogue Historique des Modifications.
Remarque : Vous devez avoir l'autorisation pour le privilège Peut examiner le journal des modifications pour que cette boîte de dialogue soit visible.
Vous pouvez afficher l'état des documents dans cette boîte de dialogue. Reportez-vous à Historique des Modifications.
Icône Icône Gérer la publication

Non applicable pour Pinpoint Standalone Light.

Si vous êtes un administrateur d'organisation, cliquez sur cette icône pour définir la révision affichée pour la publication sélectionnée. Faire référence à Gestion des publications.
Icône Impression en vrac Cliquez sur cette icône pour imprimer la composition entière ou une section sélectionnée de la composition. Faire référence à Impression en vrac.
Masquer/Afficher l'icône de contenu filtré Cette icône permet à l'utilisateur de choisir d'afficher ou de masquer le contenu filtré. Reportez-vous à Afficher/masquer le contenu filtré
Afficher les métadonnées Cliquez sur cette icône pour afficher des détails supplémentaires sur la publication ou définir une page de destination pour la publication. Faire référence à Métadonnées de Publication.
l'hiérarchique des nœuds Cliquez sur cette icône pour révéler des niveaux inférieurs du manuel, tel que les sections, les tâches, sous-tâches, et les sujets.
le nœud document Cliquez sur cette icône pour afficher le document dans la fenêtre Contenu. Un indicateur de chargement apparaît avant que le document soit affiché.
Icône de sous-tâche Pour les publications publiées avec les constructeurs iSpec ou KCA uniquement.

Icône de la figure Pour les publications publiées avec les constructeurs iSpec ou KCA uniquement.

Cette icône indique une ancre de premier niveau pour une figure. Cliquez sur cette icône pour ouvrir la figure.
Icône de feuille Pour les publications publiées avec les constructeurs iSpec ou KCA uniquement.

Cette icône indique un ancrage de premier niveau pour une feuille. Cliquez sur cette icône pour ouvrir la feuille.
