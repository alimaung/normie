Se Connecter

Pour des raisons de sécurité, lors du démarrage de l'application, la personne qui utilise le navigateur est requise de se connecter. En outre, après des périodes d'inactivité, l'utilisateur doit se connecter au navigateur.
Remarque : Si l'application: est configuré pour autoriser l'accès en invité, vous pouvez accéder au point d'accès public accessible aux invités. Contenu sans avoir à se connecter.
Remarque : Pour l’assistance d'un nouveau nom d'utilisateur et mot de passe, contacter votre superviseur ou administrateur.

Effectuez les étapes suivantes :

  1. Ouvrez votre navigateur Internet à l’URL fournie par votre superviseur ou votre administrateur.
    La page de connexion apparaît.
    Remarque : Le premier graphique ci-dessous montre la page de connexion standard. Il sera différent si l'application a été intégré à SAML. Le deuxième graphique montre la page de connexion lorsque l'accès en invité est activé.


    Page de connexion

    Page de connexion avec accès invité (Non applicable pour Pinpoint Standalone Light)

  2. Faites l'un de ces choix:
    • Entrez votre nom d'utilisateur et votre mot de passe, puis cliquez sur le bouton CONNEXION.
      Remarque : Si vous souhaitez vérifier l'orthographe du mot de passe, cochez la case Afficher le mot de passe.
    • Non applicable pour Pinpoint Standalone Light. Cliquez sur le bouton CONTINUER COMME INVITÉ.

      Si l'environnement autorise également les utilisateurs authentifiés, vous pouvez sélectionner dans la liste déroulante Plus la déconnexion de l'environnement public et afficher la page de connexion du contrôle d'accès.

  3. Optionnel. Sélectionnez une langue (anglais ou français) dans le menu déroulant CHOISISSEZ LA LANGUE
    Remarque : Vous pouvez également sélectionner la langue dans la barre d'action de Pinpoint.
  4. Si une boîte de dialogue Contrat de licence utilisateur final (EULA)) apparaît, lire le contenu et cliquez sur Je suis d'accord de continuer. Si vous n’acceptez pas, vous ne serez pas en mesure d'accéder à l'application.
    Remarque : si le droit d'utilisation de EULA à voir à chaque connexion est configuré pour s'afficher, les utilisateurs disposant du droit de lecture verront le EULA à chaque connexion. Si cette option n'est pas configurée, le EULA s'affiche uniquement pour la première connexion.
    Voici des scénarios pour l'affichage d'EULA:
    • Pinpoint Server: EULA apparaît lorsqu'un utilisateur se connecte pour la première fois, lorsqu'il passe à une autre bibliothèque ou lors de l'actualisation de la page.
    • Pinpoint Standalone: EULA apparaît lorsqu'un utilisateur se connecte pour la première fois, lorsqu'il passe à une autre bibliothèque ou lors de l'actualisation de la page.
      • Si un autre utilisateur accède à la même bibliothèque, EULA n'apparaît que si l'utilisateur précédent s'est déconnecté.
      • Si un autre utilisateur accède à la même bibliothèque, EULA n'apparaît que si l'utilisateur précédent s'est déconnecté.
    • Pinpoint Standalone Light: EULA apparaît lorsqu'un utilisateur se connecte et également lors du passage à une autre bibliothèque.
    • Pinpoint Standalone Light (Create for DVD): EULA apparaît lorsqu'un utilisateur se connecte et également lors du passage à une autre bibliothèque.

L'application s’ouvre, en affichant la page d'accueil dans la fenêtre Contenu. Dans la configuration par défaut, la page d'accueil est le logo du Flatirons, comme montré dans le graphique ci-dessous, mais il est configurable se référer à La fenêtre de configuration pour plus d'informations sur la modification de la page d'accueil.
