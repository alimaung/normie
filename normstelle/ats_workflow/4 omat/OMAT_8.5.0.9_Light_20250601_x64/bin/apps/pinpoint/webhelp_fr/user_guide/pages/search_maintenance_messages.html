Rechercher sur messages de maintenance

Rechercher sur messages de maintenance est une catégorie dans la Recherche du FRMFIM. Pour plus de détails, voir Fenêtre de recherche FRMFIM.

Pour rechercher des messages de maintenance, effectuez les étapes suivantes:

  1. Ouvrez la publication FRMFIM dans le fenêtre Library.
  2. Ouvrez la Recherche sur FRMFIM.
  3. Dans la liste déroulante de Type de recherche, choisissez la Rechercher sur messages de maintenance.
  4. Effectuez l'un des choix suivants:
    1. Saisissez un texte identifiant complet ou partiel dans le champ Texte.
    2. Saisissez un code des messages de maintenance complète ou partielle dans le champ Code.
  5. Cliquez sur le bouton Recherche, ou appuyez sur la touche Entrer de votre clavier, pour lancer la recherche.
    Les résultats de votre recherche apparaîtront dans la rubrique Résultats de recherche. Cliquez sur la ligne dans la colonne Refs pour voir l’apparition d'un message et le fenêtre Contenu.


    Les résultats de rechercher sur messages de maintenance

    Dans la zone Résultats de la recherche, cliquez sur l'icône Imprimer les résultats de la recherche pour imprimer les résultats de la recherche au format PDF.
