Rechercher des chemins électriques

Une recherche de chemin électrique nécessite une seule efficacité d'aéronef à sélectionner. Pour plus d'informations sur la sélection de l'efficacité, se référer à La fenêtre filtre.
La recherche de chemins électriques est une catégorie dans la Recherche de câblage. Pour plus de détails, se référer à La fenêtre recherche de câblage. La recherche de chemin électrique est un type de recherche facultatif pour les publications de câblage (par exemple, AWL, AWM et WDM).
Remarque : L'option de recherche Chemin électrique est visible dans le menu déroulant Types de recherche par défaut. Pour masquer cette option, décochez la case Enable Electrical Path lors de la publication de la publication dans Data Manager.
  1. Ouvrez une publication de câblage dans la fenêtre Librairie.
  2. Ouvrez la Recherche de câblage.
  3. Dans le menu déroulant Types de recherche, sélectionnez Chemin d'accès électrique.
  4. Effectuez l'un des choix suivants:
    1. Entrez tout ou partie d'un numéro de composant dans le champ du numéro d'identification.
      Selon l'OEM, cela peut être un EIN ou un FIN.
    2. Entrez tout ou partie d'un numéro de pièce dans le champ Câblage.
  5. Cliquez sur le bouton Rechercher ou sur le bouton Entrer du clavier pour lancer la recherche. Si vous devez effacer le filtre et recommencer, cliquez sur le bouton Réinitialiser.
    Vos résultats de recherche apparaissent dans la section Résultats de la recherche. S'il y a plusieurs entrées dans le résultat, vous verrez un conseil sur la sélection d'une des entrées pour voir plus d'informations. Pour plus de détails sur la navigation dans les résultats, voir Naviguer dans les résultats de recherche dans l'onglet Chemin électrique.
