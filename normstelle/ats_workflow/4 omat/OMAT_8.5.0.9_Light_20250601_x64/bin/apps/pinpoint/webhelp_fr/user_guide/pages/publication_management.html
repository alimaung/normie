Gestion des publications

Non applicable pour Pinpoint Standalone Light.

Pour chaque publication que vous souhaitez configurer, ouvrez-la d'abord dans le volet Bibliothèque. Cliquez ensuite sur Gérer la publication dans la barre Table des matières pour ouvrir la boîte de dialogue Gestion des publications. Les options disponibles dans la boîte de dialogue dépendent du type d'utilisateur et des autorisations accordées au rôle d'utilisateur auquel appartient l'utilisateur.

Voici un exemple de boîte de dialogue pour un utilisateur non administrateur:


Gestion des Publications Dialogue

Tous les utilisateurs (administrateurs et non-administrateurs) peuvent spécifier la révision à utiliser comme révision active. Faire référence à Définissez votre révision active.
Remarque : Les révisions disponibles sont définies par l'administrateur de l'organisation.
Il existe d'autres types d'utilisateurs disposant d'autorisations qui leur permettent d'effectuer des tâches supplémentaires dans la boite Gestion des publications.
  • Utilisateur auteur (fusion)

    Les utilisateurs disposant des autorisations appropriées peuvent créer des rapports de fusion, afficher des rapports de fusion et résoudre les conflits entre les révisions. Faire référence à Fusion de révisions.

    Les utilisateurs disposant du privilège Peut gérer les publications de l'organisation peuvent également définir des révisions par défaut pour leur organisation. Faire référence à Gérer les révisions d'organisation.

  • Utilisateur administrateur (organisation)

    Les utilisateurs disposant les autorisations appropriées peuvent définir les révisions par défaut pour leur organisation. Les utilisateurs non-administrateurs peuvent ensuite sélectionner la révision à utiliser comme révision active. Faire référence à Gérer les révisions d'organisation.

    Les utilisateurs disposant du privilège Peut fusionner de nouvelles révisions peuvent également créer des rapports de fusion, afficher des rapports de fusion et résoudre les conflits entre les révisions. Faire référence à Fusion de révisions.

Définissez votre révision active

Vous pouvez spécifier la révision à utiliser comme révision active. Pour définir votre révision active, procédez comme suit:
  1. Sélectionnez une révision.
  2. Dans la colonne Actions, sélectionnezDéfinir comme ma révision active.
