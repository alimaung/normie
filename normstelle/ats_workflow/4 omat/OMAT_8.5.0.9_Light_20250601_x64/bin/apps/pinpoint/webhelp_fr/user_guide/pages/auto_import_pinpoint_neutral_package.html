Importation automatique du paquet neutre Pinpoint

Vous pouvez ajouter un package neutre Pinpoint (fichier ZIP) à un dossier de données d'importation pour importer automatiquement le package dans Pinpoint. Cette fonctionnalité d’importation automatique est disponible par défaut. Vous devez créer un nouveau dossier dans lequel vous pouvez ajouter le package Pinpoint Neutral. Lorsque vous placez un paquet dans le dossier, l'importation se fait automatiquement.
Remarque : Vous ne pouvez pas ajouter de packages neutres cryptés à ce dossier. Les paquets neutres cryptés doivent être téléchargé à l’aide de la fonctionnalité Importer un Paquet de données dans Pinpoint.
Remarque : Le planificateur s'exécute toutes les minutes pour lire les fichiers ZIP ajoutés au dossier.

Pour importer automatiquement un paquet neutre Pinpoint, procédez comme suit:

  1. Créez un nouveau dossier nommé pinpoint-autoimport, par exemple C: \ pinpoint \ pinpointautoimport.
    Remarque : Ceci est le nom par défaut pour ce dossier. Votre administrateur peut configurer le nom du dossier pour s'adapte à votre environnement et vous indiquera si vous devez utiliser un nom de dossier différent.
  2. Ajoutez un paquet neutre Pinpoint (ZIP) au dossier pinpoint-autoimport.
    Le paquet est importé automatiquement dans Pinpoint. Vous pouvez afficher la progression de l’importation en sélectionnant le Icône Détails de l'import de la Barre d'action.

    Si l'importation réussit, le package disparaît du dossier. Si l'importation échoue, le fichier .failed est ajouté à le nom du fichier, par exemple, importfile1.zip.failed.

  3. Accédez à la bibliothèque et au publication importés et affichez-les.
