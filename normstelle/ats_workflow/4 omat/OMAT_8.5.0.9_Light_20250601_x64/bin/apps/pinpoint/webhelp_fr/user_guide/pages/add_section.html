Ajouter une nouvelle section

Non applicable pour Pinpoint Standalone Light.

Le mode de création vous permet d'ajouter une section au document sélectionné. Une fois le brouillon approuvé, le document modifié n'est disponible que pour les utilisateurs de votre organisation.

Pour ajouter une section, procédez comme suit:
  1. Entrez en mode création. Faire référence à Entrer en mode de création.
  2. Cliquez sur la ligne bleue entre les sections ou sur l'icône plus pour ajouter une nouvelle section. Par example:
    Une nouvelle section est ajoutée. Par example:


    Onglet Création - Nouvelle section ajoutée

  3. Après avoir ajouté une section, vous pouvez utiliser les options de la barre d'outils de création pour mettre en forme les informations, ajouter des références ou des liens graphiques et des avertissements / mises en garde / notes. Faire référence à Barre d'outils de création.
  4. Lorsque la section est terminée, sélectionnez l'une de ces options dans la barre d'outils de création:
    • Cliquez sur le bouton Enregistrer.
      Remarque : Un message de réussite apparaît:

      La section contenant vos modifications est mise en surbrillance.
    • Cliquez sur le bouton Annuler pour annuler.

      Un message de confirmation apparaît:

      Cliquez sur le bouton pour supprimer les modifications.

    Arès avoir enregistré ou annulé vos modifications, vous pouvez supprimer votre brouillon ou l'envoyer pour examen. Reportez-vous à Supprimer un brouillon and Envoyer les modifications pour examen et pour plus de détails.
