Annulation d'une révision de Publication

Non applicable pour Pinpoint Standalone Light.

La fonctionnalité d'annulation n'est disponible que pour les publications publiées sous forme de versions brouillon vers Pinpoint. Un utilisateur Avec les privilèges appropriés, vous pouvez rejeter le brouillon en cliquant sur le bouton d'annulation dans la barre d'en-tête. Cela signifie que le brouillon de révision est supprimé dans Pinpoint et Data Manager. L'utilisateur peut également transmettre la révision aux groupes d'utilisateurs capables de lire la publication, comme décrit dans la section précédente.

Remarque : L'utilisateur doit être un membre d'un groupe d'utilisateurs disposant du droit de lecture sur la ressource Peut publier ou annuler des brouillons de révision dans Contrôle d'accès.

Pour publier une révision de publication, procédez comme suit:

  1. Se connecter pour Pinpoint et accédez à la librairie qui a le projet de version que vous voulez rejeter.
  2. Sélectionnez le brouillon de révision.
  3. Dans le menu Opérations de publication, sélectionnez l'option de menu en arrière.

    Conseil: Si cette option de menu ne s'affiche pas, il se peut que vous ne disposiez pas des autorisations appropriées.

    Le brouillon de révision de publication est supprimé de Pinpoint et du gestionnaire de données. La ressource de révision de publication est également supprimée de l'arborescence de privilèges dans le contrôle d'accès.
