Recherche sur borne Liste

La Recherche sur borne est un type de recherche dans la Recherche de câblage. Pour plus de détails, voir La fenêtre recherche de câblage.

Remarque : La recherche sur borne n'est pas disponible pour les publications Airbus.
  1. Ouvrez une publication de câblage dans la fenêtre Librairie.
  2. Ouvrez la Recherche de câblage.
  3. Dans le menu déroulant de Types de recherche, sélectionnez Recherche de données de type bornes.
  4. Entrez tout ou partie d'un numéro de composant dans le champ EIN.
    Le fait que ce champ soit EIN ou FIN dépend du contexte de publication.
  5. Cliquez sur le bouton Rechercher ou sur le bouton Entrer du clavier pour lancer la recherche. Si vous devez effacer le filtre et recommencez, cliquez sur le bouton Réinitialiser.
    Les Résultats de recherche s'affichent dans l'onglet Equipement de résultats de recherche. S'il y a plusieurs entrées dans le résultat, vous verrez un conseil sur la sélection d'une des entrées pour voir plus d'informations. Pour plus de détails sur la navigation dans les résultats, voir Naviguer résultats de la recherche d'Équipment.
