Attachements

Chaque document distinct dans la bibliothèque peut avoir des attachements (telles que des révisions temporaires ou des suppléments) qui peuvent être ouvert de différentes manières. Reportez-vous à la section Afficher Attachement.
Remarque : Cette fonctionnalité n'est pas disponible pour les publications HTML.
Les utilisateurs disposant des autorisations appropriées peuvent gérer les attachements à l'aide des icônes du volet Attachements(faire référence à Volet Volet des Attachements). Toutes les attachements sont partagées entre tous les utilisateurs en ligne de Pinpoint Viewer dans le volet Attachements. Un travail de synchronisation est-il activé avec le contenu du supplément de synchronisation? option de configuration (reportez-vous à La fenêtre de configuration) qui peut actualiser toutes les attachements dans Pinpoint Standalone qui ont été ajoutées / modifiées / supprimées du côté en ligne de Pinpoint Viewer. Cependant, tout ce qui est fait avec des attachements dans Pinpoint Standalone n'est pas synchronisé avec Pinpoint Viewer en ligne. De plus, les utilisateurs de Pinpoint Mobile peuvent également voir les attachements telles qu'elles apparaissent dans Pinpoint Viewer en ligne chaque fois qu'un utilisateur effectue une synchronisation manuelle, mais il n'est pas du tout possible d'ajouter des attachements via Pinpoint Mobile.
Remarque : Pour plus de détails sur la capacité des utilisateurs à gérer les attachements, reportez-vous à Flatirons Access Control Module User Guide.

Les utilisateurs disposant des autorisations appropriées peuvent également ajouter desattachements à partir du Centre de connaissances ou télécharger des attachements via Pinpoint Viewer. Pour plus de détails sur l'ajout de attachements avec Pinpoint Viewer, reportez-vous à Ajouter Attachement.

Remarque : Les attachements décrites dans cette section sont différentes des annotations de fichiers. Pour plus de détails sur le dossier annotations, voir Les Annotations.
