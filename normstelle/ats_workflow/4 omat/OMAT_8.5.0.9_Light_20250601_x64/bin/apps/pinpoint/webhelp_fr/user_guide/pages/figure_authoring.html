Création de figures

Non applicable pour Pinpoint Standalone Light.

La création de figures vous permet d'effectuer ces tâches:
  • Ajouter des figures / feuilles: Reportez-vous à Ajouter une nouvelle figure/une page graphique.
  • Modifier les figures / feuilles: Reportez-vous à Modifier la figure/la page graphique.
  • Supprimer les figures / feuilles: Reportez-vous à Supprimer la figure/la page graphique.
  • Déplacer les figures / feuilles: Reportez-vous à Déplacer la figure/la page graphique.
