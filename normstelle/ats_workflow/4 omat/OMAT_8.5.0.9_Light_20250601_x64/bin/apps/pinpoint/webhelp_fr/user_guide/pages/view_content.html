Afficher le contenu dans le style ATA

L'icône Afficher le contenu dans un style ATA vous permet de voir la structure de la procédure dans le style ATA ou au format S1000D.

Remarque : La fonction d'affichage du contenu est activée lorsque la case est cochée pour le manuel d'activation de la vue S1000D dans le style ATA? dans le volet Configuration.
Remarque : Cette icône n'est visible que pour les publications S1000D.
