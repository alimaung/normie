La fenêtre Contenu

La fenêtre Contenu affiche le document sélectionné dans le Table des Matières.

Remarque : Le document PDF n'apparaît pas dans la Table des Matières. Lorsque cette option est sélectionnée dans la Librairie le PDF s'affiche directement dans la fenêtre Contenu. Pinpoint fournit le PDFJS intégré pour Chrome et Firefox, et il ne nécessite pas de PDF plug-in viewer pour afficher les documents. Internet Explorer nécessite Acrobat Reader. Pour plus d’informations,voir Navigation dans les documents PDF.
Remarque : Les utilisateurs peuvent ne pas être en mesure de charger avec succès des manuels PDF volumineux sur une machine Windows 32 bits à l'aide de navigateurs tels que Chrome, Edge, etc., Internet Explorer livré avec le système d'exploitation Windows OS serait capable de charger des documents PDF volumineux sans problème mais avec une surcharge de performances.

Une publication HTML est une publication qui a été créée à l'aide du générateur HTMLSet, qui utilise un package ZIP de fichiers HTML comme source d'entrée. Les publications HTML sont visibles dans Pinpoint (par exemple, les publications iFIM), cependant, certaines fonctionnalités sont désactivées pour ces types de publications. Les icônes de l'en-tête du volet Contenu ne sont pas disponibles. Tous les contrôles, tels que la navigation dans les pages et la recherche, se trouvent dans la publication HTML elle-même. Liens pour Diviser de Gros Fragments

Les plus gros fragments sont divisés en parties afin qu'ils se chargent rapidement dans la visionneuse Pinpoint. Vous pouvez accéder aux parties fractionnées en utilisant les hyperliens fournis. Cela s'applique également aux grands tableaux, aux blocs de pages d' AMM et aux chapitres d'erreurs de TSM.

Pour afficher les grands fragments fractionnés, procédez comme suit :
  1. Le contenu fractionné est disponible sous forme de nœuds sous la Table des matièrest.
  2. Cliquez sur un nœud pour l'afficher dans le volet de contenu.
  3. Cliquez sur le lien "Continue to .. -Part X" en bas pour afficher la partie suivante à partir du volet de contenu.

  4. Cliquez sur le lien "Continuation from.. -Part X" en haut, pour afficher la partie précédente depuis le volet de contenu.

Pour afficher les grands tableaux fractionnés, procédez comme suit :
  1. Lorsque de grands tableaux sont fractionnés, le contenu du tableau est remplacé par un lien hypertexte nommé “Click here to see table body”.

  2. Cliquez sur le lien pour afficher le tableau avec le contenu divisé en son propre fragment.
  3. Cliquez sur le lien “Continue to…Table Part X” pour afficher la partie suivante du tableau.
  4. Cliquez sur le lien “Continue from…Table Part 1” pour afficher la partie précédente du tableau.

  5. Cliquez sur le lien "Source Fragment" en haut du contenu du tableau pour revenir au contenu d'origine.

Pour afficher le bloc de page fractionnée dans les manuels AMM, procédez comme suit :
  1. Cliquez sur ouvrir un fragment d' AMM à partir de la Table des Matières.
  2. Cliquez sur le lien disponible dans le volet de contenu pour afficher le contenu fractionné.​

  3. Cliquez sur le lien “Continue from… Part X” en haut du volet de contenu pour afficher la partie précédente.

Pour afficher le chapitre sur les défauts partagés dans les manuels TSM, procédez comme suit :
  1. Cliquez sur n'importe quel chapitre divisé dans un TSM pour afficher la liste des liens du contenu divisé dans le volet de contenu.
  2. Cliquez sur n'importe quel lien de la liste pour afficher le contenu.

  3. Cliquez sur le lien ""Continue to .. -Part X" en bas pour afficher la partie suivante à partir du volet de contenu.

  4. Cliquez sur le lien "Continuation from.. -Part X" pour afficher la partie précédente depuis le volet de contenu.

L'onglet Contenu

Lorsqu'une Librairie contient plusieurs publications et que vous passez de l'un à l'autre, les différentes pages de publication restent sous forme d'onglets dans la fenêtre Contenu . De cette façon, vous pouvez basculer rapidement entre les pages de publication sans passer par la fenêtre Librairie. L'interface utilisateur est conçue pour différencier visiblement les onglets actifs et non actifs. L'onglet actif a une bordure bleue en haut tandis que les onglets non actifs apparaissent flous avec du texte lisible et sont mis en surbrillance au passage de la souris.
Remarque : Vous pouvez fermer les onglet manuellement dans la fenêtre Contenu en cliquant le bouton Fermer sur chaque onglet que vous souhaitez fermer.

Attachements

Si un document contient des attachements (telles que des révisions temporaires ou du contenu supplémentaire), il sera indiqué par des bannières de notification en haut du document dans le volet Contenu. Lors de l'ouverture des attachements, ces dernières apparaissent dans de nouveaux onglets dans la fenêtre de Contenu. Reportez-vous à la section Afficher Attachement.

Liens Multimédia

La procédure pour gérer les liens multimédia dans le contenu dépend du format:

  • Cliquer sur un lien multimédia qui pointe vers .ppt, .xls, .doc, .mkv, .3gp ouvrira un nouvel onglet et permettra à l'utilisateur de télécharger le fichier.
  • Cliquer sur un lien multimédia qui pointe vers PDF ouvrira un PDF dans le nouvel onglet Contenu.
Conseil : Appuyez sur F8 pour afficher la barre d'outils PDF.
  • Cliquer sur un lien multimédia qui pointe vers un format 3D pris en charge, tel que VRML, ouvrira le 3D dans la fenêtre Graphique . Si vous utilisez Internet Explorer ou Chrome, le graphique peut être affiché sans aucun plugin tiers. Si d'autres navigateurs sont utilisés, vous devrez installer le plugin CORTONA 3D Viewer sur le poste du client. Pour plus de détails, merci de se référer à Affichage d'un SIMIC/VRML 3D Graphique.
  • Dans la liste du graphique dans la fenêtre graphique, Seules les images et les objets 3D seront affichés, car ils sont les seuls affichés dans la fenêtre graphique.

Module de données de conteneur

Les documents S1000D peuvent faire référence à des modules de données de conteneurs qui peuvent contenir encore plusieurs références à des modules de données avec application différente. La gestion des modules de données de conteneur dans Pinpoint dépend des données. Dans la publication A350, s'il n'y a qu'un seul document applicable dans le conteneur, vous serez directement routé à ce sujet. S'il y a plusieurs documents applicables, Pinpoint ouvrira le conteneur à la place. Dans les types de données non-A350, le conteneur est toujours affiché.

Module de données de processus

Le module de données de processus contient des structures de traitement interactives permettant de séquencer d'autres modules de données ou étapes à l'intérieur de celui-ci. Le séquençage est basé sur des informations d'état dynamiques ou statiques et est géré par un composant logiciel appelé Logic Engine.

Le Logic Engine prend actuellement en charge ces contrôles dans la boîte de dialogue:
  • Un champ de saisie
  • Bouton Push
  • Soumettre
  • Annuler
  • Un bouton radio
Remarque : Le module de données de processus n'envoie pas d'entrées ou ne reçoit pas d'entrées provenant d'autres applications externes.
Par exemple:


  • Cliquez sur le bouton Next dans le module de données à naviguer à la prochaine nœud.


  • Entrez vos coordonnées dans les zones de saisie de texte.
  • Sélectionnez le choix de menu (dans cet exemple, Oui ou Non).
    Remarque : Le choix du menu est présenté comme un bouton radio.
  • Cliquez sur le bouton Soumettre
    Remarque : Cliquez sur le bouton Annuler pour effacer l'entrée et revenir à la page précédente.
Les informations que vous entrez dans la boîte de dialogue déterminent le contenu qui s'affiche après avoir cliqué sur le bouton Envoyer.
  • La séquence continue à s'exécuter jusqu'à ce que vous sélectionniez la bonne réponse.Vous pouvez ensuite passer au nœud suivant, si disponible.


  • Si vous sélectionnez une mauvaise réponse, le nombre de mauvaises réponses est incrémenté.La séquence se répète jusqu'à ce que vous sélectionniez la bonne réponse.


  • Le dernier nœud de la séquence n'aura que le bouton Précédent. Lien dmRef dans les modules de données de processus.
