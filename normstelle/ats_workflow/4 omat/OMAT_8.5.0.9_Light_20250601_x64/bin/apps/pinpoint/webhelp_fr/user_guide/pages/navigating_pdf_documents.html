Navigation dans les documents PDF

Lorsqu'il est sélectionné dans la Librairie, le PDF s'affiche directement dans la fenêtre Contenu. Pinpoint fournit le PDFJS intégré pour Chrome et Firefox et aucun PDF Viewer plug-in est nécessaire pour visualiser les documents. Internet Explorer nécessite Acrobat Reader.

Cliquez sur l'icône rechercher dans l'en-tête du PDF Viewer et saissez un mot clé à rechercher dans un document dans le champ de recherche. Une liste de résultats de recherche s'affichera. La barre de recherche interne montre le nombre de résultats de la recherche.



Liste de recherche PDF

Le mot clé est mis en surbrillance dans la liste des résultats de la recherche et dans le contenu du document. Vous pouvez sélectionner les résultats directement dans la liste des résultats de recherche et directement dans le contenu de cette page.

Vous pouvez également utiliser les fonctions suivantes dans la barre de recherche pour naviguer dans le document :
  • - Visualiser le résultat de la recherche précédent.
  • - Visualiser le résultat de la recherche suivant.
  • - Mettre en surbrillance tous les résultats de la recherche dans le document.
  • - Rechercher l'expression exacte renseignée dans le champ de recherche.
