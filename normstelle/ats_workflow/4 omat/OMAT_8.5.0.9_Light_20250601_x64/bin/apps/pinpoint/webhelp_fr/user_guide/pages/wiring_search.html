La fenêtre recherche de câblage

Le volet Recherche de câblage est disponible lorsque vous ouvrez une publication de câblage pris en charge dans la bibliothèque. S'il est minimisé, vous pouvez l'agrandir en un clic. Recherche de câblage permet de tracer des câbles électriques d'un composant à un autre et de voir les connexions.entre les deux. Pour des exemples de publications de câblage prises en charge, reportez-vous au Tableau 10: Exemple d’assistance à la recherche de câblage pour les publications et les types de câblage.
Remarque : Les types de recherche de câblage disponibles dépendent des spécifications de publication du fabricant d'équipement d'origine (OEM) et de l'ATA. Par exemple, les publications d'Airbus prennent en charge recherche de câblage et recherche de chemin électrique
Remarque : La recherche de chemin électrique est activée par défaut, cependant, elle dépend de la configuration Enable Electrical Path dans Data Manager pour le générateur.

Le volet Recherche de câblage contient également les Types de recherche, qui vous aident à catégoriser la recherche. Le système se souvient de l'option que l'utilisateur a sélectionnée la dernière fois et la remplit automatiquement chaque fois que l'utilisateur accède au Recherche de câblage la prochaine fois.
Remarque : Cette fonctionnalité est prise en charge jusqu'à ce que le cache du navigateur soit vidé.
Remarque : Lorsque la Recherche de câblage est ouverte pour la toute première fois, la valeur du type de recherche est par défaut la première option de la liste.
Les types de recherche disponibles dans la fenêtre Recherche de câblage sont décrites dans les sections ci-dessous.

Recherche de chemin électrique

Cette recherche vous permet de rechercher des éléments et des câbles électriques dans les chemins électriques. Vous pouvez ensuite naviguer le long d'un chemin électrique en cliquant sur les éléments, les broches et les fils. La recherche de chemin électrique est un type de recherche facultatif pour les publications de câblage (par exemple, AWL, AWM et WDM). La publication doit être configurée pour prendre en charge le chemin électrique lors de sa création dans Data manager.
Remarque : L'option de recherche Chemin électrique est visible dans le menu déroulant Types de recherche par défaut. Pour masquer cette option, décochez la case Enable Electrical Path lors de la publication de la publication dans Data Manager.

Pour plus de détails sur la façon d'effectuer une recherche, se référer à Rechercher des chemins électriques.

Recherche de câblage

Cette recherche vous permet de rechercher des numéros de faisceau et de câbles dans les listes de câble.
Remarque : Vous pouvez effectuer une recherche de harnais / faisceau dans une recherche de câble pour les données de la série C. Cette fonctionnalité est disponible lorsque vous entrez un numéro de faisceau / harnais exact dans le champ BUNDLE.
Recherche de câblage pour les détails sur la façon d'effectuer une recherche, se référer à Rechercher les listes de câblages.

Recherche d'équipement

Cette recherche vous permet de rechercher des composants dans les listes d'équipement.
Remarque : La recherche d'équipement n'est pas disponible pour les données Airbus données traitées via Data Manager. Si vous visualisez ce type de données, reportez-vous plutôt à Recherche sur FIN/Zone/Panneau.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Recherche sur listes d'équipement.

Recherche de connexion

Cette recherche vous permet de rechercher les FINs dans les listes de Connexion.
Remarque : La recherche de connexion n'est pas disponibles pour les données Airbus données traitées via Data Manager. Si vous regardez ce type de données, se référer à Recherche sur FIN/Zone/Panneau instead.
Remarque : L'onglet Branchage peut ou non être disponible selon le format de données OEM.

Pour plus de détails sur la façon d'effectuer une recherche, se référer à Rechercher de connexion.

Recherche de attache

Cette recherche vous permet de rechercher des EIN dans les listes de attache.
Remarque : La recherche de attache n'est pas disponible pour les publications d'Airbus.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Recherche sur Attache Listes.

Recherche de Disjoncteur

Cette recherche vous permet de rechercher des EIN ou PAN dans les listes de câbles.
Remarque : La recherche de Disjoncteur n'est pas disponible pour les publications d'Airbus.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Rechercher les Disjoncteur.

Recherche de données Prise de terre

Cette recherche vous permet de rechercher des EIN dans les listes prise de terre.
Remarque : La recherche de données Prise de terre n'est pas disponible pour les publications d'Airbus.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Rechercher sur Prise de terre.

Recherche de données Junction

Cette recherche vous permet de rechercher des EIN dans le list du Jonction.
Remarque : La recherche de données Junction n'est pas disponible pour les publications d'Airbus.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Recherche sur Junction listes.

Recherche de données de type bornes

Cette recherche vous permet de rechercher des EIN dans les listes de terminal.
Remarque : La recherche de données de type bornes n'est pas disponible pour les publications d'Airbus.
Pour plus de détails sur la façon d'effectuer une recherche, se référer à Recherche sur borne Liste.
