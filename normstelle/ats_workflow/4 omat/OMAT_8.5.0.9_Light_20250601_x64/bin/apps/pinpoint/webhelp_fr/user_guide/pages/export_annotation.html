Exporter et importer des annotations

Les annotations peuvent être exportées et importées dans Pinpoint. Bien que cette fonctionnalité soit applicable pour Pinpoint Viewer et Pinpoint Standalone Light, elle est principalement utilisée pour Pinpoint Standalone. Elle s'applique au scénario suivant:

  1. L'utilisateur final reçoit une version autonome de Pinpoint avec des données (version 1).
  2. L'utilisateur final crée des annotations dans cette version.
  3. L'utilisateur final reçoit une nouvelle révision de Pinpoint autonome avec des données mises à jour (version 2).
  4. L'utilisateur final souhaite transférer les annotations de la version 1 à la version 2.

Pour transférer des annotations d'une version autonome à l'autre, faire les étapes suivantes:

  1. Démarrer et vous connecter à la première version de Pinpoint autonome.
  2. Dans la barre d'actions, cliquez sur le bouton Autres actions.

    Plus menu déroulant

  3. Sélectionnez Exporter les Annotations.

    Pinpoint va maintenant créer un fichier avec le nom "annotations.json". Le mode de téléchargement dépend du navigateur. Dans Internet Explorer, il vous sera demandé si vous souhaitez enregistrer ou ouvrir le fichier.

  4. Enregistrez le fichier à l'emplacement approprié.
  5. Démarrer et vous connecter à la dernière version de pinpoint reçue.
  6. Dans le menu déroulant Autres actions, sélectionnez Télécharger les Annotations.
    S'il existe déjà des annotations précédentes avec pièce jointe, un message de confirmation apparaît.
  7. Dans le navigateur de fichiers, recherchez et sélectionnez le fichier "annotations.json" créé à partir de la première version.
    Une boîte de dialogue de confirmation apparaît:

  8. Vérifiez que toutes les annotations ont été importées correctement dans la nouvelle version autonome.
