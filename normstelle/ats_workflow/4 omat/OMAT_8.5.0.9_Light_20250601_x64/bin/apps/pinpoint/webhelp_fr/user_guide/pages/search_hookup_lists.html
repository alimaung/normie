Rechercher de connexion

Rechercher de connexion est un type de recherche dans la Recherche de câblage. Pour plus d'informations, merci de voir La fenêtre recherche de câblage.

Remarque : La recherche de connexion n'est pas disponible pour Airbus données traitées via Data Manager. Si vous consultez ce type de données, voir à Recherche sur FIN/Zone/Panneau à la place.
Remarque : L'onglet Branchage peut ou non être disponible selon le format de données OEM.
  1. Ouvrez une publication de câblage dans la fenêtre Librairie.
  2. Ouvrez la Recherche de câblage.
  3. Dans le menu déroulant Types de recherche, sélectionnez Rechercher de connexion.
  4. Entrez un numéro de composant complet dans le champ EIN. (La recherche partielle n'est pas supportée dans ce champ).
    Le fait que ce champ soit EIN ou FIN dépend du contexte de publication.
  5. Cliquez sur le bouton Recherche, ou appuyez sur la touche Entrer de votre clavier, pour lancer la recherche.Si vous devez effacer le filtre et recommencez, cliquez sur le bouton Réinitialiser.
    Vos résultats de recherche apparaissent dans les Résultats de la recherche. S'il y a plusieurs entrées dans le résultat, vous verrez un conseil sur la sélection d'une des entrées pour voir plus d'informations. Pour plus de détails sur la navigation dans les résultats, voir Naviguer dans les résultats de la recherche de connexion.
