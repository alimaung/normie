Vue d’ensemble de guide de l'utilisateur

Ce guide de l'utilisateur fournit les informations de base nécessaires à l'utilisation du Pinpoint. Il suppose que vous êtes déjà familier avec les fonctions informatiques de base et la terminologie du logiciel.

Pour la documentation de la suite Flatirons, le terme publications / manuels S1000D est le plus souvent utilisé pour faire référence aux publications standard S1000D au lieu des publications S1000D spécifiques aux constructeurs. Les fonctionnalités offertes pour certains types de publications S1000D (telles que C-Series, A350 et XWB) peuvent être personnalisées à partir de la norme par défaut S1000D comportement de publication.
Remarque : Cette documentation couvre uniquement les fonctionnalités générales du produit et non le large éventail de personnalisations pouvant varier selon la configuration.
Remarque : Les Acronymes sont utilisés dans ce guide de l'utilisateur. Si vous rencontrez un acronyme que vous ne connaissez pas, voir les Acronymes.
