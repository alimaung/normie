Résoudre les conflits de révision

Non applicable pour Pinpoint Standalone Light.

Les utilisateurs doivent disposer des autorisations pour le privilège Peut fusionner de nouvelles révisions pour afficher un rapport de fusion et résoudre les conflits.

Les panneaux Report de Conflits fournissent des informations sur les documents avec des changements dans la révision et vous permettent de résoudre les conflits éventuels.
Remarque : Les sections, figures et feuilles en conflit ont un arrière-plan gris. Vous devez résoudre tous les conflits dans le document pour marquer le document comme résolu. Tous les documents doivent être résolus pour terminer la fusion.
Remarque : Les données sources doivent spécifier des identifiants uniques (c'est-à-dire des identifiants ou des clés) pour les sections, les figures et les feuilles afin de garantir un alignement correct entre les sections, les figures et les feuilles dans les révisions. Les données sans identifiants afficheront les sections, les figures et les feuilles telles que supprimées de la révision précédente et ajoutées dans une nouvelle révision sans alignement.

  • Le panneau Tous les documents le plus à gauche montre tous les documents avec des changements dans la révision. L'icône sur le document affiche une icône d'avertissement pour les documents contenant des conflits. Le pied de page de ce panneau répertorie un pourcentage global de documents résolus par rapport aux documents en conflit.
  • Le panneau principal affiche le document actuellement sélectionné, qui est par défaut le premier de la liste. Ce panneau affiche une vue côte à côte du contenu du document ou de la liste des figures, selon l'onglet sélectionné.
    Le numéro indiqué dans l'onglet Document ou Liste des figures du panneau principal indique le nombre de conflits dans le document ou les figures. Par exemple, il y a un conflit dans ce document:

    Le côté gauche du panneau principal montre la nouvelle révision OEM . Le côté droit montre l'aperçu de la nouvelle révision OEM avec les modifications COC ajoutées.

  • L'extrême droite du panneau affiche les actions disponibles pour chaque section du document.
  • La partie supérieure droite de l'écran a ces icônes:
    • Ajouter des modifications supplémentaires à ce document icône

      Cette option est disponible lorsque tous les conflits des documents actuels sont résolus. Vous pouvez apporter des modifications supplémentaires au contenu de droite avant de terminer la fusion. Ceci est utile lorsque vous souhaitez résoudre un conflit en utilisant OEM ou COC, mais également copier du contenu à partir de la version non sélectionnée. Par exemple, vous souhaiterez peut-être conserver votre version COC mais copier les modifications OEM dans la version COC .

      Lorsque vous sélectionnez cette option, ce message de confirmation apparaît:

      Entrez la raison des modifications supplémentaires dans le champ Commentaire et cliquez sur le bouton .
      Remarque : Le contenu saisi dans le champ Commentaire est visible par les auditeurs dans la boîte de dialogue Historique des conflits. Faire référence à Audit de fusion.
    • Historique des conflits icône

      Cette option est disponible après toute action de fusion et permet à un auditeur d'afficher toutes les actions de fusion pour le document actuel. Faire référence à Audit de fusion.

    • Réinitialiser l'aperçu de ce document icône

      Cette option est disponible après toute action de fusion et restaure le document de droite à son état initial. Toutes les actions de fusion sont supprimées et l'historique de fusion effacé pour le document.

      Lorsque vous sélectionnez cette option, ce message de confirmation apparaît:

      Cliquez sur le bouton pour réinitialiser le document à son état initial.

    • icône / champ

      Cette icône / champ indique le nombre total de sections, figures ou feuilles en conflit dans le document actuel.

  1. Affichez le Report de Conflits. Faire référence à Afficher le rapport de fusion.
  2. Consultez les conflits dans l'onglet Document et / ou l'onglet Liste des figures.
    Remarque : Lors de la résolution des conflits dans la Liste des figures, vous pouvez cliquer sur l'icône Comparer l'image Image pour lancer une comparaison côte à côte de l'image. Par example:

  3. Sélectionnez l'une de ces options sur le côté droit du rapport pour résoudre le conflit:
    • Cliquez sur le bouton sélectionner le changement OEM.

      Une boîte de dialogue de commentaire apparaît:

    • Cliquez sur le bouton pour sélectionner le changement de COC.

      Une boîte de dialogue de commentaire apparaît:

    • Cliquez sur le bouton pour rejeter toutes les modifications.

      Une boîte de dialogue de commentaire apparaît:

    Voici quelques éléments à prendre en compte lors du choix de l'option Rejeter:
    • Lorsque vous rejetez une section contenant uniquement des modifications COC cette action entraîne le rejet des modifications COC et l'utilisation de la version OEM de la section à la place.
    • Lorsque vous rejetez une section contenant uniquement des modifications OEM cette action entraîne le rejet des modifications OEM et l'utilisation du contenu OEM de la révision précédente en tant que nouveau COC.
    • Lorsque vous rejetez une section contenant à la fois des modifications OEM et COC, cette action entraîne le rejet des modifications COC et OEM et l'utilisation du contenu OEM de la révision précédente comme nouveau COC.
  4. Optionnel. Entrez un commentaire dans la boîte de dialogue commentaire pour l'action sélectionnée..
    Dans la boîte de dialogue commentaire, vous pouvez fournir des justifications pour la sélection de cette option de fusion. L'utilisateur effectuant l'action, l'action entreprise, l'horodatage de l'action et les commentaires sont persistants dans l'historique de fusion et sont disponibles pour examen par un auditeur à l'avenir. Reportez-vous à pour plus d'informations Audit de fusion.
  5. Cliquez sur le bouton .
    Un message de réussite apparaît. Une icône remplace les boutons de conflit sur le côté droit du rapport.
    Remarque : Si vous survolez l'icône , elle se transforme en icône Annuler les modifications. Cliquez sur l'icône pour revenir à la résolution de conflit précédemment sélectionnée. Les options de résolution réapparaissent. Vous pouvez sélectionner une option pour modifier la résolution des conflits.

    Reportez-vous à Annuler ou terminer la fusion pour plus d'informations sur l'annulation ou la finalisation de la fusion.
