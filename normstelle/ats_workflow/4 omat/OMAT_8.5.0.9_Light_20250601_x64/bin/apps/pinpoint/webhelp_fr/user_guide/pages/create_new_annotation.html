Créer une nouvelle annotation

Pour créer des annotations pour du texte et / ou des graphiques (SVG, GIF et PNG), procédez comme suit:
Remarque : S'il existe un avertissement pour le document sur lequel vous souhaitez créer une annotation, vous devez accepter les instructions de sécurité. Après avoir coché la case Acquitter l'instruction de sécurité, l'icône d'annotation est activée, ce qui vous permet de créer une annotation pour le document.
  1. Pour créer une annotation de texte, procédez comme suit:
    1. Dans la partie Contenu, mettez en surbrillance le texte que vous souhaitez annoter.


    2. Cliquez sur l'icône d'annotation .
  2. Pour créer une annotation pour un graphique, procédez comme suit:
    1. Ouvrez le graphique sur lequel vous souhaitez créer une annotation.
    2. Cliquez sur le bouton dans la barre d'outil Graphique.
      Le curseur se transforme en une forme .
    3. Dessiner un carré où vous voulez placer votre annotation
  3. La boîte de dialogue contextuelle d'annotation qui apparaît est identique pour le texte et le graphique.
  4. Si vous êtes autorisé à créer, modifier et supprimer des annotations publiques, cette boîte de dialogue contextuelle d'annotation apparaît:

    Accès si le contenu appartient à votre organisation

    Accès si le contenu n'appartient pas à votre organisation

  5. Non applicable pour Pinpoint Standalone Light. Si vous consultez une publication de votre organisation, sélectionnez l'un de ces boutons radio d'accès:
    1. Si vous souhaitez que l'annotation ne soit visible que par vous, sélectionnez le bouton radio Privé.
    2. Si vous souhaitez que l'annotation soit visible uniquement par votre organisation, sélectionnez le bouton radio Mon organisation.
    3. Si vous souhaitez que l'annotation soit visible par toutes les organisations, sélectionnez le bouton radio Tout le monde.
  6. Non applicable pour Pinpoint Standalone Light. Si vous consultez une publication d'une autre organisation, sélectionnez l'un de ces boutons radio d'accès:
    1. Si vous souhaitez que l'annotation ne soit visible que par vous, sélectionnez le bouton radio Privé.
    2. Si vous souhaitez que l'annotation soit visible uniquement par votre organisation, sélectionnez le bouton radio Mon organisation.
  7. Si vous n'êtes pas autorisé à créer, modifier et supprimer des annotations publiques, cette boîte de dialogue contextuelle d'annotation apparaît:


    Remarque : Vous pouvez déplacer la boîte de dialogue contextuelle d'annotation en cliquant sur l'en-tête d'annotation et en faisant glisser la boîte de dialogue vers un autre emplacement.
  8. Choisissez si l'annotation est privée ou publique
    Remarque : Les annotations publiques sont sous le contrôle de privilège. Pour créer, modifier et supprimer des annotations publiques vous aurez besoin écriture et suppression de la permission Peut créer, modifier ou supprimer des annotations publiques dans le Access Control. Cette annotation doit être approuvée par un utilisateur disposant d'une autorisation en écriture avant de pouvoir être rendue publique.
  9. Tapez un titre et les commentaires que vous voulez faire.
    Remarque : Le champ Date affiche la date actuelle et ne peut pas être modifié
  10. Dans la barre d'outils de format, sélectionnez un style de format à appliquer aux commentaires:
    • Gras
    • Italiques
    • Souligné
    • Liste ordonnée
    • Liste non ordonnée
    • Retrait correct
    • Retrait gauche
    Remarque : Toutes les options de mise en forme que vous appliquez aux annotations sont visibles lorsque vous modifiez ou affichez une image d'annotation et lorsque vous créez un document de retour.
  11. Facultatif: dans le champ Sélectionner ou supprimer un fichier, ajoutez une attachement à l'annotation à l'aide de l'une des méthodes suivantes:
    • Faites glisser le fichier du système de fichiers de votre ordinateur et déposez-le dans le champ Sélectionner ou supprimer un fichier.
    • Cliquez dans le champ pour ouvrir le navigateur de fichiers, recherchez et insérez le fichier.
    Voici quelques exemples de formats pris en charge:
    • .bmp
    • .gif
    • .jpg
    • .jpeg
    • .mp4
    • .png
    • .pdf
    Remarque : Pour supprimer une attachement, cliquez sur l'icône Supprimer la pièce jointe en regard du nom de la attachement. Toutes les attachements dans des formats pris en charge par le navigateur s'affichent en ligne dans l'annotation.
    Les attachements dans des formats non pris en charge ont le nom de fichier.
    Remarque : Pour IE 11 uniquement: les attachements dont la taille de fichier est supérieure à 5 Mo semblent être plus lentes. des aperçus.
  12. Cliquez sur le bouton Enregistrer.
    Dans le volet Contenu, le texte annoté apparaît en surbrillance jaune, tandis que dans le volet graphique, vous verrez l'annotation comme un carré rouge. Lorsque vous déplacez la souris sur l'annotation, elle apparaît dans une boîte de dialogue. Vous le verrez également si vous cliquez dans la zone grise "Afficher les annotations".
