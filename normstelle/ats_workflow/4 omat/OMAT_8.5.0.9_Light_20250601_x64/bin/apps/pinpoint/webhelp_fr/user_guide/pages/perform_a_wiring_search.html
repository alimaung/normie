Effectuer une recherche sur câblage

Le volet Recherche de câblage est disponible lorsque vous ouvrez une publication de câblage pris en charge dans la bibliothèque.

Dans le menu Types de recherche, sélectionnez l'une de ces options de menu:

  • Pour rechercher des chemins électriques, cliquez sur l'option de menu Chemin électrique. Reportez-vous à Rechercher des chemins électriques.
  • Pour rechercher des listes d'équipements, cliquez sur l'option de menu Recherche d'équipements. Reportez-vous à Recherche sur listes d'équipement.
  • Pour rechercher des listes de connexions, cliquez sur l'option de menu Recherche de connexion. Reportez-vous à Rechercher de connexion.
  • Pour rechercher des listes de câblages, cliquez sur l'option de menu Recherche de câblage. Reportez-vous à Rechercher les listes de câblages.
  • Pour rechercher des listes de junction, cliquez sur l'option de menu de Recherche de données Junction. Reportez-vous à Recherche sur Junction listes.
  • Pour rechercher des listes de attache, cliquez sur l'option de menu de Recherche de Attache. Reportez-vous à Recherche sur Attache Listes.
  • Pour rechercher des listes de prise de terre, cliquez sur l'option de menu de Rechercher de données Prise de terre. Reportez-vous à Rechercher sur Prise de terre.
  • Pour rechercher des listes de terminaux, cliquez sur l'option de menu Recherche de données de type bornes. Reportez-vous à Recherche sur borne Liste.
  • Pour rechercher des listes de disjoncteurs, cliquez sur l'option de menu Recherche de Disjoncteur. Reportez-vous à Rechercher les Disjoncteur.
