Copier le Lien GOTO Pinpoint

Pour les documents Pinpoint, la copie du lien depuis la barre d'adresse du navigateur Internet ne fonctionnera pas correctement pour afficher le même contenu ultérieurement. Au lieu de cela, vous devez utiliser la fonction intégrée Lien vers le contenu.
L'URL copiée avec cette fonctionnalité peut inclure le filtre d'applicabilité / effectivité actuel, les termes de recherche, etc. Pour plus de détails sur le format et les spécifications de l'URL GOTO, reportez-vous au Flatirons Pinpoint Configuration Guide, au "format et aux spécifications d'URL GOTO".
Remarque : Cette fonctionnalité n'est pas disponible pour les publications HTML.

Si un administrateur a activé le privilège ne Peut accéder qu'aux révisions actuelles pour votre rôle d'utilisateur, les publications qui ne sont pas à jour ne sont pas accessibles à l'aide de la fonction GOTO. Vous devez sélectionner la dernière révision avant que ces publications soient disponibles. Faire référence à La fenêtre de Librairie.

Pour copier un lien Pinpoint GOTO, procédez comme suit:

  1. Accédez au document dans Pinpoint qui contient le lien que vous souhaitez copier.
  2. Ouvrez la boîte de dialogue URL:
    Option Description
    Méthode de la souris Dans la barre d'en-tête du volet Contenu, cliquez sur l'icône Lien vers le contenu..
    Méthode de raccourci clavier Press Ctrl+Alt+C.
    La boîte de dialogue URL affiche le lien GOTO vers ce document. Par défaut, le lien contient les ID comme paramètres avec le bouton bascule Utiliser les ID sélectionné en cyan.
  3. Sélectionnez l'un de ces boutons bascule:
    Bouton à bascule Description
    Utiliser des identifiants Il s'agit de l'option par défaut dans laquelle l'ID sera généré lors de la création de la publication. Cette option continue de fonctionner même si la publication ou l'un de ses parents est renommé. Cependant, si vous utilisez plusieurs environnements Pinpoint, cela ne fonctionnera pas entre eux car ils auront des ID générés différents.


    Boîte de dialogue URL - Utiliser les ID sélectionnés
    Utiliser les noms Cette option utilise le chemin de publication comme paramètre. Cette option fonctionne quel que soit l'environnement Pinpoint tant que la publication se trouve dans le même chemin. Cependant, le chemin ne sera plus valide si vous renommez la publication ou l'un de ses parents.


    Boîte de dialogue URL - Utiliser le chemin sélectionné
    Copier le lien Cette option permet à l'utilisateur de coller le lien dans un autre emplacement. Le format du lien est par défaut le même que le format Afficher la révision qui comprend la révision et le titre.
    Le bouton bascule que vous avez sélectionné est mis en surbrillance en cyan.
  4. Cochez la case Afficher la révision.
    Option Description
    Laissez la case à cocher Afficher la révision vide Utilisez cette option pour créer un lien vers la dernière publication de document. Si le document que vous consultez est révisé, le lien que vous avez copié affichera la dernière révision au lieu du contenu exact que vous avez vu lors de la première copie du lien.
    Cochez la case Afficher la révision Utilisez cette option pour créer un lien vers la révision de publication spécifique que vous consultez actuellement. Le contenu que vous voyez continuera d'être le contenu exact qui sera affiché lorsque le lien sera cliqué, même si la publication est mise à jour ultérieurement.
  5. Copiez l'URL:
    Option Description
    Méthode Button Dans la plupart des cas, vous pouvez copier automatiquement l'URL affichée dans le presse-papiers en cliquant simplement sur le bouton Copier.
    Méthode de mise en évidence Pour certaines configurations de navigateur Internet, Pinpoint peut ne pas disposer des autorisations appropriées pour mettre à jour automatiquement le presse-papiers. Si vous remarquez que l'URL n'est pas copiée correctement lorsque vous cliquez sur le bouton Copier, vous pouvez à la place copier le lien à partir de la boîte de dialogue URL de la même manière que vous copiez du texte normal. Par exemple, mettez le lien en surbrillance dans la boîte de dialogue et appuyez sur Ctrl + C.
L'URL est copiée dans le presse-papiers.
Vous pouvez coller l'URL là où c'est nécessaire. Par exemple:
  • Vous pouvez envoyer l'URL dans un e-mail.
  • Lors de la création d'une carte de travail dans la perspicacité, vous pouvez copier-coller le lien GOTO dans le champ de référence Pinpoint de la carte de travail. Reportez-vous au Flatirons Insight User Guide.
Remarque : Lorsque vous copiez une URL pour une publication de lien symbolique, la publication d'origine (cible) s'ouvre lorsque vous collez l'URL dans un navigateur.
Si quelqu'un qui n'est pas encore connecté à Pinpoint clique sur un lien GOTO, cette personne sera dirigée vers la page de connexion précise (faire référence à Se Connecter). Une fois connecté, l'utilisateur sera redirigé vers l'emplacement de document correct qui a été configuré par la fonction de lien GOTO.
