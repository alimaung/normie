Références intégrées

Remarque : Votre administrateur doit attribuer l'autorisation de lecture Peut afficher la référence intégrée pour le privilège de consultation des références intégrées dans les publications. Pour désactiver la possibilité d'afficher les références intégrées, supprimer l'autorisation
Remarque : Administrateurs: Vous devez désactiver l'aperçu des références par survol avec la souris si vous utilisez la fonction de références intégrées. Reportez-vous à la rubrique "Activer l'aperçu au survol des références DM / CSN" dans Flatirons Pinpoint Configuration Guide.
Les références intégrées vous permettent d'ouvrir une référence dans un cadre de conteneur dans le contenu d'origine que vous visualisez dans le volet de Contenu. Cette fonctionnalité peut être activée/désactivée pour tous les constructeurs ou les constructeurs sélectionnés. Reportez-vous au sujet "Enabling/Disabling Embedded References for Builders and Specific Publications" dans Flatirons Pinpoint Configuration Guide.

Fonctionnalité prise en charge

Lorsque vous travaillez avec des références intégrées, vous devez être conscient de la fonctionnalité prise en charge par la fonctionnalité:
  • Seuls ces types de liens fonctionneront:
    • bibliothèque à bibliothèque
    • constructeur à constructeur
    • HTML en HTML
  • Vous devez cliquer sur l'icône Afficher la référence pour développer la référence.
    Remarque : Cliquer sur le lien de référence directement a le même comportement actuel et vous dirige vers cette référence.
  • Vous ne pouvez pas créer, modifier ou supprimer des annotations ou des suppléments dans une référence intégrée.
  • La liste des graphiques n'inclut pas les graphiques dans une référence intégrée.
  • Si vous activez les références intégrées, la fonction de survol de référence est désactivée.
  • Il n'y a pas de limite au nombre de références que vous pouvez ouvrir. Cependant, les performances se dégraderont à mesure que le nombre de références intégrées ouvertes augmentera.
  • Dans ATA, les liens de bloc de page de données fonctionneront comme ils le font actuellement. Il n'y a pas de fonctionnalité supplémentaire pour les blocs de page dans les références intégrées.
  • Pour le contenu qui contient son propre lien de références à l'intérieur, ces auto-références ne sont pas prises en charge pour l'affichage ou impression.

Constructeurs/Types de publication pris en charge

L'affichage des références intégrées est pris en charge dans ces générateurs et les types de modules publications ou de données:
  • A350: AMM, SRM, NTM, TSM
  • C-Series: AMM, ANDTP, ASRP
  • iSpec2200: EM, OMAT, SDS, SPM, TLM, TSD
  • KCA: AMM, CIR, EM, ESM, FRMFIM, HMM, LMM, SM, SPM, SRM, TSM
  • Pratt & Whitney: CIRM, EMAN, EMM, FIM
  • S1000D: Compatibility for spec 3.x, 4.x, 2.3 - descript, proced, frontmatter, crew, sb, schedul
  • XWB: CIRM, CREP, EMAN, SETM
Remarque : Les publications de procédures ne prennent pas en charge les références intégrées.

Reportez-vous à Afficher les références intégrées.
