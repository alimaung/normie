Naviguer dans un projet

Naviguer dans un projet:



La fenêtre Librairie contient un ou plusieurs dossiers, représentés par des icônes .

  1. Cliquez sur un dossier pour trouver la publication que vous recherchez.
    Les publications sont représentées par des icônes .
  2. Sélectionnez la publication que vous souhaitez afficher.
    La fenêtre Librairie est maintenant réduit et la structure de publication est affichée dans la fenêtre Table des matières ci-dessous.
    Remarque : Vous pouvez rapporter la fenêtre Librairie à sa taille maximale en cliquant dessus.
    Remarque : Pour certains types de publication, vous serez redirigé vers la page Filtre avant de commencer à voir le contenu.
  3. Naviguer dans la publication en cliquant sur les chapitres de la Table des Matières. Lorsque vous cliquez sur une entrée, elle se développe pour révéler les niveaux inférieurs, tels que les sections, les tâches, les sous-tâches et les sujets.
    Remarque : Pour éviter plusieurs entrées étendues dans la fenêtre Table des Matières, Pinpoint réduit automatiquement le chapitre précédent lorsqu'un nouveau chapitre est sélectionné.
  4. Cliquez sur le document que vous souhaitez voir (représenté par une icône) .

    Un indicateur de chargement est affiché avant que le document n'apparaisse dans la fenêtre Contenu.

    Les illustrations dans le document sont représentées par des liens. Cliquez sur ces liens pour afficher les illustrations dans la fenêtre Graphique.
