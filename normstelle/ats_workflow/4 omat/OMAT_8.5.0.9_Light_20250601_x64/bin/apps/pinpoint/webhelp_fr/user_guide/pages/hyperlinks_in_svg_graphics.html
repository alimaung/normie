Liens hypertexte dans les graphique SVG

Dans les graphique SVG, par exemple les schémas de câblage, il peut y avoir des liens qui vous permettent de déclencher une nouvelle recherche d'équipement ou d'ouvrir un autre diagramme. Les graphique SVG peuvent aussi contenir des hotspots qui reliés à la liste des pièces dans la fenêtre Contenu. Vous pouvez identifier des liens en plaçant le pointeur de la souris sur le texte dans le diagramme. Si le symbole du curseur change d'un symbole de curseur panoramique à un pointeur de curseur il existe un lien.

En fonction du type d'objet, vous déclencherez différentes actions lors d'un double-clique sur les liens.

  1. Voir un graphique SVG, par example un schéma de câblage.
  2. Dans le graphique SVG, double-cliquez sur un lien hypertexte.

    • Si le lien est un EIN/FIN, la fenêtre Recherche de câblage s'ouvre avec le code EIN/FIN inséré dans le champ de recherche approprié.

      Remarque : Si une recherche d'équipement précédemment été effectuée, vous devrez confirmer que vous souhaitez lancer une nouvelle recherche dans une boîte de dialogue pop-up.

    • Si le lien est un autre schéma, il vous sera demandé de choisir la publication cible.

    • Si le lien est un numéro de position avec un lien vers une liste de pièces, l’application fera automatiquement défiler jusqu’à et mettez en surbrillance le chiffre approprié dans la section Contenu. Cette fonctionnalité est disponible dans ATA AIPC et A350 AIPC.
