Panier-Commande de pièces

La fonction de panier de commande de pièces vous permet de sélectionner et de commander des pièces via une application tierce.

Remarque : Administrateurs, cette fonctionnalité doit être activée. Reportez-vous au sujet Enabling the Part Order Shopping Basket dans Flatirons Pinpoint Configuration Guide.
Pour commander des pièces, procédez comme suit:
  1. Dans le volet Librairie, sélectionnez un dossier.

    Les publications appartenant au dossier sélectionné apparaissent sous le nom du dossier.

  2. Sélectionnez une publication.

    La publication s'affiche dans le volet Contenu.

  3. Sélectionnez l'icône du panier sous la pièce que vous souhaitez commander.

    L'application tierce configurée pour votre organisation s'affiche.

  4. Vérifiez les informations dans l'application. Par exemple, vous pouvez vérifier ces éléments:
    • Numéro d'article
    • Code cage MFG
    • Partager la description
    • Autres éléments déterminés par votre organisation
  5. Soumettez votre commande.
Remarque : Vous devez suivre ces étapes pour chaque pièce que vous souhaitez commander.
