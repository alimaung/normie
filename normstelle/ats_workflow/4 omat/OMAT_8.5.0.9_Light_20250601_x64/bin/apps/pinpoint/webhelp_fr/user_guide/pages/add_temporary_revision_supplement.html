Ajouter Attachement

Non applicable pour Pinpoint Standalone Light.

Remarque : L'ajout de attachements nécessite d'activer toutes les autorisations pour Peut télécharger supplément.

Si vous disposez des autorisations appropriées, procédez comme suit pour ajouter une nouvelle attachement à un document:

  1. Accédez au document auquel vous souhaitez ajouter une attachement.
  2. Dans la barre d'en-tête de Contenu, effectuez l'une de ces choix:
    • Cliquez sur l'onglet Attachements sur le côté droit de la page.
    • Cliquez sur l'icône Télécharger une révision / supplément temporaire.

    Le volet Attachements apparaît:



    Volet des Attachements

  3. Faites l'un de ces choix:
    • Cliquez sur l'onglet + Ajouter des attachements.
    • S'il n'y a aucune attachement pour le document, cliquez sur le bouton vert Ajouter une attachements.
    L'onglet + Ajouter des attachements s'affiche. Les options disponibles peuvent varier.


    + Onglet Ajouter des attachements Exemple

  4. Dans le champ Titre, saisissez un titre pour la attachement.
  5. Facultatif: ajoutez du texte dans le champ DESCRIPTION.
  6. Facultatif: Pour sélectionner une date pour la attachement, procédez comme suit:
    1. À droite du champ DATE, cliquez sur l'icône de sélection de date.
      Un widget de calendrier s'affiche. Par défaut, la date actuelle est sélectionnée.
    2. Sélectionnez une date pour le document dans le widget de calendrier.
    La date que vous avez sélectionnée s'affiche dans le champ DATE.
  7. Facultatif: Si un administrateur a configuré Pinpoint Viewer pour afficher le champ de DATE DE NOTIFICATION, procédez comme suit pour configurer une notification par e-mail pour savoir quand la attachement doit être adressée:
    Pour plus de détails sur la façon dont un administrateur peut configurer les notifications, reportez-vous au Flatirons Pinpoint Configuration Guide, section "Configuration des notifications de attachements".
    1. À droite du champ de DATE DE NOTIFICATION, cliquez sur l'icône de sélection de date.
      Un widget de calendrier s'affiche. Par défaut, la date actuelle est sélectionnée.
    2. Sélectionnez une date pour le document dans le widget de calendrier.
      La date que vous avez sélectionnée s'affiche dans le champ de DATE DE NOTIFICATION et un nouveau champ BÉNÉFICIAIRES DE NOTIFICATION est maintenant visible.
    3. Dans les RECEPTEURS DE NOTIFICATION, saisissez les adresses e-mail qui doivent recevoir une notification sur le DATE DE NOTIFICATION sélectionné.
      Si vous saisissez plusieurs adresses e-mail, saisissez une virgule (,) entre chaque adresse.
    Si vous suivez cette procédure, les adresses e-mail que vous avez saisies recevront une alerte quotidienne une fois que la date actuelle correspond ou est supérieure à la date de notification. L'heure spécifique de la journée à laquelle l'e-mail est envoyé est basée sur ce qui a été configuré par l'administrateur.
  8. Si vous consultez une publication de votre organisation, sélectionnez l'un de ces boutons radio ACCES:
    • Si vous souhaitez que la attachement ne soit visible que par votre organisation, sélectionnez la case d'option Mon organisation.
    • Si vous souhaitez que la attachement ne soit visible que par toutes les organisations, sélectionnez la case d'option Tout les personnes.
      Remarque : Si vous affichez une publication qui ne fait pas partie de votre organisation, la attachement ne sera visible que par votre organisation par défaut.
  9. Dans le menu déroulant CATÉGORIE, sélectionnez le type de téléchargement.
    Les choix dans ce menu déroulant sont configurés via un fichier JSON d'extrémité arrière. Voir le Flatirons Pinpoint Configuration Guide, section "Configuration des types de catégories de attachements".
    Voici quelques exemples de choix dans le menu déroulant CATÉGORIE:
    • Supplément
    • Révision temporaire
  10. À partir les boutons radio de POSITION, effectuez l'une des opérations suivantes:
    • Si la attachement ne se rapporte à aucun emplacement spécifique, sélectionnez le bouton radio Attacher a l'ensemble du document.
    • Si la attachement concerne des emplacements spécifiques dans un document rendu au format HTML, procédez comme suit:

      1. Sélectionnez le bouton radio Attacher a un endroit spécifique.

        Ajouter des ancres aux icônes de sélection sont affichées sur le côté gauche des emplacements de contenu qui prennent en charge les attachements. De plus, un message d'ancrage apparaît sous les boutons radio de POSITION.

      2. Cliquez sur l'icône d'ancrage Ajouter à la sélection des emplacements qui doivent référencer la attachement.

        Les ID d'emplacement d'ancrage que vous avez sélectionnés sont affichés sous forme de liste sous les boutons radio de POSITION.

        Remarque : Pour supprimer un emplacement d'ancrage, cliquez sur l'icône Supprimer l'ancre à droite de la liste ancre.
    • Si la attachement concerne un emplacement spécifique dans un document PDF, procédez comme suit:

      1. Sélectionnez le bouton radio Attacher a un endroit spécifique.

        Le champ PAGES apparaît sous les boutons radio de localisation.

      2. Dans le champ PAGES, tapez une liste de numéros de page séparés par des virgules qui doivent faire référence à la pièce jointe.
        Remarque : La liste des numéros de page séparés par des virgules peut inclure des plages à l'aide de tirets (-).

        Par exemple, tapez 1,3-5 pour référencer la attachement aux pages 1, 3, 4 et 5.

  11. Si le menu déroulant TYPE D'ALERTE n'est pas verrouillé. sélectionnez l'un de ces types d'importance:
    • Pour empêcher la attachement d'être incluse dans les notifications spéciales, sélectionnez l'option de menu None.
    • Pour inclure la attachement dans les bannières de notification Attachements disponibles (Cliquez pour afficher) en haut du document dans le volet Contenu, sélectionnez l'option de menu Normal.
    • Pour afficher la attachement dans une fenêtre contextuelle de attachements importantes lorsque les utilisateurs ouvrent le document (ainsi que les bannières de notification des attachements disponibles (cliquez pour afficher), sélectionnez l'option de menu Important.
  12. Faites l'un de ces choix:
    • Si la CATÉGORIE sélectionnée autorise les attachements, procédez comme suit pour joindre un fichier:

      1. Dans le menu déroulant TYPE D'ATTACHEMENT, sélectionnez l'option de menu Fichier. Le champ Faites glisser votre fichier ici s'affiche sous le menu déroulant TYPE D'ATTACHEMENT.

      2. Faites glisser un fichier de votre ordinateur dans le champ Glisser votre fichier ici ou cliquez sur le champ pour sélectionner un fichier à l'aide d'un boîte de dialogue standard de l'explorateur de fichiers. Le nom de fichier est affiché sous le champ Glisser votre fichier ici.

    • Si la CATÉGORIE sélectionnée autorise les attachements d’hyperliens, effectuez ces sous-étapes pour attacher un lien hypertexte externe vers une page Web:
      Remarque : Si vous souhaitez joindre un lien vers un emplacement de publication, il est recommandé d'utiliser plutôt l'option de menu Publication existante. Si vous utilisez l'option de menu Lien pour ce cas et qu'un utilisateur clique sur le lien, une nouvelle instance de page Web s'ouvrira et ignorera la progression actuelle de l'utilisateur et les utilisateurs de Pinpoint Mobile ne pourront pas ouvrir les liens directement dans l'application Pinpoint Mobile.
      1. Dans le menu déroulant TYPE D'ATTACHEMENT, sélectionnez l'option de menu Lien.
      2. Dans le champ LINK, saisissez une URL valide vers une page Web.
        Remarque : L'URL doit inclure l'intégralité du lien hypertexte, y compris le "http: //" ou "https: //".

        Par exemple, tapez: ar exemple, saisissez: https://www.google.com/

    • Si la CATÉGORIE sélectionnée autorise les attachements de publication existantes, effectuez ces sous-étapes pour attacher un lien Pinpoint à une révision spécifique d'une publication existante:
      1. Dans le menu déroulant TYPE D'ATTACHEMENT, sélectionnez l'option de menu Publication existante.

        Le champ de sélection de PUBLICATION est affiché sous le menu déroulant TYPE D'ATTACHEMENT.

      2. Cliquez sur le champ de sélection PUBLICATION.

        La boîte de dialogue Publication s'affiche avec une liste de publications regroupées par bibliothèque.

      3. Dans la boîte de dialogue Publication, cliquez sur
        sur les icônes de développement pour accéder à la révision souhaitée de la publication souhaitée.
        Remarque : Vous pouvez également utiliser les icônes de réduction pour masquer les groupes de la vue si nécessaire.
      4. Dans la boîte de dialogue Publication, cliquez sur la révision souhaitée que vous souhaitez référencer.
        Remarque :

        Si vous sélectionnez Par défaut, Pinpoint ajoutera un lien vers la révision qui a été sélectionnée par les administrateurs avec la boîte de dialogue Gestion de la publication. Si personne dans votre organisation n'utilise cette boîte de dialogue pour sélectionner une révision spécifique, cette option crée un lien qui se met toujours à jour vers la dernière révision. Faire référence à Gestion des publications.

        Le champ de sélection PUBLICATION affiche la révision de publication que vous avez sélectionnée.

  13. Cliquez sur le bouton vert Créer attachement.

La pièce jointe téléchargée apparaît dans le volet Attachement. Si vous avez ajouté une attachement avec Pinpoint Viewer en ligne, elle est mise à la disposition des autres utilisateurs de Pinpoint Viewer en ligne selon l'option ACCES sélectionnée. Un travail de synchronisation peut également le copier dans Pinpoint Standalone. Cependant, si vous avez créé la attachement dans Pinpoint Standalone, elle n'est pas copiée dans Pinpoint Viewer en ligne. De plus, les utilisateurs de Pinpoint Mobile (tel que déterminé par l'option d'accès sélectionnée) peuvent également voir votre nouvelle attachement s'ils effectuent une synchronisation manuelle.

Après avoir ajouté uneattachement, vous pouvez effectuer l'une de ces options selon vos besoins:
  • Un document peut avoir plusieurs attachements. Pour ajouter d'autres attachements au volet Attachements , répétez les étapes de cette procédure.
  • Pour fermer le volet Attachements, cliquez sur l'onglet Attachements sur le côté droit de la page ou cliquez sur l'icône Télécharger une révision / supplément temporaire.
  • Pour afficher une attachement, cliquez sur le titre de la attachement. Reportez-vous Afficher Attachement.
  • Pour modifier ou afficher les détails d'une attachement, utilisez les icônes à droite du titre de la attachement. Se référer aux Volet Volet des Attachements.
