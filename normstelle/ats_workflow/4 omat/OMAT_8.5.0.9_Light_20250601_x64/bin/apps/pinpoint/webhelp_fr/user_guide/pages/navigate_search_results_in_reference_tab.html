Naviguer dans les résultats de la recherche dans l'onglet Référence

Les résultats de la recherche de l'onglet Référence affichent un historique des schémas de câblage ouverts et des guides d'utilisation ESPM.

  1. Effectuez une recherche de câblage Effectuer une recherche sur câblage.
  2. Dans l'onglet Fil, cliquez sur le lien hypertexte Numéro de pièce de fil dans la colonne Connexion. Pour plus de détails, reportez-vous à Naviguer dans les résultats de recherche de câblage.
    Affiche les résultats de l'onglet Référence.


    Résultats de l'onglet Référence

  3. Effectuez une recherche FIN Effectuer une recherche sur FIN / Zone / Panneau.
  4. Entrez un bon FIN connu dans la zone et cliquez sur le bouton Rechercher
    Affiche la page Sélectionner une catégorie d'entreprise.
  5. Cliquez sur la liste des fils.
    Affiche les informations de l'onglet FIN.
  6. Cliquez sur la zone en surbrillance dans l'onglet FIN.
    Affiche les informations de l'onglet Fil.
  7. Cliquez sur n'importe quelle ligne des informations de l'onglet Fil.
    Affiche les informations de l'onglet Données techniques.
  8. Cliquez sur le lien hypertexte Wire Part Number sur la page Technical Data.
    Affiche les résultats de l'onglet Référence.
