Supprimer la Attachement

Non applicable pour Pinpoint Standalone Light.

Remarque : Il est uniquement possible de supprimer les attachements qui ont été ajoutées directement avec Visionneuse Pinpoint . Vous devez également toutes les autorisations sont activées pour Peut télécharger supplément.

Si vous disposez des autorisations appropriées, procédez comme suit pour supprimer une attachement existante:

  1. Recherchez la attachement que vous souhaitez supprimer du document dans le volet Attachements. Reportez-vous à la section Afficher Attachement.
  2. Cliquez sur l'icône de suppression de attachement à droite de la attachement que vous souhaitez supprimer. Une fenêtre contextuelle de confirmation de suppression apparaît.
  3. Cliquez sur le bouton rouge Supprimer.

    Pinpoint supprime la attachement du document. Si vous avez supprimé une attachement avec Pinpoint Viewer en ligne, elle est également supprimée pour tous les autres utilisateurs de Pinpoint Viewer en ligne et une tâche de synchronisation peut la supprimer de Pinpoint Standalone. Cependant, si vous avez supprimé la attachement dans Pinpoint Standalone, elle n'est pas supprimée de Pinpoint Viewer en ligne. En outre, la attachement est supprimée pour les utilisateurs de Pinpoint Mobile s'ils effectuent une synchronisation manuelle.
