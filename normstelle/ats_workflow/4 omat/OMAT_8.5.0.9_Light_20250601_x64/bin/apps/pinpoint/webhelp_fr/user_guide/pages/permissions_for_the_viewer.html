Les autorisations pour le viewer

Les autorisations pour les fonctionnalités de Pinpoint sont définies dans Access Control. L’administrateur du contrôle d’accès accorde des autorisations au différents rôles d'utilisateur pouvant accéder aux fonctions de la visionneuse. L'administrateur accorde des autorisations aux groupes d'utilisateurs, ce qui permet aux membres d'un groupe d'accéder aux données. Cet accès aux données inclut les bibliothèques, leurs publications et leurs révisions.

Pour plus de détails sur l'octroi d'autorisations aux rôles et groupes d'utilisateurs, reportez-vous au "Manage Function Privileges and Data Access Permissions" sujet dans Flatirons Access Control Module User Guide. Se référer au "Permissions for Pinpoint Viewer" sujet dans Flatirons Access Control Module User Guide pour les autorisations disponibles pour Pinpoint. Vous pouvez ouvrir ce guide en cliquant sur le bouton dans Access Control Barre d'en-tête de l'application.
