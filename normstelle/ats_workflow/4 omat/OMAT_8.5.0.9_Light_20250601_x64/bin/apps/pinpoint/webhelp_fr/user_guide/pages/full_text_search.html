Recherche en texte intégral

La recherche en texte intégral est un moyen rapide de trouver l'un de ces types de données:
  • Lorsque vous ne sélectionnez pas les options Part ou FIN, cette recherche renvoie les résultats pour un ensemble de mots apparaissant dans une publication ou toute pièce jointe contenant des données texte lisibles par machine. Lors de l'utilisation de cette option, les données CIR ne sont pas incluses dans la recherche. Par exemple, si vous tapez un numéro de pièce pour une publication S1000D en Recherche en texte intégral sans sélectionner l'option Pièce, seules les références définies dans les modules de données IPD sont renvoyées.
  • Publications de pièces (tels que AIPC, EIPC, IPD, IPDP et Panasonic_IPD) ont une option Pièce. Lors de l'activation de l'option Pièce, la recherche essaie d'abord d'effectuer une recherche normale en texte intégral. Si aucun résultat n'est renvoyé, l'entrée est supposée être un numéro de pièce dans le CIR. Par exemple, ce type de recherche inclut des résultats pour des pièces facultatives ou préférées.
  • L'option FIN apparaît pour certaines publications (tels que les publications ATA). Lorsque vous sélectionnez l'option FIN, cette recherche renvoie les résultats pour les FIN.
  • Pour les données iSpec 2200, un champ de code vous permet de rechercher par code ATA.

La fenêtre Recherche en texte intégral est ouvert en cliquant en dessous de fenêtre Table de Matières. La page de recherche peut être ouverte dans le contexte d'une publication unique ou d'une librairie. S'il est ouvert au niveau de la librairie, il recherchera dans tous les publications de cette bibliothèque.

Les options de recherche en texte intégral dépendent du contexte. Pour une description détaillée des options de recherche, reportez-vous à ces sections:
