Recherche sur listes d'équipement

Remarque : La recherche d'équipement n'est pas disponible pour Airbus données traitées via Data Manager. Si vous visualisez ce type de données, reportez-vous à Recherche sur FIN/Zone/Panneau à la place.
  1. Ouvrez une publication de câblage dans la fenêtre Librairie.
  2. Ouvrez la Recherche de câblage.
  3. Dans le menu déroulant Types de recherche, sélectionnez Equipement.
  4. Effectuez l'une de ces choix:
    1. Entrez tout ou partie d'un numéro de composant dans le champ EIN.
      Le fait que ce champ soit EIN ou FIN dépend du contexte de publication.
    2. Entrez tout ou partie d'un numéro de pièce dans le champ PNR.
  5. Cliquez sur le bouton Rechercher ou sur le bouton Entrer du clavier pour lancer la recherche. Si vous devez effacer le filtre et recommencer, cliquez sur le bouton Réinitialiser.
    Les résultats de votre recherche apparaissent dans la section Résultats de la recherche. Si le résultat contient plusieurs entrées, un conseil vous conseillera de sélectionner l'une des entrées pour obtenir plus d'informations. Pour plus de détails sur la navigation dans les résultats, reportez-vous à la section Naviguer résultats de la recherche d'Équipment.
