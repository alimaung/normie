Metadonnées du document

La fenêtre Metadata du document s'ouvre en cliquant sur le "i" dans la fenêtre Contenu.
Remarque : Cette icône n'est disponible que si le module de données contient des métadonnées générées par le générateur S1000D.


Metadonnées du document

Le tableau répertorie les métadonnées du document, par exemple:
  • Code du module de données (DMC)
  • Langue
  • Version
  • Date d'édition
  • Niveau de classification
  • RPC
  • Auteur
  • Assurance qualité
  • Applicabilité
Remarque : Si un champ n'a pas de métadonnées, il n'apparaîtra pas dans la table.
