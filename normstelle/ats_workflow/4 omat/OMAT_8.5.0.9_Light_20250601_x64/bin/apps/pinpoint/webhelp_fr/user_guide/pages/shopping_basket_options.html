Options du panier

L'option de panier disponible pour votre organisation dépend de la configuration. Si elles ne sont pas configurées, ces options ne sont pas disponibles dans votre environnement.

Voici les options possibles pour le panier:

  • Panier-Liste de commande de pièces: Cette option vous permet d'ajouter des pièces à une liste pour référence lors de la commande de pièces.
  • Panier-Commande de pièces: Cette option vous permet de commander immédiatement la pièce via une application tierce pour votre organisation.
  • Demande de pièces: Cette option vous permet d'effectuer une demande d'article et de transmettre les paramètres de l'article à une application tierce pour votre organisation.
