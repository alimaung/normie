Examiner le candidat à l'annotation publique

Non applicable pour Pinpoint Standalone Light.

Un utilisateur disposant des autorisations pour créer, modifier et supprimer des annotations peut utiliser cette fonction pour examiner et approuver ou rejeter les annotations créées en tant que candidat public.

Remarque : Les annotations créées par les utilisateurs sans autorisation de les rendre publiques sont créées en tant que "Public Candidate". Ces annotations doivent être approuvées par un utilisateur disposant des autorisations appropriées avant d'être rendues publiques. Pour plus d'informations, voir Créer une nouvelle annotation.

Cette icône apparaît dans l'en-tête Annotations / Supplemental Contents pour les administrateurs lorsqu'il existe des annotations des candidats à examiner. Le nombre indique combien de candidats publics figurent dans le document.

Pour examiner une annotation de candidat publique, suivez les étapes ci-dessous:

  1. Recherchez l'annotation que vous souhaitez réviser et effectuez l'une des opérations suivantes:
    • Passez la souris sur l'annotation pour déclencher la boîte de dialogue contextuelle d'annotation.
    • Cliquez dans la zone grise "Afficher les annotations" pour développer la zone d'annotation.
  2. Cliquez sur l'icône en forme de crayon ( ou ) pour activer.

    Cette boîte de dialogue apparaît lorsque vous modifiez le champ "Afficher les annotations", par exemple:

  3. Affichez toutes les annotations de fichiers pour les formats pris en charge ou en cliquant sur le nom du fichier pour les formats non pris en charge.
  4. Après avoir examiné l'annotation, effectuez l'une des opérations suivantes:
    • Cliquez sur le bouton pour l'approuver et ajoutez éventuellement un commentaire.
      Remarque : Lorsque vous approuvez une annotation, celle-ci devient publique, avec tous les commentaires. Les commentaires ne s'affichent pas en mode Afficher et servent uniquement au suivi.
    • Cliquez sur le bouton pour le rejeter. Vous devez ajouter un commentaire lors du rejet d'une annotation.
      Remarque : Lorsque vous refusez une annotation, elle devient privée pour la création, avec les commentaires de rejet.
    • Cliquez sur le bouton pour annuler.
