La fenêtre graphique

La fenêtre Graphique affiche des illustrations sélectionnées dans la fenêtre Contenu. Les illustrations sont représentées par des liens dans le texte, et en cliquant sur ceux-ci, l'interface utilisateur affiche automatiquement les fenêtres Contenu/Graphique.



La fenêtre graphique

Dans le volet Graphique, cliquez sur l'icône Liste des figures pour afficher la liste des Figures. La liste contient toutes les figures du document actuellement sélectionné. La vue liste est la vue par défaut. Par example:


Figure Liste - Vue liste

Si le document sélectionné est une publication de câblage (WDM, AWM, SSM, ASM), la liste Figures des figures inclut le numéro de page. Par example:


Figure Liste - Publication de câblage

Les publications ASM et SSM peuvent également avoir un schéma. Par example:


Figure Liste - ASM Publication de câblage

Dans la liste des Figures liste, cliquez sur l'optionl , pour passer à une vue de galerie des figures. Par example:


Figure Liste - Vue Vignette

Cliquez sur l'option , pour revenir à une liste des chiffres.

Cliquez sur cette icône pour ouvrir l'image dans une nouvelle fenêtre du navigateur. La nouvelle fenêtre affiche le graphique en taille réelle. Il n'y a pas d'autres fonctions (zoom, pan, etc.) dans la nouvelle fenêtre.

Rafraîchir Cliquez sur cette icône pour réinitialiser le graphique dans sa taille et sa position d'origine dans la fenêtre (par exemple, si vous avez utilisé les fonctions zoom ou rotation).
