Créer un rapport de fusion

Non applicable pour Pinpoint Standalone Light.

Les utilisateurs doivent disposer des autorisations pour le privilège Peut fusionner de nouvelles révisions pour créer un rapport de fusion.

  1. Ouvrez la boîte de dialogue Gestion des publications. Faire référence à Gestion des publications pour la fusion Opérations.
  2. Cliquez sur l'option Créer rapport dans la colonne Actionssur le côté droit de la boîte de dialogue.
    Un message de confirmation apparaît:

  3. Cliquez sur le bouton pour créer le rapport.
    Un message de réussite apparaît:

    Une fois le rapport créé, vous pouvez le visualiser en le sélectionnant dans la boîte de dialogue Gestion des publications. Faire référence à Afficher le rapport de fusion.
