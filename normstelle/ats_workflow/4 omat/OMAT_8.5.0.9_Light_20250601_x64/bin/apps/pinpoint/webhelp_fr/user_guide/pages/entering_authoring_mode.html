Entrer en mode de création

Mode de création

Non applicable pour Pinpoint Standalone Light.

Remarque : Vous devez avoir l'autorisation du privilège Peut créer du contenu pour accéder au mode de création dans Pinpoint. Les utilisateurs de l'organisation système n'ont pas accès à la fonctionnalité de création.

Si vous disposez des autorisations appropriées, vous pouvez voir et sélectionner l'icône Allumer authoring mode dans l'en-tête du volet Contenu. Cette fonctionnalité vous permet d'ajouter un nouveau contenu et de modifier le contenu existant d'un document. Faire référence à Ajouter une nouvelle section and Modifier la section.

Pour entrer en mode création, procédez comme suit:
  1. Dans le volet Librairie, sélectionnez une bibliothèque, puis sélectionnez une publication.
  2. Dans le volet Table de Matières, sélectionnez un document.

    Le document s'ouvre dans le volet Contentu.

  3. Dans l'en-tête du volet Contenu, cliquez sur l'icône Allumer authoring mode. Un message apparaît pour confirmer que vous souhaitez créer un brouillon. Par example:



  4. Cliquez sur le bouton OK pour créer le brouillon.
    L'onglet Authoring apparaît.


    Volet Contenu - Onglet Authoring

Lorsque vous entrez en mode de création, ces modifications de fonctionnalité se produisent:
  • Les fonctionnalités attachements, annotations, et de références intégrées est désactivée lorsque vous êtes en mode création.
  • Le contenu que vous créez est verrouillé pour empêcher d'autres utilisateurs de créer le contenu.
Remarque : Vous pouvez toujours naviguer dans l'application Pinpointet utiliser ses fonctionnalités en mode création.

Icône du mode de création - Indicateurs d'état

L'icône Allumer authoring mode se transforme en une icône différente en fonction de l'état du document en cours de création. Voici les icônes qui peuvent s'afficher:
  • : Le document est disponible pour la création.
  • : Le document est en cours d'élaboration et extrait par l'auteur actuel.
  • : Le document est en cours et extrait par un autre auteur.
  • : Le document est en cours de révision et l'utilisateur actuel est autorisé à le réviser.
  • : Le document est en cours de révision et l'utilisateur actuel ne dispose pas des autorisations nécessaires pour le réviser.
