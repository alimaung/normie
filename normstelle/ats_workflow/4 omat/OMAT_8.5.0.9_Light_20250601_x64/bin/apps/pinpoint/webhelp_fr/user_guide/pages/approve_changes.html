Accepter/Rejeter Changements

Non applicable pour Pinpoint Standalone Light.

Pour examiner les modifications, procédez comme suit:
  1. Ouvrez Historique des Modifications d'un document. Faire référence à Historique des Modifications.
  2. Cliquez dans la colonne la plus à droite du document que vous souhaitez consulter.
    Le document sélectionné s'ouvre dans le volet Contenu. Dans cet exemple, la section rose foncé montre le nouveau contenu à examiner, tandis que la section rose clair est un contenu approuvé préexistant:


    Onglet Création - Revoir le contenu

    Remarque : Le nombre qui s'affiche sur les boutons Rejeter Changements et Accepter Changements indique le nombre de sections, figures ou feuilles modifiées.
  3. Après avoir examiné les modifications, sélectionnez l'une de ces options:
    • Cliquez sur le bouton pour rejeter les modifications.

      La boîte de dialogue Rejeter Changements apparaît, par exemple:

      Optionnel. Entrez une raison du rejet dans le champ commentaire .
      Remarque : Ce commentaire est persistant dans l'historique du brouillon et peut être consulté par l'auteur.

      Cliquez sur le bouton . Cette action ramène le document à la création.

    • Cliquez sur le bouton pour accepter les modifications.

      La boîte de dialogue Accepter Changements apparaît, par exemple:

      Optionnel. Entrez un commentaire de révision dans le champ de commentaire .
      Remarque : Ce commentaire est persistant dans l'historique du projet et peut être consulté par les auditeurs à l'avenir.

      Cliquez sur le bouton . Cette action met à jour la version active du document avec le nouveau contenu.
