Rechercher les listes de câblages

Wire est un type de recherche dans la Recherche de câblage. Pour plus de détails, voir La fenêtre recherche de câblage.

Vous pouvez effectuer une recherche defaisceau pour les données de la série C via une recherche de câble. Cette fonctionnalité est disponible lorsque vous entrez un numéro de faisceau exact dans le champ Bundle.

  1. Ouvrez une publication de câblage dans la fenêtre Librairie.
  2. Ouvrez la Recherche de câblage.
  3. Dans le menu déroulant Types de recherche, sélectionnez Câblage.
  4. Effectuez l'une de ces choix:
    1. Entrez un numéro de composant complet ou partiel dans le champ de l'ensemble.
      Remarque : Vous devez entrer un numéro de faisceau exact pour une recherche de faisceaux de la série C.
    2. Entrez un numéro de pièce complet ou partiel dans le champ Filaire.
  5. (Seulement pour Boeing) , Si applicable, cliquez sur le bouton Fil de réserve pour limiter la recherche aux fils de rechange.
  6. Cliquez sur le bouton Rechercher ou sur le bouton Entrer du clavier pour lancer la recherche. Si vous devez effacer le filtre et recommencer, cliquez sur le bouton de réinitialisation.
    Les Résultats de la recherche s'affichent dans l'onglet Câblage. S'il y a plusieurs entrées dans le résultat, vous verrez un conseil sur la sélection d'une des entrées pour voir plus d'informations. Pour plus de détails sur la navigation dans les résultats, voir Naviguer dans les résultats de recherche de câblage.
    Pour les recherches de faisceaux de la série C:
    • S'il existe plusieurs enregistrements de faisceau, chaque champ de l'enregistrement affiche les valeurs de champ fusionnées.
    • Dans les résultats, la première partie affichée est celle des enregistrements de faisceau. La deuxième partie est les enregistrements de câble où le numéro de faisceau a été utilisé. Seul l'enregistrement faisceau s'affiche s'il n'y a aucun enregistrement de câble.
