Modify Existing Organization

  1. Click the Organizations icon on the header bar to open the Organizations page.
  2. Locate the organization in the list of organizations on the left side pane.
    Note: If there are many organizations in the list you can use the search field above the list to find the organization you are looking for.
  3. Click the organization you want to modify.
  4. Click the Edit icon to make Organization Details fields editable.
    Note: The Edit icon changes to a Cancel icon. If you want to cancel the operation, just click on this icon.
  5. Modify the fields in the form.
    Note: It is not allowed to change the NCAGE field as this can lead to data inconsistencies.
  6. Click the Save button to save the changes.
