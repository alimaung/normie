Approving/Renewing an Access Key

After you request an access key from the Configuration pane in Pinpoint Standalone, a new ACM window opens. After you log in to ACM, you can view, approve, or renew the key in the User Details pane.
Note: You can only manage your own access keys, not those for other users.
  • Any unapproved access keys are removed based on a clean up interval set by your administrator. The default value is 10 minutes. Administrators, refer to the "Configure Clean Up Interval for Unapproved Access Keys in ACM" topic in the Flatirons Pinpoint Configuration Guide.
  • The default validity of an access key is 30 days. Your administrator can configure this value. Administrators, refer to the "Configure Access Key Validity in ACM" topic in the Flatirons Pinpoint Configuration Guide.

To approve or renew your access key, do these steps:

  1. Log in to ACM.
    The User Details pane appears for the logged in user. For example:

    The access key fields are located at the bottom of the User Details pane.
  2. Select one of these options:
    • Click the Approve icon to approve the access key.
    • Click the Renewal icon to renew the access key.
