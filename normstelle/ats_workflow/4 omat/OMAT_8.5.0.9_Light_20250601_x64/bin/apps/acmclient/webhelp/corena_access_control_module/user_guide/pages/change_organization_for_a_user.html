Change Organization for a User

If you belong to a user role that has Write permission on the Users node, you can change the organization of other users. Each user can only belong to one organization. When synchronizing with LDAP, any new users are first associated with the organization selected with the Default organization field on the Organization page. To change the organization for a user, do these steps:

  1. Click the Users icon on the header bar to open the Users page.
  2. Locate the user you want to modify in the list of users on the left side pane.
    Tip: If there are many users in the list you can use the search field above the list to find the user you are looking for.
  3. Click the user you want to modify.
  4. Click the Edit icon to make User Details fields editable.
    Tip: The Edit icon changes to a Cancel icon. If you want to cancel the operation, just click on this button.
  5. Click inside the Organization field.
    The Organizations dialog opens.


    Organizations Dialog

  6. Locate and select the organization you want to associate with the user.
    Note: If you just want to remove the existing organization from the user, select the (No organization) option.
  7. Click the Save icon to save the changes.
