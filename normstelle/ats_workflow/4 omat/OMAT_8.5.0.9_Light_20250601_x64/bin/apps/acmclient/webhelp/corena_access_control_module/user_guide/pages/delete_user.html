Delete User

Note: It is not possible to delete the last user who has Read and Write permission to Privileges.
  1. Click the Users icon on the header bar to open the User page.
  2. In the User section, select the user that you want to delete.
  3. Click the Delete icon in the User Group Details pane.
    A confirmation dialog appears.

  4. Click the Delete button to remove the user.
    Note: If you delete a SAML user by mistake, the user will be recreated in the ACM database the next time the deleted user logs in to ACM.
