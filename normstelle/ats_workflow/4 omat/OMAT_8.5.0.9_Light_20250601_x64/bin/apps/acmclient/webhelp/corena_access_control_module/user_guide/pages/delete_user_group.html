Delete User Group / User Role

Note: It is not possible to delete the last user group that has Read and Write permission to Privileges.

To delete a user group or user role, do these steps:

  1. Click the User Groups icon on the header bar.
    The User Group page shows.
  2. From the drop-down menu at the top of the left-side pane, select one of these options:
    • User Groups
    • User Roles
    Access Control Manager shows a list of the user groups or user roles in your organization that you have permission to see. For example, only system administrators and organization administrators can see "[NCAGE] Organization Administrators" roles.
  3. In the User Groups or User Roles section, select the user group or role you want to delete.
  4. Click the Delete icon in the User Group Details or User Role Details pane.
    A confirmation dialog appears:


    Delete Confirmation Dialog

  5. Click the Delete button to remove the user group or user role.
