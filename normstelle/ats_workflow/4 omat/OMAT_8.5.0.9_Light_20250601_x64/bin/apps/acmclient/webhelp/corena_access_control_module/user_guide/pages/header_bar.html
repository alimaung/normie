Header Bar

The application header bar provides a set of shortcuts to pages within Access Control Manager itself and to other related resources.



Header Bar

Tip: If an icon appears as greyed out, it means that you do not have access to that function. After privileges have been granted, the page must be refreshed. The links to the external applications (Pinpoint Viewer, Data Manager and Audit Manager) are only displayed if their links are present in the acm.app.conf.json file. For more information, refer to Configure Links to External Applications.
Table 1. Header Bar Shortcuts
Shortcut Description
Home icon Application icon. Clicking this icon will take you to the default start page.
Privileges icon Opens the user interface for managing privileges. Refer to Privileges.
Users icon Opens the user interface for managing users. Refer to Users.
User Groups icon Opens the user interface for viewing user groups. Refer to User Groups / User Roles.
Organizations icon Opens the user interface for managing organizations. Refer to Organizations.
Pinpoint Viewer icon Opens Pinpoint Viewer. Refer to Flatirons Pinpoint Viewer User Guide.
Data Manager icon Opens Data Manager. Refer to Flatirons Data Manager User Guide.
Access Control Manager icon The blue highlight indicates that you are inside the Access Control Manager application.
Audit Manager icon Opens Audit Manager. Refer to Flatirons Audit Manager User Guide.
Configuration icon Opens the user interface for setting up the configuration. Refer to Configuration.
Help icon Opens the Access Control Manager User Guide in a new browser tab.
Log Out icon Logs out of Flatirons Pinpoint.
