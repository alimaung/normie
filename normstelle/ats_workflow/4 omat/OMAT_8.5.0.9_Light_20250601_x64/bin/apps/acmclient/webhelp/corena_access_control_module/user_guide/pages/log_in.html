Log In

For security reasons, when initially starting the Access Control Manager, the person using the browser is required to log in. Also, after periods of inactivity, the user is required to log in to the browser.
Note: If guest access is enabled, you can access the public, guest-accessible Pinpoint content without being required to log in.
Note:

For new username and password assistance, contact your supervisor or administrator.

Do these steps:

  1. Open a web browser to the URL provided by your supervisor or administrator.
    Note: Supported web browsers are listed in the Software Overview.
    The login page appears.
    Note: The first graphic shows the standard login page. It will look different if the application has been integrated with SAML. The second graphic shows the login page when guest access is enabled.


    Login Page



    Login Page with Guest Access

    Note: The CHOOSE LANGUAGE option on the login page applies to Pinpoint only.
  2. Do one of these choices:
    1. Enter your Username and Password, and click the LOG IN button.
      Note: If you want to check the spelling of the password, select the Show Password checkbox.
    2. Click the CONTINUE AS GUEST button.
      If the environment also allows authenticated users, you can select at the top right corner of the application to log out of the public environment and display the Access Control Manager login page.
  3. Hit the Enter button or click the LOG IN button.

You are then directed to the Access Control Manager welcome page.



Start Page

Note: The menu options available to you depends the configuration of the system and on the privileges that you have. If an icon is greyed out, it means that you do not have permission to access that function.
The bottom bar provides this information:
  • The current version of the software.
  • Status of ACM information, for example LDAP configuration (if any).
  • Name and user role for the currently logged in user. If the user belongs to more than one role, the first role is displayed.
    Note: You can click the link to view the user ID, name, and the user groups/roles to which the user belongs.
