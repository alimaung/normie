Import User Groups

User groups can be added by importing a CSV file. The CSV file must be a list where the user groups are separated by new lines. You can optionally add descriptions that will populate the Description field. The user group and the description must then be separated by a semicolon as shown in the example below:

Mechanics;Department 40 staff
Crew;Department 58 staff
Operators;Department 99 staff
Note: This feature is not available for User Roles.

To import user groups, do these steps:

  1. Click the User Groups icon on the header bar.
    The User Group page shows.
  2. From the drop-down menu at the top of the left-side pane, select User Groups.
  3. In the top of the User Groups section, click the Upload CSV icon.
    A Click or Drop CSV File here dialog appears:


    Click or Drop CSV File Here Dialog

  4. Do one of the following:
    • Drag the CSV file into the dialog box.
    • Click inside the dialog to browse for the CSV file.

The uploading starts. When complete you will see a status message stating the number of user groups that have been imported.
