Defining Server Log Level

All exceptions thrown from the server can be logged by configuring the file logback-include.xml in the ACM config directory. The XML file is not default present in the config directory, it has to be added manually. When it is not present, the log level is default set to INFO. To modify the log level you can add the file using the example below and then modify the log level attributes. In this example the logging options are commented out, which means that logging level by default is set to INFO:

<included>
<!-- override the default value; or comment out to leave it at default -->
<!--<property name="root.level" value="info" />-->
<!--<logger name="com.flatirons.commons.i18n.BaseException" level="trace"/>-->
</included>

To enable/change logging you can simply remove the comments tags "<!--" and "-->" on line 3 and 4. The following log levels can then be applied: trace/debug/info/warn/error. For more information about log levels, refer to http://logback.qos.ch/manual/architecture.html

<property name="root.level" value="info" /> controls the log level for all ACM while <logger name="com.flatirons.commons.i18n.BaseException" level="trace"/> is for BaseException only.

If you modify the file, the server must be restarted for the changes to take effect.
