Add/Edit/Delete Permission Types

This procedure explains how you can add, edit or delete permission types in Access Control Manager.

To modify permission types, do these steps:

  1. Click the Configuration icon on the header bar to open the Configuration page.
  2. In the left menu, click Permission Types.
    The Permission Types pane appears.


    Permission Types

  3. Do one of these choices.
    • Create a new permission type: Click the Create icon and type a new name in the Add/Edit Permission field.
    • Edit existing permission type: Click the entry you want to edit in the Permission Types list and modify it in the Add/Edit Permission field.
    • Delete existing permission type: Click an existing entry in the Permission Types field and click the Delete icon. Click the OK button in the confirmation dialog.
  4. If you created a new or modified an existing permission type, click the Save icon to save the changes.
    New or modified permission type can be seen in the Permission Types list. You can also open the Privileges page by clicking on the Privileges icon in the header bar and verify that the updated permission types are present.
