Encrypt Passwords/User Names

The Encryption page offers a quick way of encrypting strings, like the LDAP password or the passwords used for communication between Access Control Manager, Data Manager, Pinpoint and other applications. It can take any input string and encrypt it with both RSA and Jasypt.
Note: The password in LDAP Configuration support both Jasypt and RSA encoded passwords.

Follow the steps below to encrypt a string:

  1. Click the Configuration icon on the header bar to open the Configuration page.
  2. In the left menu, select the Encryption option.
    The Encryption page appears.


    Encryption Page

  3. In the Input String field, enter the string that shall be encrypted.
  4. Click the Encrypt string icon.
    The encrypted version of the string appears below, both with RSA and Jasypt encoding:


    Encryption Example

  5. Click the Copy to clipboard icon to the right of the field.
    The encrypted field is now on your clipboard. You can paste the encrypted field (the entire string, including RSA/ENC) into files or application forms.
