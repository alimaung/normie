ACM Managers Feature Configuration

You can make an ACM managers feature configuration change in the acm.app.conf.json file with the two Boolean variables:
  • "groupManagerActive": false
  • "roleManagerActive": false
By default, the values will be set to false:
  1. If the role manager feature active value is false, the managers field, and the buttons to move users in and out of that user role will not show on the role dialog and the Managers show in the user field.
  2. If the group manager feature active value is false, the managers field, and the buttons to move users in and out of that user role will not show on the group dialog and the Managers show in the user field.
  3. If the role manager feature active value is true, the managers field, and the buttons to move users in and out of that user role will show and are active on the role dialog and the Managers show in the Managers field.
  4. If the group manager feature active value is true, the managers field, and the buttons to move users in and out of that user role will show and are active on the group dialog and the Managers show in the Managers field.
