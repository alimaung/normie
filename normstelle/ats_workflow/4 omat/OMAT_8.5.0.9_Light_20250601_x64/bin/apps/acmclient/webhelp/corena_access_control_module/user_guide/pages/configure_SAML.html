Configure SAML

This procedure explains how to add or modify SAML configuration settings in Access Control Manager so that users are authenticated by a SAML Identity Provider.

  1. Click the Configuration icon on the header bar to open the Configuration page.
  2. In the left menu, select SAML Configuration
    The SAML Configuration form appears:


    SAML Configuration

  3. Click the Edit icon to enable editing.
  4. Complete the required information, as described in Table 3. Required fields appear with bold letters, asterisk and a red border.
  5. To add a certificate, do the following sub-steps:
    1. Click the Edit icon next to the Trusted certificates field to enable editing.
    2. Click the button.
      The Add certificate dialog appears:


      Add Certificate Dialog

    3. Type a description in the Certificate description field.
    4. Paste the certificate into to Certificate field.
    5. Click the Save icon in the upper right corner to save the certificate.
      The certificate description is now listed in the Trusted Certificates field.
      Note:
      • If you need to modify a certificate, select it in the Trusted certificates field and click the to open the Add certificate dialog again.
      • If you want to delete a certificate, select it in the Trusted certificates field and click the Delete icon.
      Note: The changes that you do, both in the text fields and in the Trusted certificates field, are not saved before the Save icon in the upper right corner is pressed. For example, if you accidentally removed a certificate or the content in a mapping field, and cannot remember the content of it, you can simply click the Delete icon and confirm the All changes will be lost dialog to return to the last saved settings.
  6. Click the button to save the SAML configuration.
  7. If not already done, open the Authentication Provider Configuration page select the SAML option to activate the SAML configuration.
    The application login page will now be decided by the SAML configuration and the user authentication will be handled by the defined SAML Identity Provider.
