Create New User Group / User Role

Note: You can only create user roles and user groups for the organization you belong to. For example, if you use a system administrator account belonging to the System organization, any user groups or user roles you create will belong to the System organization.

To create a new user group or user role for your organization, do these steps:

  1. Click the User Groups icon on the header bar.
    The User Group page shows.
  2. From the drop-down menu at the top of the left-side pane, select one of these options:
    • User Groups
    • User Roles
  3. In the top of the User Groups or User Roles section, click the Create new icon.
    An empty User Group Details / User Role Details pane appears on the right side.


    Create User Group Example

  4. If applicable, activate the Synchronized with LDAP checkbox.
  5. Type a name in the GroupName or RoleName field (required).
  6. Optional: Type some text in the Description field.
  7. To add users to the user group or user role, do these substeps:
    1. Click the Add User(s) icon.
      Access Control Manager shows a list of users.
    2. In the Add User(s) dialog, select the users you want to add.

      You can use Shift + left click to select multiple users.

    3. Click the Save icon.
    The Users list updates.
  8. To remove users from the user group or user role, do these substeps:
    1. Click a user in the Users list.
    2. Click the Remove User(s) icon.
    The Users list updates.
  9. Optional: To add another user group or user role immediately after saving the current one, activate the Create another checkbox at the top-right of the form.
  10. Click the Save icon.

Access Control Manager saves the new user group or user role for your organization.
