Organizations

If your user role has Read permission for the Organizations privilege, you can access the Organizations page by clicking the Organizations icon on the header bar.

The Organizations page lets you view and manage organizations. The page is split in two panes:

  • Organizations (left side): Lists all registered organizations in the system and allows you to search for organizations.
  • Organization Details (right side): Shows detailed information about a selected organization.


Organizations Page Example

Some organization tasks are located in different parts of Access Control Manager:
  • To update which users belong to which organizations, refer to Change Organization for a User.
  • To update data access and function privileges available to each organization, refer to Manage Function Privileges and Data Access Permissions.

The table below describes the components in the Organizations pane.

Table 1. Components in Organizations
Field/button Description
Create new icon Click this icon to Create a New Organization.
Search field and search icon

Type text in this field and click the search icon to search for a specific organization. The search returns organizations that match the search text in either Name, NCAGE, or Type.

The search is not case sensitive and has support for "*" and "%" wild cards. A hidden "%" wild card is automatically applied in front of and behind the entered text. This means that a search for "test" returns "tests" and "tester" in addition to the actual search word.

You can also use the "*" or "%" wild card to replace characters in the search word. A search for "organi*ation" will return both "organisation" and "organization".
Organizations list

The organization list shows all organizations registered in the system. When you select an organization in the list you will see detailed information about it in the Organization Details pane on the right side.

If the list contains more entries than can fit into one page, the list is paged and you can navigate between the pages using the navigation buttons below the list.

The list is by default sorted by organization Name, but you can change the sorting by clicking on the column headers.

Type drop-down menu The organization types available in the Type field are pre-defined in the system. The meaning of each organization type and how different organisations are categorised, should be decided by the system owner. The descriptions provided below are intended as suggestions only
  • CUSTOMER: Typically a documentation receiver.
  • PARTNER: Typically a sub-contractor
  • OWNER: Typically a project owner.
  • VENDOR: Typically a parts manufacturer
Track audits checkbox By default, this option is activated for a new organization. When activated, track audit events for the organization are tracked in Audit Manager.

Users who are members of user roles with the "Can configure track audits for libraries and publications" can enable or disable tracking for the organization.

Note: If you disable Track Audits, data tracked prior to that change is not removed from Audit Manager automatically. This requires manual clean up of this data.

Small logo This area allows the customer's smaller logo to be uploaded to the Pinpoint Mobile Viewer device like the iPad, iPhone, Android phone, or tablet.
