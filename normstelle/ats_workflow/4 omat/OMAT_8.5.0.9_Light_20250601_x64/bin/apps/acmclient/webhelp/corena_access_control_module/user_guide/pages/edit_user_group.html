Edit User Group / User Role

If you have proper permissions, you can edit a user group or user role and the users that belong to that group or role. Do these steps:

  1. Click the User Groups icon on the header bar.
    The User Group page shows.
  2. From the drop-down menu at the top of the left-side pane, select one of these options:
    • User Groups
    • User Roles
    Access Control Manager shows a list of the user groups or user roles in your organization that you have permission to see. For example, only system administrators and organization administrators can see "[NCAGE] Organization Administrators" roles.
  3. In the User Groups or User Roles section, select the user group or user role you want to modify.
  4. Click the Edit icon in the User Group Details or User Role Details pane.
    The User Group Details or User Role Details is now editable.


    Edit User Group Example

  5. If applicable, activate the Synchronized with LDAP checkbox.
  6. Type a name in the GroupName or RoleName field (required).
  7. Optional: Type some text in the Description field.
  8. To add users to the user group or user role, do these substeps:
    1. Click the Add User(s) icon.
      Access Control Manager shows a list of users that belong to the selected group’s/role’s organization (if that group/role has a specific organization associated with it).
    2. In the Add User(s) dialog, select the users you want to add.

      You can use Shift + left click to select multiple users.

    3. Click the Save icon.
    The Users list updates.
  9. To remove users from the user group or user role, do these substeps:
    1. Click a user in the Users list.
    2. Click the Remove User(s) icon.
    The Users list updates.
  10. Save changes by clicking the Save icon.
