Set a User to Absent

You can set a user to absent and add information about the absence. This allows you to notify others of the absence, for example, a user marked as absent would show as absent on various reports created in Audit Manager.

Do these steps:

  1. Click the Users icon on the header bar to open the Users page.
  2. Locate the user you want to set as absent in the list of users on the left side pane.
    Tip: If there are many users in the list you can use the search field above the list to find the user you are looking for.
  3. Click the user you want to set as absent.
  4. Click the Edit icon to make the User Details fields editable.
    Tip: The Edit icon changes to a Cancel icon. If you want to cancel the operation, just click on this button.
    You can select the Absent checkbox.


    Absent Checkbox

  5. Select the Absent checkbox.
    Note: When you set a user as absent and that user logs in, the Absent checkbox is cleared automatically. You can also manually deactivate the checkbox.
  6. Enter information about the absence in the field next to the checkbox.
    Note: The information you enter about the absence is retained for future use whether you manually deactivate the Absent checkbox or the absent user logs in.
  7. Click the Save icon to save the changes.
