Managing User Access Keys

Through ACM, Pinpoint supports SAML. SAML enables SSO, which allows users to log in once and reuse those credentials. This functionality enables Pinpoint Standalone to connect SAML enabled PP Server and to download packages.

The access key area must be enabled before it is visible in the User Details pane. Administrators, refer to the "Enable the Display of Access Keys Panel in ACM" topic in the Flatirons Pinpoint Configuration Guide.

Users can request an access key from the Configuration pane in Pinpoint Standalone. After the request is submitted, a new ACM window opens. The user requesting the access key needs to log in to ACM. After logging in, the user can view, approve, renew, or delete the key in the User Details pane.
Note: A user can only manage their own access keys, not those for other users.

User Details Pane

This table describes the access key fields, which are located at the bottom of the User Details pane.

Field Description
KEY LABEL Displays the Username.
KEY STATUS Displays the status of the access key.
EXPIRATION DATE Displays the expiration date of the access key.
APPROVAL DATE Displays the approval date of the access key.
ACTIONS Select one of these options to take on the access key:
  • Approve - Approve the access key
  • Delete - Delete the access key
  • Renewal - Renew the access key
