Single Search Term: safety
Finds documents with the word "safety"
Matches the entire word, a search for "safe" will not return matches for "safety"

Multiple Search Terms OR: safety varnish
Finds documents with the word "safety" OR "varnish"

Multiple Search Terms AND: +safety +varnish
Finds documents with the word "safety" AND "varnish"

Multiple Search Terms NOT: +safety -varnish
Finds documents with the word "safety" AND NOT "varnish"

Wildcards: var*
Finds documents with a word starting with "var"
The "*" represents one or more characters
A search for "var*" would return a match for "varnish", but not for "var"

Fuzzy Matches: varnash~1
Finds documents with a word within one letter of "varnash"

Stop Words:
Generic words, such as "the", will be discarded from the search
A warning will display if you attempt to search on a stop word
