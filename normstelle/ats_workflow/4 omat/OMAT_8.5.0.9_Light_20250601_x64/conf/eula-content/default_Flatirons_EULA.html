Template for End-User License Agreement (EULA)

This dialog shows the EULA template for Pinpoint.
You must click "I agree" in order to access and view content loaded into this application.

The EULA dialog can be customized to fit your organization/content.

You can also decide whether this dialog should be displayed to the user every time a new publication has been loaded.

If a EULA is not required it can be turned off.

Refer to the Pinpoint documentation for a description of how to configure the EULA functionality.
