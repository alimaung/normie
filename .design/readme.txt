# To prepare email templates we've used helpfull tool available on https://app.bootstrapemail.com/

# Files with names *-template.html are ready to use

# If there is a need to change templates please just copy code from files names *-source.html 
  and paste it to the https://app.bootstrapemail.com/editor and re-render a new output code which is ready to be sent in emails 

# The images used in templates always should be available online (do not use inline base64 code)

# To test email templates there is a tool available on https://putsmail.com/tests/new
